# Карточка звонка CALL_CARD: обзор команд и событий

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Точка встраивания `CALL_CARD` добавляет виджет приложения вкладкой в карточку звонка CRM. Через js-интерфейс приложение получает данные текущего звонка, управляет автозакрытием карточки и реагирует на смену клиента или состояния звонка.

{% note warning "" %}

Команды и события этого раздела — не методы REST. Приложение вызывает их в браузере через js-интерфейс точки встраивания: команды — методом [BX24.placement.call](../bx24-placement-call.md), подписку на события — методом [BX24.placement.bindEvent](../bx24-placement-bind-event.md). Запросов к `/rest/` с именами `getStatus` или `CallCard::EntityChanged` не существует.

{% endnote %}

## Как начать работу с CALL_CARD

1. Зарегистрируйте точку встраивания `CALL_CARD` методом [placement.bind](../../placement-bind.md) — виджет появится вкладкой в карточке звонка. Как устроена сама точка встраивания и какие данные приходят обработчику при открытии, описано на странице [{#T}](../../telephony/call-card.md)
2. Убедитесь, что виджет открыт именно в этой карточке: список доступных команд и событий возвращает [BX24.placement.getInterface](../bx24-placement-get-interface.md)
3. Получите данные текущего звонка командой [getStatus](./get-status.md)
4. Подпишитесь на изменения в карточке методом [BX24.placement.bindEvent](../bx24-placement-bind-event.md)

Минимальный рабочий цикл: приложение читает данные звонка и следит за сменой его состояния.

```js
BX24.ready(function () {
    BX24.init(function () {
        BX24.placement.call('getStatus', {}, function (status) {
            console.log(status.CALL_ID, status.PHONE_NUMBER);
        });

        BX24.placement.bindEvent('CallCard::CallStateChanged', function (callState) {
            console.log(callState);
        });
    });
});
```

## Как устроен вызов команды точки встраивания

Команду вызывают по имени: первым аргументом [BX24.placement.call](../bx24-placement-call.md) передают имя команды, вторым — объект параметров, третьим — функцию обратного вызова.

Ни одна из команд `CALL_CARD` параметров не принимает — вторым аргументом передают пустой объект `{}`.

Команда `getStatus` возвращает данные текущего звонка, команды управления автозакрытием — пустой массив. Собственных кодов ошибок у них нет.

Если виджет открыт не в карточке звонка, интерфейс точки встраивания игнорирует незнакомую команду: функция обратного вызова не срабатывает вовсе.

События приходят в функцию обратного вызова, переданную в [BX24.placement.bindEvent](../bx24-placement-bind-event.md). В обработчик попадают данные клиента, состояние звонка с дополнительными параметрами или вызов без данных, если карточка закрывается.

## Как устроено автозакрытие карточки

По умолчанию карточка исчезает сразу после разговора, вместе с ней закрывается и виджет. Чтобы пользователь успел заполнить форму приложения, автозакрытие блокируют.

1. Разговор завершается, и Битрикс24 пытается закрыть карточку
2. Если автозакрытие запрещено командой [disableAutoClose](./disable-auto-close.md), приходит событие [CallCard::BeforeClose](./call-card-before-close.md), а карточка остается на экране еще 65 секунд. Каждый повторный вызов `disableAutoClose` отсчет продлевает
3. Когда приложение закончило работу, оно вызывает [enableAutoClose](./enable-auto-close.md). Запрет снимается, и карточка закрывается, если разговор уже завершен

```js
BX24.ready(function () {
    BX24.init(function () {
        // пользователь начал заполнять форму — не даем карточке закрыться
        BX24.placement.call('disableAutoClose', {}, function () {
            console.log('автозакрытие заблокировано');
        });

        BX24.placement.bindEvent('CallCard::BeforeClose', function () {
            // карточку пытаются закрыть: сохраняем данные формы
            saveFormData().then(function () {
                BX24.placement.call('enableAutoClose', {}, function () {
                    console.log('автозакрытие возвращено');
                });
            });
        });
    });
});
```

## Как выбрать команду или событие

#|
|| **Сценарий** | **Что использовать** ||
|| Нужны данные текущего звонка: идентификатор, номер, линия, привязка к CRM | Команда [getStatus](./get-status.md) ||
|| Виджет показывает форму, и карточка не должна закрыться сама после завершения звонка | Команда [disableAutoClose](./disable-auto-close.md), а после сохранения данных — [enableAutoClose](./enable-auto-close.md) ||
|| Нужно обновить интерфейс виджета, когда сменился привязанный к звонку клиент: карточка подтянула данные CRM, оператор создал лид или перешел к следующему клиенту в обзвоне | Событие [CallCard::EntityChanged](./call-card-entity-changed.md) ||
|| Нужно сохранить данные до того, как карточка исчезнет | Событие [CallCard::BeforeClose](./call-card-before-close.md) вместе с командой [disableAutoClose](./disable-auto-close.md) ||
|| Виджет должен реагировать на соединение и завершение разговора | Событие [CallCard::CallStateChanged](./call-card-call-state-changed.md) ||
|#

## Обзор команд и событий {#all-methods}

> Scope: [`placement`](../../../scopes/permissions.md) — регистрация точки встраивания, [`telephony`](../../../scopes/permissions.md) — доступ к точке встраивания карточки звонка
>
> Кто может выполнять команды: любой пользователь

{% list tabs %}

- Команды

    #|
    || **Команда** | **Описание** ||
    || [getStatus](./get-status.md) | Получает информацию о текущем звонке ||
    || [disableAutoClose](./disable-auto-close.md) | Отключает автоматическое закрытие карточки после завершения звонка ||
    || [enableAutoClose](./enable-auto-close.md) | Включает автоматическое закрытие карточки после завершения звонка ||
    |#

- События

    #|
    || **Событие** | **Вызывается** ||
    || [CallCard::EntityChanged](./call-card-entity-changed.md) | При смене клиента, привязанного к звонку ||
    || [CallCard::BeforeClose](./call-card-before-close.md) | При попытке закрыть карточку звонка, в том числе неудачной ||
    || [CallCard::CallStateChanged](./call-card-call-state-changed.md) | При смене состояния текущего звонка ||
    |#

## Типовые ошибки

#|
|| **Проблема** | **Причина и что сделать** ||
|| Функция обратного вызова не срабатывает | Виджет открыт не в точке встраивания `CALL_CARD` или имя команды набрано с ошибкой. Сверьте список доступных команд методом [BX24.placement.getInterface](../bx24-placement-get-interface.md) ||
|| Карточка закрывается, пока пользователь заполняет форму виджета | Автозакрытие не отключено. Вызовите [disableAutoClose](./disable-auto-close.md) и не забудьте вернуть автозакрытие командой [enableAutoClose](./enable-auto-close.md) ||
|| В данных звонка пустой `CRM_ENTITY_TYPE` или `CRM_ENTITY_ID = 0` | Звонок не привязан к объекту CRM. Разбирайте этот случай отдельно, не считая его ошибкой ||
|| Попытка управлять кнопками карточки, менять заголовок или состояние интерфейса | В `CALL_CARD` таких команд нет. Это возможности фоновой точки встраивания — см. [{#T}](../page-background-worker/index.md) ||
|#
