# Сценарий встраивания WebRTC

Приложение телефонии со своим WebRTC-клиентом работает с карточкой звонка Битрикс24 в два шага: регистрирует фоновый обработчик один раз, а при каждом звонке регистрирует звонок, и Битрикс24 показывает его карточку. Команды и события карточки перечислены в обзоре раздела [{#T}](./index.md).

## Регистрация обработчика

Обработчик WebRTC-клиента регистрируется один раз и загружается на каждой странице.

Для этого есть специальная точка встраивания — невидимый фрейм на каждой странице Битрикс24. Приложение регистрирует в ней обработчик методом [placement.bind](../../placement-bind.md) из своего интерфейса, например при установке. Приложению нужны скоупы `placement` и `telephony`. Кто может вызывать [placement.bind](../../placement-bind.md), описано на странице метода. Обработчик начнет загружаться, когда установка приложения завершится.

Примеры написаны на [BX24.js](../../../../sdk/bx24-js-sdk/index.md) — библиотеку подключают на странице приложения. Пример регистрации:

```js
BX24.callMethod(
    'placement.bind',
    {
        PLACEMENT: 'PAGE_BACKGROUND_WORKER',
        HANDLER: 'https://your-domain.com/widgets/call-worker.html',
        TITLE: 'WebRTC-клиент',
        OPTIONS: {
            errorHandlerUrl: 'https://your-domain.com/widgets/call-worker-error.php'
        }
    },
    function (result) {
        if (result.error()) {
            console.error(result.error());
        } else {
            console.log(result.data()); // true
        }
    }
);
```

Тот же вызов на других языках показан в статье [{#T}](../../universal/background-worker.md).

Важное отличие от других точек — обязательный параметр `OPTIONS[errorHandlerUrl]`. Виджет загружается на каждой странице, поэтому обработчик должен отвечать быстро: если фрейм обработчика загружается дольше пяти секунд и это повторяется больше десяти раз за сутки на одном Битрикс24, регистрация удаляется. Об удалении Битрикс24 сообщает запросом на адрес из `errorHandlerUrl`, после чего обработчик нужно зарегистрировать заново. Подробнее — в статье [{#T}](../../universal/background-worker.md).

## Сценарий использования

Звонок регистрируют методом [telephony.externalCall.register](../../../telephony/telephony-external-call-register.md). Он же показывает карточку звонка сотруднику из параметра `USER_ID`. Вызывайте метод, когда WebRTC-клиент виджета начал обрабатывать звонок. Фоновый обработчик подписывается на события карточки раньше — при загрузке, методом [BX24.placement.bindEvent](../bx24-placement-bind-event.md). Событие, которое пришло до подписки, обработчик не получит.

Пример вызова:

```js
BX24.callMethod(
    'telephony.externalCall.register',
    {
        USER_ID: 1,                  // оператор, которому Битрикс24 покажет карточку
        PHONE_NUMBER: '+79001234567', // номер собеседника
        TYPE: 2,                     // 2 — входящий звонок
        SHOW: 1                      // показать карточку сразу
    },
    function (result) {
        if (result.error()) {
            console.error(result.error());
        } else {
            console.log(result.data().CALL_ID); // идентификатор звонка для telephony.externalCall.finish
        }
    }
);
```

Далее виджет может взаимодействовать с открытой карточкой звонка. Для работы с карточкой через точку встраивания `PAGE_BACKGROUND_WORKER` есть 9 команд js-интерфейса для получения и изменения данных карточки и 16 событий для обработки действий оператора — полный список в обзоре раздела [{#T}](./index.md).

Ключевое событие — [BackgroundCallCard::initialized](./events/initialized.md). Оно возникает при создании карточки звонка, и только после него карточкой можно управлять. Поэтому команды вызывайте после того, как оно придет. Исключение — команда [CallCardGetListUiStates](./call-card-get-list-ui-states.md): ей карточка не нужна. Номер собеседника и привязка к CRM приходят раньше `initialized` — в событии [BackgroundCallCard::entityChanged](./events/entity-changed.md), в полях `PHONE_NUMBER`, `CRM_ENTITY_TYPE`, `CRM_ENTITY_ID`. Это событие приходит, только если карточка загружает данные CRM.
