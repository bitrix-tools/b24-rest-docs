# Методы BX24 SDK для виджетов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

В виджетах можно использовать JS-методы `BX24.openApplication`, `BX24.openPath` и `BX24.closeApplication`. Они помогают открывать интерфейс приложения или стандартные страницы Битрикс24 прямо из встроенного виджета без вызова REST-методов.

Методы работают только во фрейме приложения: вызывайте их после инициализации библиотеки, в функции обратного вызова [BX24.init](../../sdk/bx24-js-sdk/system-functions/bx24-init.md). Как подключить библиотеку к странице обработчика, описано в обзоре [BX24.js](../../sdk/bx24-js-sdk/index.md).

Подробное описание синтаксиса, параметров и callback-функций смотрите в разделе [Дополнительные функции BX24.js](../../sdk/bx24-js-sdk/additional-functions/index.md).

## Открыть интерфейс в слайдере BX24.openApplication

Используйте `BX24.openApplication`, когда нужно открыть интерфейс вашего приложения в отдельном слайдере и передать в него произвольные параметры.

Метод используют для настроек приложения, диалогов с пользователем и показа дополнительной информации поверх текущего интерфейса. Если интерфейс виджета ограничен размером iframe, слайдер открывается поверх текущей страницы и позволяет показать отдельный интерфейс приложения без ограничений исходной области встраивания.

Метод управляет только интерфейсом приложения и не заменяет вызовы REST API.

{% include [Сноска о примерах](../../_includes/examples.md) %}

```js
BX24.init(function () {
    // параметры придут JSON-строкой в PLACEMENT_OPTIONS обработчика в слайдере;
    // по view обработчик сам решает, какой экран показать
    BX24.openApplication(
        { view: 'settings' },
        function () {
            console.log('Слайдер закрыт');
        }
    );
});
```

Подробнее в описании метода [BX24.openApplication](../../sdk/bx24-js-sdk/additional-functions/bx24-open-application.md).

## Открыть страницу BX24.openPath

Используйте `BX24.openPath`, когда нужно открыть стандартную страницу Битрикс24, например карточку CRM, задачу или профиль пользователя.

Метод позволяет не дублировать стандартный интерфейс Битрикс24 внутри приложения. Его задача — навигация внутри интерфейса, а не получение данных со страницы напрямую.

Чтобы обновить данные виджета после закрытия стандартной страницы, используйте `callback` метода `BX24.openPath`: он срабатывает, когда пользователь закрывает слайдер. [События](../events/index.md) и [интерактивное взаимодействие](../../settings/interactivity/index.md) нужны, если данные могут измениться и без участия виджета.

На телефонах и планшетах метод не работает: `callback` получит ошибку `METHOD_NOT_SUPPORTED_ON_DEVICE`.

Пример открывает карточку сделки с идентификатором `5`. Для своей сделки подставьте в путь ее идентификатор.

```js
BX24.init(function () {
    BX24.openPath('/crm/deal/details/5/', function (result) {
        if (result.result === 'error') {
            console.log('Не удалось открыть страницу:', result.errorCode);
            return;
        }

        console.log('Пользователь закрыл слайдер');
    });
});
```

Подробнее в описании метода [BX24.openPath](../../sdk/bx24-js-sdk/additional-functions/bx24-open-path.md).

## Закрыть окно приложения BX24.closeApplication

Используйте `BX24.closeApplication`, когда нужно закрыть окно приложения, ранее открытое через `BX24.openApplication`.

Метод работает на стороне интерфейса и управляет только окном приложения. Он не предназначен для закрытия произвольных стандартных слайдеров Битрикс24.

```js
BX24.init(function () {
    // кнопка <button id="close-window"> на странице, открытой через BX24.openApplication
    document.getElementById('close-window').addEventListener('click', function () {
        BX24.closeApplication();
    });
});
```

Подробнее в описании метода [BX24.closeApplication](../../sdk/bx24-js-sdk/additional-functions/bx24-close-application.md).
