# Универсальные виджеты: обзор точек встраивания

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Универсальные виджеты не привязаны к конкретному инструменту Битрикс24: ни своей кнопки, ни своего меню у них нет. Обработчик вызывается либо по ссылке, которую приложение само разместило в контенте, либо на каждой странице Битрикс24 без участия пользователя. Обе точки требуют scope `placement`.

Для регистрации виджета используйте метод [placement.bind](../placement-bind.md) и передавайте нужный код в параметре `PLACEMENT`.

> Быстрый переход: [все точки встраивания](#all-placements)

## Как выбрать точку встраивания

Точки различаются тем, кто запускает обработчик.

#|
|| **Точка встраивания** | **Кто запускает** | **Когда использовать** ||
|| [REST_APP_URI](./app-url.md) | Пользователь — переходом по ссылке приложения | Приложение размещает ссылку в сообщении, комментарии, задаче или другом контенте, а обработчик открывается слайдером поверх текущей страницы. В ссылку можно передать свои параметры ||
|| [PAGE_BACKGROUND_WORKER](./background-worker.md) | Битрикс24 — при каждой загрузке страницы | Приложению нужен код, работающий на всех страницах Битрикс24: прием сигналов от своего backend, интеграция телефонии, автоматическое открытие интерфейса приложения. Видимого элемента у точки нет ||
|#

## Как начать работу

1. Выберите точку по тому, кто запускает обработчик: пользователь по ссылке или Битрикс24 на каждой странице
2. Зарегистрируйте обработчик методом [placement.bind](../placement-bind.md), передайте код точки в `PLACEMENT`. Для `PAGE_BACKGROUND_WORKER` обязательно передайте `OPTIONS[errorHandlerUrl]`
3. Завершите установку приложения: до этого обработчик не вызывается
4. Вызовите точку: перейдите по ссылке `/marketplace/view/#APP_CODE#/` или откройте любую страницу Битрикс24
5. Разберите `PLACEMENT_OPTIONS`, чтобы получить контекст запуска
6. Если виджет должен открыть интерфейс приложения, используйте [методы JavaScript для виджетов](../bx24-widget-methods.md)

Обе точки регистрируются в единственном экземпляре: повторный `placement.bind` для того же приложения вернет ошибку `ERROR_PLACEMENT_MAX_COUNT`.

### PLACEMENT_OPTIONS

Значение `PLACEMENT_OPTIONS` передается как JSON-строка с контекстом вызова.

#|
|| **Точка встраивания** | **Ключи** | **Что в них приходит** ||
|| [REST_APP_URI](./app-url.md) | Ключи из `params` ссылки, `URI` | Параметры, которые приложение само задало в ссылке, и адрес страницы, с которой пользователь по ней перешел ||
|| [PAGE_BACKGROUND_WORKER](./background-worker.md) | `ID`, `URI` | Код точки встраивания и адрес страницы, на которой загрузился обработчик ||
|#

Ключ `URI` универсальный: он приходит любой точке встраивания и несет путь с query-строкой той страницы Битрикс24, с которой открыт виджет.

## Связь с другими объектами

**Интерфейс приложения.** Обе точки открывают приложение в собственном фрейме, поэтому дальше работают [методы JavaScript для виджетов](../bx24-widget-methods.md): `openApplication` открывает слайдер приложения, `closeApplication` закрывает его.

**Обмен сигналами.** `PAGE_BACKGROUND_WORKER` — единственная точка, которая работает без действия пользователя, поэтому через нее backend приложения передает сигнал в браузер механизмом [интерактивного взаимодействия](../../../settings/interactivity/index.md).

**Карточка звонка.** Приложения телефонии управляют карточкой звонка из фонового обработчика. Методы и события описаны в разделе [{#T}](../ui-interaction/page-background-worker/index.md).

## Типовые ошибки

#|
|| **Ошибка** | **Решение** ||
|| `placement.bind` возвращает `EMPTY_ERROR_HANDLER_URL` | Точка `PAGE_BACKGROUND_WORKER` требует адрес для сообщений об отключении. Передайте `OPTIONS[errorHandlerUrl]` ||
|| `placement.bind` возвращает `ERROR_PLACEMENT_MAX_COUNT` | Обработчик для этой точки уже зарегистрирован. Снимите старую регистрацию методом [placement.unbind](../placement-unbind.md) ||
|| Ссылка `/marketplace/view/#APP_CODE#/` открывает пустой слайдер | Проверьте, что установка приложения завершена и в ссылке указан код приложения, а не идентификатор регистрации обработчика ||
|| Фоновый обработчик перестал вызываться | Регистрация удаляется, если обработчик больше десяти раз за сутки грузился дольше пяти секунд. Битрикс24 сообщает об этом на адрес из `errorHandlerUrl` ||
|#
