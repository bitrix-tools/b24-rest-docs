# Коллекция смайлов IM_SMILES_SELECTOR

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

{% note warning " " %}

**DEPRECATED**

Встройка `IM_SMILES_SELECTOR` устарела с версии модуля `im 25.1600.0`. Смайлы заменили на [стикеры](https://helpdesk.bitrix24.ru/open/26987270/).

Метод [placement.bind](../placement-bind.md) код точки принимает, но в интерфейсе обработчик больше не вызывается: окно выбора смайлов заменено на новое, и вкладок приложений в нем нет. Страница оставлена как архивная справка для старых интеграций.

{% endnote %}

> Scope: [`placement`](../../scopes/permissions.md)

Раньше встройка добавляла свою вкладку в окно выбора смайлов, которое открывается из поля ввода сообщения. Приложение показывало в этой вкладке собственную коллекцию: свои наборы смайлов или подборку Giphy.

## Чем заменить

Приложениям, которым нужна кнопка рядом с полем ввода сообщения, подходит [{#T}](./textarea.md): точка живая и получает идентификатор диалога. Остальные точки мессенджера собраны в [обзоре раздела](./index.md).

Своей точки встраивания у стикеров нет, поэтому приложение не может добавить в интерфейс собственный набор стикеров.

## Что происходит при регистрации

Регистрация обработчика по-прежнему проходит, и точка остается видна в ответе [placement.get](../placement-get.md). Это нужно старым приложениям, которые зарегистрировали обработчик до замены смайлов на стикеры: их регистрация не ломает установку, но и не выводит ничего в интерфейсе.

Метод [placement.bind](../placement-bind.md) принимает для этой точки параметры `OPTIONS`: `extranet`, `role` и `context`, те же, что у [IM_CONTEXT_MENU](./context-menu.md). На поведение это не влияет, потому что обработчик не вызывается.
