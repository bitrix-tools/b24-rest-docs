# Файлы в Базе знаний 2.0: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Файлы в Базе знаний 2.0 привязываются к документам и используются как вложения в Markdown: изображения, видео и обычные файлы. Методы `note.file.*` помогают загрузить файл, получить его метаданные, узнать схему полей и вернуть блок Markdown для вставки в документ.

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [Битрикс24 База знаний 2.0: как создать и настроить](https://helpdesk.bitrix24.ru/open/28444346/)

Методы раздела относятся к REST 3.0. Особенности вызова и формат ответа новой версии API описаны в [обзоре REST 3.0](../../rest-v3.md).

{% endnote %}

## Как начать работу

1. Создайте документ методом [note.document.add](../document/note-document-add.md), если у вас еще нет страницы, к которой нужно привязать файл
2. Загрузите файл методом [note.file.add](./note-file-add.md) и сохраните возвращенный `id` или сразу `assetMarkdown`
3. Добавьте `assetMarkdown` к тексту документа и передайте результат в `markdown` метода [note.document.update](../document/note-document-update.md). Если нужен блок Markdown для ранее загруженного файла, получите его методом [note.file.get](./note-file-get.md)
4. Уточните состав и типы полей методами [note.file.field.list](./note-file-field-list.md) и [note.file.field.get](./note-file-field-get.md), если строите форму, таблицу или валидацию на своей стороне

## Ограничения и особенности

- Лимит относится к размеру файла после декодирования Base64. Положительное значение настройки `main.max_file_size` умножается на 1024; иначе лимит составляет 25 МиБ — 26 214 400 байт. При превышении метод `note.file.add` возвращает `NOTE_FILE_TOO_LARGE`
- Допустимые расширения перечислены в [параметре fileName метода note.file.add](./note-file-add.md#parameters). Проверка не учитывает регистр. Если расширение отсутствует или не разрешено, метод возвращает `NOTE_FILE_TYPE_NOT_ALLOWED`
- Для загрузки нужно право редактировать документ, для получения файла — право просматривать документ. Права могут быть получены через базу знаний или назначены на документ

## Связь с другими объектами

**Документы.** Файл привязан к конкретному [документу](../document/index.md). Для вызова [note.file.get](./note-file-get.md) нужны оба идентификатора: `id` файла и `documentId` документа.

**Базы знаний.** Документ входит в [базу знаний](../collection/index.md). Общий порядок работы с базами и документами описан в [обзоре Базы знаний 2.0](../index.md).
