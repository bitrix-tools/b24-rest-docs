Привязка — запись, которая связывает заказ с его источником. Методы `sale.tradeBinding.*` возвращают привязки и описание их полей. Создать или изменить привязку через них нельзя.

Источниками заказов бывают счета, документы реализации, сделки, дела и лендинги. Их список возвращают методы раздела [Источники заказов](../trade-platform/index.md).

> Быстрый переход: [все методы](#all-methods)

## Как начать работу

1. Получите список источников заказов методом [sale.tradePlatform.list](../trade-platform/sale-trade-platform-list.md)
2. Проверьте доступные поля привязки методом [sale.tradeBinding.getFields](./sale-trade-binding-get-fields.md)
3. Получите привязки заказов нужного источника методом [sale.tradeBinding.list](./sale-trade-binding-list.md)
4. Откройте данные нужного заказа методом [sale.order.get](../order/sale-order-get.md)

## Связь с другими объектами

С каждой привязкой связаны два объекта: источник заказа и заказ.

**Источник заказа.** Привязка ссылается на источник через поле `tradingPlatformId` — это `id` из ответа `sale.tradePlatform.list`.

**Заказ.** Привязка ссылается на заказ через поле `orderId`. Передайте это значение в параметр `id` метода `sale.order.get`, чтобы получить состав и статус заказа.

Метод `sale.order.get` сам возвращает привязки заказа в поле `tradeBindings`, поэтому источник известного заказа можно узнать без `sale.tradeBinding.list`.
