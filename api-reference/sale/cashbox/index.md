Когда вы продаете что-то через CRM, информация о покупке поступает в кассу. Касса формирует чек и отправляет:
- оператору фискальных данных для отчетности перед налоговой,
- клиенту по СМС или на электронную почту.

Чтобы добавить новую кассу, создайте предварительно обработчик кассы. Он свяжет Битрикс24 с вашим кассовым оборудованием или онлайн-сервисом. Затем добавьте и настройте кассу: укажите название, выберите обработчик и настройте фискализацию.

## Как начать работу

1. Создайте обработчик кассы методом [sale.cashbox.handler.add](./sale-cashbox-handler-add.md) или получите код существующего методом [sale.cashbox.handler.list](./sale-cashbox-handler-list.md).
2. Добавьте кассу методом [sale.cashbox.add](./sale-cashbox-add.md): передайте код обработчика, email для уведомлений и настройки кассы.
3. Проверьте список касс методом [sale.cashbox.list](./sale-cashbox-list.md). Новая касса создается неактивной, включите ее методом [sale.cashbox.update](./sale-cashbox-update.md) с `ACTIVE` = `Y`.
4. Принимайте данные чеков на `PRINT_URL` и передавайте результат печати методом [sale.cashbox.check.apply](./sale-cashbox-check-apply.md).
5. Чтобы удалить обработчик, сначала удалите его кассы методом [sale.cashbox.delete](./sale-cashbox-delete.md), затем вызовите [sale.cashbox.handler.delete](./sale-cashbox-handler-delete.md).

## Ограничения и особенности

- Методы `sale.cashbox.update` и `sale.cashbox.delete` работают только с кассами, подключенными через REST-обработчик. Метод `sale.cashbox.list` возвращает все кассы
- Приложение может изменять только свои обработчики и кассы на их основе
- Методы `update` объединяют переданный `SETTINGS` с сохраненным: непереданные настройки не меняются

## Связь касс с другими объектами

**Обработчик кассы.** Обработчик описывает ваш сервис печати чеков: адреса `PRINT_URL` и `CHECK_URL` и структуру настроек `SETTINGS.CONFIG`. Касса связана с обработчиком по коду: код обработчика из параметра `CODE` передается в `REST_CODE` метода [sale.cashbox.add](./sale-cashbox-add.md). Значения настроек кассы передаются в `SETTINGS` по структуре `CONFIG` обработчика.

**Оператор фискальных данных.** Код ОФД передается в параметре `OFD` кассы, настройки ОФД — в `OFD_SETTINGS`. Список кодов приведен на странице [sale.cashbox.add](./sale-cashbox-add.md).

**Чек.** Битрикс24 отправляет данные чека на `PRINT_URL` обработчика. Сервис возвращает `UUID` чека, а результат печати передает методом [sale.cashbox.check.apply](./sale-cashbox-check-apply.md) или отдает по запросу на `CHECK_URL`.
