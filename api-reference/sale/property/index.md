Свойства заказа — это поля, которые покупатель заполняет при оформлении заказа: имя, номер телефона, адрес доставки. У каждого типа плательщика будут свои свойства заказа. Описание полей — в справочнике [sale_order_property](../data-types.md#sale_order_property).

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [Как покупателю оформить заказ в интернет-магазине](https://helpdesk.bitrix24.ru/open/28841930/)

## Как начать работу со свойствами заказа

1. Получите тип плательщика методом [sale.persontype.list](../person-type/sale-person-type-list.md).
2. Получите группу свойств для этого типа плательщика методом [sale.propertygroup.list](../property-group/sale-property-group-list.md) или создайте ее методом [sale.propertygroup.add](../property-group/sale-property-group-add.md). Идентификатор группы обязателен при создании свойства.
3. Проверьте поля для нужного типа свойства методом [sale.property.getFieldsByType](./sale-property-get-fields-by-type.md).
4. Создайте свойство методом [sale.property.add](./sale-property-add.md).
5. Для свойства типа `ENUM` добавьте варианты методами [sale.propertyvariant.*](../property-variant/index.md).
6. Если свойство должно отображаться только в отдельных сценариях, настройте привязку методами [sale.propertyRelation.*](../property-relation/index.md).

## Типы свойств заказа

Основные типы свойства задаются в поле `type`:

- `STRING` — строка
- `Y/N` — да или нет
- `NUMBER` — число
- `ENUM` — список вариантов
- `FILE` — файл
- `DATE` — дата
- `LOCATION` — местоположение
- `ADDRESS` — адрес

Тип `ADDRESS` доступен при установленном модуле `location`.

## Особые свойства заказа

### LOCATION

Если для расчета доставки или налогов нужно местоположение покупателя, создайте свойство типа `LOCATION` и включите нужные опции:

- `isLocation` — чтобы рассчитывать стоимость доставки
- `isLocation4tax` — чтобы определять налоговые ставки

### STRING

Чтобы обозначить контактные данные покупателя, создайте свойства типа `STRING` и включите нужные опции:

- `isEmail` — использовать в качестве e-mail
- `isPhone` — использовать в качестве номера телефона

## Связь свойств заказа с другими объектами

**Типы плательщиков.** Определите, к какому виду клиентов относится покупатель: физическое или юридическое лицо. Для этого используйте методы [sale.persontype.*](../person-type/index.md).

**Группы свойств.** Привяжите свойство заказа к подходящей группе: личные данные или данные для доставки. Вы можете создать или изменить группы свойств с помощью методов [sale.propertygroup.*](../property-group/index.md).

**Варианты свойств.** Если вы создаете свойство заказа типа ENUM, укажите доступные варианты с помощью методов [sale.propertyvariant.*](../property-variant/index.md). Например, для свойства «Время доставки» укажите варианты «08:00-12:00», «12:00-16:00» и «16:00-20:00».

**Привязка свойства.** Задайте условия, при которых покупатель увидит конкретное свойство. Для этого привяжите свойство заказа к платежной системе, службе доставки, лендингу или торговой платформе методами [sale.propertyRelation.*](../property-relation/index.md). Например, покажите свойство «Станция метро» при выборе «Доставки курьером».

**Значения свойства.** Просмотрите или измените значения свойства конкретного заказа с помощью методов [sale.propertyvalue.*](../property-value/index.md).
