Табличная часть отгрузки — это список товаров, которые входят в отгрузку заказа. Каждый элемент связывает позицию корзины с отгрузкой и задает количество товара в поле `quantity`. Название и цена товара хранятся в позиции корзины, а не в элементе табличной части.

Методы `sale.shipmentitem.*` добавляют, изменяют, читают и удаляют элементы табличной части отгрузки. Поля элемента описаны в типе [sale_order_shipment_item](../data-types.md#sale_order_shipment_item).

## Связь табличной части отгрузки с другими объектами

**Отгрузка.** Элемент привязан к отгрузке через поле `orderDeliveryId`. Идентификатор отгрузки можно получить методом [sale.shipment.list](../shipment/sale-shipment-list.md).

**Заказ.** Отгрузка и позиция корзины должны принадлежать одному заказу. Список заказов можно получить методом [sale.order.list](../order/sale-order-list.md).

**Корзина.** Элемент ссылается на позицию корзины через поле `basketId`. Идентификатор позиции можно получить методом [sale.basketitem.list](../basket-item/sale-basket-item-list.md).

## Как распределяется количество товара {#quantity}

Количество товара из позиции корзины распределяется между отгрузками заказа. Товар, который не добавлен ни в одну отгрузку, числится в системной отгрузке. Методы [sale.shipment.*](../shipment/index.md) системную отгрузку не возвращают, а [sale.shipmentitem.list](./sale-shipment-item-list.md) возвращает и ее элементы. Метод [sale.shipmentitem.get](./sale-shipment-item-get.md) для элемента системной отгрузки возвращает пустой массив.

- Сумма `quantity` по всем отгрузкам не может превышать количество в позиции корзины
- Одна позиция корзины может входить в отгрузку только один раз
- `basketId` и `orderDeliveryId` после добавления не меняются. Чтобы перенести товар в другую отгрузку, удалите элемент и добавьте новый
- Элементы системной отгрузки нельзя изменить или удалить
- В отгрузке с `deducted` = `Y` нельзя добавлять и удалять товар и менять количество, можно изменить только `xmlId`

## Как начать работу

1. Получите идентификатор отгрузки методом [sale.shipment.list](../shipment/sale-shipment-list.md). Если отгрузки еще нет, создайте ее методом [sale.shipment.add](../shipment/sale-shipment-add.md).
2. Получите идентификатор позиции корзины методом [sale.basketitem.list](../basket-item/sale-basket-item-list.md).
3. Добавьте позицию корзины в отгрузку методом [sale.shipmentitem.add](./sale-shipment-item-add.md).
4. Проверьте состав отгрузки методом [sale.shipmentitem.list](./sale-shipment-item-list.md) с фильтром по `orderDeliveryId`.
5. Измените количество методом [sale.shipmentitem.update](./sale-shipment-item-update.md) или уберите товар из отгрузки методом [sale.shipmentitem.delete](./sale-shipment-item-delete.md).

## Формат ответа

- Методы добавления, изменения и получения возвращают элемент в `result.shipmentItem`
- Метод [sale.shipmentitem.delete](./sale-shipment-item-delete.md) возвращает `true` в `result`
- Метод [sale.shipmentitem.list](./sale-shipment-item-list.md) возвращает до 50 элементов за вызов в `result.shipmentItems`, общее число найденных — в `total`, значение `start` для следующей страницы — в `next`

При ошибке приходят поля `error` и `error_description`, полный перечень кодов — на странице каждого метода.
