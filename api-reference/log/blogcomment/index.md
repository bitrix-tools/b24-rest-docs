# Комментарии к сообщениям Ленты: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга

Лента новостей — общая лента сообщений сотрудников Битрикс24, похожая на внутреннюю соцсеть. Под сообщением пользователи оставляют комментарии: обсуждают его, делятся мнением, уточняют детали. К комментарию можно прикрепить файлы.

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [Что такое Лента в Битрикс24](https://helpdesk.bitrix24.ru/open/18634548/)

## Связь комментариев с другими объектами

**Сообщение Ленты новостей.** Комментарий привязан к сообщению по идентификатору `POST_ID`. Идентификатор сообщения вернет метод [log.blogpost.get](../log-blogpost-get.md).

**Пользователь.** Комментарий привязан к пользователю по идентификатору `USER_ID`. Идентификатор пользователя вернут методы [user.get](../../user/user-get.md) и [user.search](../../user/user-search.md).

**Файлы.** Чтобы прикрепить файл к комментарию, передайте в параметре `FILES` массив из имени файла и его содержимого в кодировке `Base64`, то есть строкой. Сведения о прикрепленном файле вернет метод [disk.attachedObject.get](../../disk/attached-object/disk-attached-object-get.md).

## Как начать работу

1. Получите идентификатор сообщения `POST_ID` методом [log.blogpost.get](../log-blogpost-get.md)
2. Добавьте комментарий методом [log.blogcomment.add](./log-blogcomment-add.md)
3. Получите комментарии к сообщению методом [log.blogcomment.get](./log-blogcomment-get.md). Комментарии одного пользователя ко всем сообщениям вернет метод [log.blogcomment.user.get](./log-blogcomment-user-get.md)
4. Удалите комментарий методом [log.blogcomment.delete](./log-blogcomment-delete.md). Удалить его может автор комментария или администратор
