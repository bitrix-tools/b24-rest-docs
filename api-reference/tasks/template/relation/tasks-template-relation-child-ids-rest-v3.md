# Получить идентификаторы дочерних шаблонов v 3.0 tasks.template.relation.child.ids

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

> Scope: [`tasks`](../../../scopes/permissions.md)
>
> Кто может выполнять метод: пользователь с правом чтения каждого шаблона из запроса

{% note info "" %}

Метод относится к REST 3.0. Особенности вызова и формат ответа новой версии API описаны в [обзоре REST 3.0](../../../rest-v3.md).

{% endnote %}

Метод `tasks.template.relation.child.ids` возвращает идентификаторы дочерних шаблонов для каждого переданного шаблона.

## Параметры метода

{% include [Сноска об обязательных параметрах](../../../../_includes/required.md) %}

#|
|| **Название**
`тип` | **Описание** ||
|| **templateIds***
[`integer[]`](../../../data-types.md) | Массив идентификаторов шаблонов, для которых нужно получить дочерние шаблоны. Передайте от одного до 20 уникальных идентификаторов, повторы метод не учитывает.

Идентификатор шаблона можно получить при [создании шаблона](../tasks-template-add-rest-v3.md) или методом [получения списка шаблонов](../tasks-template-list-rest-v3.md) ||
|#

{% note info "" %}

Метод возвращает только дочерние шаблоны первого уровня. Чтобы получить следующий уровень, передайте в `templateIds` идентификаторы из `subTemplateIds`. Дочерние шаблоны, которые пользователь не может читать, в ответ не попадают.

{% endnote %}

- Python

    У методов `tasks.template.relation.*` нет готовых оберток в `b24pysdk`, и SDK отправляет в REST 3.0 только методы из списка `Config().api_v3_methods`. Добавьте метод в этот список и вызовите его через `bitrix_token.call_method` с `prefer_version=3`.

    ```python
    from b24pysdk import Config
    from b24pysdk.errors import BitrixSDKException
    from b24pysdk.errors.v3 import BitrixAPIError

    method = "tasks.template.relation.child.ids"
    Config().configure(api_v3_methods=Config().api_v3_methods | {method})

    try:
        response = bitrix_token.call_method(
            api_method=method,
            params={
                "templateIds": [117, 119],
            },
            prefer_version=3,
        )
        for item in response["result"]["items"]:
            print(item["id"], item["subTemplateIds"])
    except BitrixAPIError as error:
        print(
            "Ошибка Bitrix API",
            f"code: {error.code}",
            f"message: {error.error.message}",
            sep="\n",
        )
    except BitrixSDKException as error:
        print(f"Ошибка Bitrix SDK: {error.message}")
    except Exception as error:
        print(f"Непредвиденная ошибка: {error}")
    ```

### Возможные коды ошибок

#### Ошибки валидации запроса

HTTP-статус: **400**

Код ошибки: `BITRIX_REST_V3_EXCEPTION_VALIDATION_REQUESTVALIDATIONEXCEPTION`

#|
|| **Поле** | **Описание ошибки** | **Как исправить** ||
|| `templateIds` | Обязательное поле `templateIds` не указано | Передайте непустой массив идентификаторов шаблонов ||
|| `templateIds` | В поле `templateIds` требуется тип данных `integer` для такого запроса | Передайте идентификаторы числами, а не строками ||
|| `templateIds` | В поле `templateIds` требуется тип данных `array` для такого запроса | Передайте массив, а не одно число. Если ошибка приходит для массива, проверьте его размер: в одном запросе допустимо не больше 20 уникальных идентификаторов ||
|#

#### Шаблон не найден

HTTP-статус: **404**

Код ошибки: `BITRIX_TASKS_V2_INFRASTRUCTURE_REST_EXCEPTION_TEMPLATE_NOTFOUNDEXCEPTION`

#|
|| **Поле** | **Описание ошибки** | **Как исправить** ||
|| `templateIds` | Запись с ID = `999999` не найдена | Проверьте идентификаторы методом [tasks.template.get](../tasks-template-get-rest-v3.md). Если хотя бы один шаблон не найден, метод не возвращает данные и по остальным ||
|#

#### Ошибка доступа

HTTP-статус: **403**

Код ошибки: `BITRIX_REST_V3_EXCEPTION_ACCESSDENIEDEXCEPTION`

#|
|| **Поле** | **Описание ошибки** | **Как исправить** ||
|| `-` | Доступ запрещен | Проверьте, что у пользователя есть право чтения каждого шаблона из `templateIds`. Если хотя бы один шаблон недоступен, метод не возвращает данные и по остальным ||
|#
