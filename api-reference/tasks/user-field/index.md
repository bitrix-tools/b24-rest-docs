# Пользовательские поля в задачах: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга

{% endnote %}

В задаче есть набор системных полей: исполнитель, наблюдатели, крайний срок выполнения, теги и так далее. Если системных полей недостаточно, вы можете создать собственные — пользовательские поля. Пользовательские поля позволяют хранить информацию в различных форматах данных: строка, число, дата со временем и да/нет.

## Как начать работу

1. Получите доступные типы пользовательских полей методом [task.item.userfield.gettypes](./task-item-user-field-get-types.md)
2. Получите описание полей для настройки пользовательского поля методом [task.item.userfield.getfields](./task-item-user-field-get-fields.md)
3. Создайте пользовательское поле методом [task.item.userfield.add](./task-item-user-field-add.md)
4. Проверьте созданное поле методом [task.item.userfield.get](./task-item-user-field-get.md) или получите список полей методом [task.item.userfield.getlist](./task-item-user-field-get-list.md)
5. Измените параметры поля методом [task.item.userfield.update](./task-item-user-field-update.md), если нужно скорректировать название, обязательность или множественность
6. Удалите поле методом [task.item.userfield.delete](./task-item-user-field-delete.md), если оно больше не нужно

## Особенности пользовательских полей

При создании пользовательского поля методом [task.item.userfield.add](./task-item-user-field-add.md) в названии поля `FIELD_NAME` обязательно использовать префикс `UF_`. Если не указать префикс, система автоматически добавит его в начало названия.
Получить список всех пользовательских полей задач можно методом [task.item.userfield.getlist](./task-item-user-field-get-list.md). В списке будет три системных поля задач для связи с другими объектами:

- `UF_CRM_TASK` — с объектами CRM
- `UF_MAIL_MESSAGE` — с письмом Почты
- `UF_TASK_WEBDAV_FILES` — с файлами Диска

Они созданы на основе пользовательских полей, поэтому есть в списке. Подробнее о связях задачи с другими объектами — в статье [Задачи: обзор методов](../index.md).

## Связь с другими объектами

**Задача.** Пользовательские поля добавляются в карточку задачи и доступны в методах работы с задачами. Значения пользовательских полей передаются в массиве полей задачи, например `UF_CRM_TASK` или собственное поле с префиксом `UF_`.

**CRM.** Системное поле `UF_CRM_TASK` связывает задачу с объектами CRM. Чтобы привязать объект, укажите его идентификатор с префиксом, например `C_3` для контакта или `D_27` для сделки. Идентификаторы элементов CRM можно получить методом [crm.item.list](../../crm/universal/crm-item-list.md).

**Диск.** Системное поле `UF_TASK_WEBDAV_FILES` связывает задачу с файлами Диска. Для прикрепления файлов к уже созданной задаче используйте метод [tasks.task.files.attach](../tasks-task-files-attach.md).
