# Цветовые темы страницы

Поле `THEME_CODE` задает готовую цветовую палитру страницы. В таблице приведены доступные коды и общие цветовые характеристики тем.

Задать значение `THEME_CODE` можно при создании и обновлении страницы через методы [landing.landing.add](./methods/landing-landing-add.md) и [landing.landing.update](./methods/landing-landing-update.md).

Получить текущее значение `THEME_CODE` можно через метод [landing.landing.getadditionalfields](./methods/landing-landing-get-additional-fields.md), если поле заполнено.

## Условия доступа

Для вызова методов нужен scope [`landing`](../../scopes/permissions.md). Необходимые права зависят от действия:

- для `landing.landing.add` нужно право «редактирование» сайта
- для `landing.landing.update` нужно право «изменение настроек» сайта
- для `landing.landing.getadditionalfields` нужно право «просмотр» сайта

## Как выбрать цвет

Выберите способ настройки цвета:

- для готовой палитры передайте один из кодов таблицы в `THEME_CODE`
- для собственного цвета передайте `THEME_USE = Y` и `THEME_COLOR` в формате `#RRGGBB`
- настройки шрифтов передавайте отдельно в полях `THEMEFONTS_*`

Цветовая тема меняет цвет кнопок и некоторых других элементов. Точный набор элементов зависит от блока.

## Как передать код темы

Для метода `landing.landing.update` передайте `THEME_CODE` в объекте `fields.ADDITIONAL_FIELDS`:

```json
{
    "lid": 349,
    "fields": {
        "ADDITIONAL_FIELDS": {
            "THEME_CODE": "2business"
        }
    }
}
```

При создании страницы передавайте тот же объект `fields.ADDITIONAL_FIELDS` в метод [landing.landing.add](./methods/landing-landing-add.md).

## Что важно знать

Блоки с заранее заданным цветовым стилем могут не измениться после выбора темы.
