# Интеграция КЭДО с системами кадрового учета: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

В Битрикс24 КЭДО можно настроить обмен данными с внешней системой кадрового учета. Интеграция помогает автоматизировать подписание кадровых документов, сократить ручной ввод данных и снизить вероятность ошибок.

С интеграцией Битрикс24 КЭДО и системы кадрового учета можно:

- связывать компании Битрикс24 с компаниями в системе кадрового учета
- синхронизировать сотрудников и сопоставлять их с пользователями Битрикс24
- передавать значения полей системы кадрового учета для заполнения документов КЭДО
- обновлять задания синхронизации и отслеживать их статус

Методы работают только в контексте авторизации [приложения](../../../settings/app-installation/index.md). Для большинства методов пользователь должен быть администратором.

## Интеграция с 1С

Интеграция Битрикс24 КЭДО + 1С настраивается в интерфейсе Битрикс24. Методы `humanresources.hcmlink.*` позволяют управлять данными интеграции через HCM Link: компаниями, сотрудниками, сопоставлениями и значениями полей.

## Как связаны sign.b2e и humanresources.hcmlink

`sign.b2e` управляет документами КЭДО: отправляет документ на подписание, получает документ, возвращает провайдеров подписи и списки подписанных документов.

`humanresources.hcmlink` обслуживает интеграцию КЭДО с системой кадрового учета. Эти методы создают связку с компанией в системе кадрового учета, загружают сотрудников, возвращают сопоставленных сотрудников и передают значения полей, которые затем используются при заполнении документов КЭДО.

## Основной сценарий обмена

**Подключение компании.** Приложение добавляет компанию из системы кадрового учета методом [humanresources.hcmlink.company.add](./humanresources-hcmlink-company-add.md). В параметре `fields.crmCompanyId` передается идентификатор компании CRM, а в `fields.fields` — поля системы кадрового учета, которые будут доступны для заполнения документов КЭДО.

**Синхронизация сотрудников.** Когда в интерфейсе запускается синхронизация, приложение получает событие `OnHumanResourcesHcmLinkEmployeeListRequested` с идентификатором задания `jobId`, кодом компании `company` и датой запроса. После этого приложение передает список сотрудников методом [humanresources.hcmlink.employee.set](./humanresources-hcmlink-employee-set.md) и завершает задание методом [humanresources.hcmlink.job.update](./humanresources-hcmlink-job-update.md).

**Сопоставление пользователей.** После сопоставления пользователей Битрикс24 с физическими лицами из системы кадрового учета приложение получает событие `OnHumanResourcesHcmLinkEmployeeListMapped`. По этому событию нужно запросить измененные сопоставления методом [humanresources.hcmlink.employee.list](./humanresources-hcmlink-employee-list.md). Передавайте параметр `updatedAt`, чтобы получить только изменения, а не весь список сотрудников.

**Запрос значений для документов.** При отправке документа КЭДО Битрикс24 запрашивает значения полей системы кадрового учета событием `OnHumanResourcesHcmLinkFieldValueRequested`. В событии приходит `jobId`, код компании, список сотрудников и список полей. Приложение передает значения методом [humanresources.hcmlink.field.value.set](./humanresources-hcmlink-field-value-set.md), затем обновляет задание методом [humanresources.hcmlink.job.update](./humanresources-hcmlink-job-update.md).

**Получение подписанного документа.** После подписания документа, связанного с HCM Link, приложение получает событие [OnSignHcmLinkB2eDocumentSigned](../events/on-sign-hcm-link-b2e-document-signed.md). В событии приходит идентификатор участника подписания `data.id`. По этому идентификатору можно получить данные подписанного файла методом [sign.b2e.hcmlink.document.get](../sign-b2e-hcmlink-document-get.md).

## Идентификаторы сотрудников

В обмене используются два идентификатора сотрудника из системы кадрового учета:

- `person` — код физического лица в системе кадрового учета
- `employee` — код сотрудника в системе кадрового учета

Одно физическое лицо может быть связано с несколькими сотрудниками в одной компании, например если у человека несколько должностей. Битрикс24 сопоставляет пользователя с `person`, а значения полей для документов запрашивает по `employee`.

## Связанные сценарии КЭДО

**Зарплата и отпуск.** Для страниц расчетных листков и остатков отпусков приложение регистрирует встройку `HCMLINK_SALARY_VACATION`. Метод [humanresources.hcmlink.company.user.list](./humanresources-hcmlink-company-user-list.md) возвращает компании, в которых текущий пользователь сопоставлен с физическим лицом из системы кадрового учета.

**ПИН-код и расчетные данные.** Для запросов ПИН-кода и данных по зарплате и отпускам используются события `OnHumanResourcesHcmLinkPinRequested` и `OnHumanResourcesHcmLinkSalaryVacationRequested`. Ответ по таким заданиям передается методом [humanresources.hcmlink.field.value.set](./humanresources-hcmlink-field-value-set.md).

## Связь с другими объектами

**Компания CRM.** Метод `humanresources.hcmlink.company.add` связывает компанию из системы кадрового учета с компанией CRM через параметр `fields.crmCompanyId`. Идентификатор компании можно получить методом [crm.item.list](../../crm/universal/crm-item-list.md) с параметром `entityTypeId = 4` и фильтром `isMyCompany = Y`. В интерфейсе такие компании находятся в `CRM > Еще > Настройки > Мои реквизиты`. Этот идентификатор используется в методах КЭДО, когда документ отправляется от имени компании.

**Сотрудник Битрикс24.** Метод `humanresources.hcmlink.employee.set` связывает сотрудника из системы кадрового учета с пользователем Битрикс24 через `data[].userId`. После сопоставления документы КЭДО можно отправлять по `employeeId` или `employeeCode` в методе [sign.b2e.document.send](../sign-b2e-document-send.md).

**Поля системы кадрового учета.** Список доступных полей передается при добавлении или обновлении компании. Коды этих полей используются в событиях запроса значений и в методе [humanresources.hcmlink.field.value.set](./humanresources-hcmlink-field-value-set.md).
