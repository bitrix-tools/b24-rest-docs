# Сообщения форума: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Сообщение форума — это комментарий к событию календаря, отчету о рабочем времени, фотографии, странице вики или элементу универсального списка, а также сообщение форума. Метод `forum.message.delete` удаляет сообщение по идентификатору.

> Быстрый переход: [все методы](#all-methods)

{% note info "" %}

Метод раздела относится к REST 3.0. Особенности вызова и формат ответа новой версии API описаны в [обзоре REST 3.0](../../rest-v3.md).

{% endnote %}

## Пользовательские поля сообщения

Пользовательские поля сообщений создают и настраивают методы [forum.message.field.custom.*](../userfield/index.md). Полный список пользовательских полей возвращает [forum.message.field.custom.list](../userfield/forum-message-field-custom-list.md).

## Удаление сообщения

Метод [forum.message.delete](./forum-message-delete.md) удаляет сообщение по идентификатору:

- удалить сообщение может его автор или администратор
- вместе с сообщением удаляется связанная запись или комментарий в [Ленте новостей](../../log/index.md)
- для несуществующего идентификатора метод тоже возвращает `true`, поэтому ответ не подтверждает, что сообщение существовало

В REST 3.0 нет метода, который возвращает сообщения форума, поэтому идентификатор сообщения нужно получить вне методов раздела. Комментарии задач хранятся в чате задачи, а не в форуме, и этим методом не удаляются.
