# Удалить пользовательское поле сообщений форума forum.message.field.custom.delete

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

> Scope: [`forum`](../../scopes/permissions.md)
>
> Кто может выполнять метод: любой пользователь

{% note info "" %}

Метод относится к REST 3.0. Особенности вызова и формат ответа новой версии API описаны в [обзоре REST 3.0](../../rest-v3.md).

{% endnote %}

Метод `forum.message.field.custom.delete` удаляет пользовательское поле сообщений форума вместе с его значениями во всех сообщениях.

## Параметры метода

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

#|
|| **Название**
`тип` | **Описание** ||
|| **id***
[`integer`](../../data-types.md) | Идентификатор пользовательского поля, которое нужно удалить.

Идентификатор можно получить методом [forum.message.field.custom.list](./forum-message-field-custom-list.md).

Удаление по `filter` не поддерживается: такой запрос завершается внутренней ошибкой ||
|#

### Возможные коды ошибок

#### Ошибки валидации запроса

Код ошибки: `BITRIX_REST_V3_EXCEPTION_VALIDATION_REQUESTVALIDATIONEXCEPTION`

#|
|| **Поле** | **Описание ошибки** | **Как исправить** ||
|| `-` | Не заполнено значение хотя бы одного обязательного поля: id, filter | Передайте `id` пользовательского поля ||
|| `-` | Должно быть передано только одно из значений: id, filter | Передайте `id` пользовательского поля ||
|#

#### Поле не найдено

Код ошибки: `BITRIX_REST_V3_EXCEPTION_ENTITYNOTFOUNDEXCEPTION`

#|
|| **Поле** | **Описание ошибки** | **Как исправить** ||
|| `id` | Запись с ID = `#ID#` не найдена | Поля с таким `id` нет или оно уже удалено. Проверьте идентификатор методом [forum.message.field.custom.list](./forum-message-field-custom-list.md) ||
|#

#### Внутренняя ошибка

HTTP-статус: **500**

Ответ приходит в формате старой версии API: `{"error":"INTERNAL_SERVER_ERROR","error_description":"Internal server error"}`.

#|
|| **Поле** | **Описание ошибки** | **Как исправить** ||
|| `-` | Internal server error | В запросе передан `filter`. Передайте `id` пользовательского поля ||
|#
