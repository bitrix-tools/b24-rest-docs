Рабочий график задает правила рабочего дня сотрудников, например самое позднее начало дня и минимальную продолжительность работы. Получить настройки графика можно методом [timeman.schedule.get](./timeman-schedule-get.md).

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [рабочие графики](https://helpdesk.bitrix24.ru/open/17937890/)

## Как начать работу

1. Посмотрите идентификатор рабочего графика в интерфейсе Битрикс24
2. Получите настройки графика методом [timeman.schedule.get](./timeman-schedule-get.md)
3. Используйте полученные настройки при расчете рабочего времени, смен или проверке доступности сотрудника

## Идентификатор рабочего графика

Идентификатор рабочего графика `id` можно посмотреть в интерфейсе Битрикс24 на странице *Сотрудники > Время и отчеты > Рабочие графики*.

Передайте `id` в метод [timeman.schedule.get](./timeman-schedule-get.md), чтобы получить настройки графика, смены, календарь и правила нарушений.

## Связь с другими объектами

С графиком связаны рабочий день сотрудника и записи о рабочем времени.

**Рабочий день.** Методы [рабочего дня](../base/index.md) открывают, приостанавливают и закрывают рабочий день сотрудника. Ограничения из графика возвращает метод [timeman.settings](../base/timeman-settings.md):
- `UF_TM_MAX_START` — самое позднее начало дня
- `UF_TM_MIN_FINISH` — самое раннее окончание дня
- `UF_TM_MIN_DURATION` — минимальная продолжительность рабочего дня

Поле `UF_TM_FREE` показывает, работает ли сотрудник по свободному графику.

**Записи о рабочем времени.** Записи о рабочих интервалах сотрудника возвращает метод [timeman.record.list](../record/timeman-record-list.md). В ответе нет графика, по которому работал сотрудник.
