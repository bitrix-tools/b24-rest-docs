# Запустить спринт tasks.api.scrum.sprint.start

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

> Scope: [`task`](../../../scopes/permissions.md)
>
> Кто может выполнять метод: владелец или модератор Скрама, администратор Битрикс24

Метод `tasks.api.scrum.sprint.start` запускает спринт.

Запустить можно только спринт в статусе `planned`, в котором есть хотя бы одна незавершенная задача. В Скраме может быть только один активный спринт. Если в Скраме уже есть спринт в статусе `active`, сначала завершите его методом [tasks.api.scrum.sprint.complete](./tasks-api-scrum-sprint-complete.md).

При запуске спринта колонки активного спринта и роботы будут перенесены из предыдущего завершенного спринта, если он есть.

Задачи спринта будут добавлены в канбан активного спринта. Если в спринте в этот момент были завершенные задачи, они будут перенесены в бэклог.

## Обработка ошибок

HTTP-статус: **400**

```json
{
    "error": 0,
    "error_description": "Sprint not found"
}
```

{% include notitle [обработка ошибок](../../../../_includes/error-info.md) %}

### Возможные коды ошибок

#|
|| **Статус** | **Код** | **Описание** | **Значение** ||
|| `400` | `0` | `Sprint id not found` | В параметре `id` передан `0` ||
|| `400` | `0` | `Access denied` | Пользователь не владелец и не модератор Скрама или у него нет доступа к задачам Скрама ||
|| `400` | `0` | `Sprint not found` | Спринт с указанным `id` не найден ||
|| `400` | `0` | `Sprint must be planned` | Спринт не в статусе `planned`: он уже запущен или завершен ||
|| `400` | `0` | `Unable to start sprint` | В Скраме уже есть активный спринт или в спринте нет незавершенных задач ||
|| `400` | `100` | `Could not find value for parameter {id}` | Не передан параметр `id` ||
|| `400` | `100` | `Invalid value {stringValue} to match with parameter {id}. Should be value of type int` | Параметр `id` не является числом ||
|#
