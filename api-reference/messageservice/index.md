# Провайдеры сообщений: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Провайдеры сообщений — это сервисы для интеграции с Битрикс24. Они позволяют отправлять сообщения клиентам. Каналами связи могут быть СМС и другие системы, которые распознают получателя по номеру телефона.

{% note info "" %}

Методы раздела работают только в контексте [приложения](../../settings/app-installation/index.md). Провайдер регистрируется на конкретное приложение, и это же приложение получает сообщения в свой обработчик.

{% endnote %}

> Быстрый переход: [все методы](#all-methods)

## Как начать работу

1. Зарегистрируйте провайдер методом [messageservice.sender.add](./messageservice-sender-add.md). Передайте код провайдера `CODE`, тип `TYPE` со значением `SMS`, название `NAME` и адрес обработчика `HANDLER`. Регистрировать, менять и удалять провайдеры может только администратор.
2. Дождитесь отправки сообщения. Когда сотрудник отправляет сообщение из карточки CRM или из бизнес-процесса, Битрикс24 обращается к адресу из `HANDLER` и передает данные сообщения: номер получателя, текст и уникальный идентификатор `message_id`. Полный состав данных описан на странице метода [messageservice.sender.add](./messageservice-sender-add.md#handler).
3. Отправьте сообщение на стороне своего сервиса.
4. Обновите статус доставки методом [messageservice.message.status.update](./messageservice-message-status-update.md). Передайте код провайдера `CODE`, полученный `message_id` в параметре `MESSAGE_ID` и новый статус `STATUS`. Статус чужого сообщения может обновить только администратор.

Проверить, какие провайдеры уже зарегистрированы приложением, можно методом [messageservice.sender.list](./messageservice-sender-list.md). Изменить название, описание или адрес обработчика — методом [messageservice.sender.update](./messageservice-sender-update.md), удалить провайдер — методом [messageservice.sender.delete](./messageservice-sender-delete.md).

## Связь с другими объектами

**CRM.** Сообщение отправляют из карточки CRM. Обработчик приложения получает параметр `module_id` со значением `crm` и массив `bindings` с привязками сообщения к объектам CRM.

**Бизнес-процессы.** Сообщение отправляется автоматически из действия бизнес-процесса или робота CRM. Провайдер указывают в настройках бизнес-процесса только через интерфейс Битрикс24. Обработчик приложения получает параметр `module_id` со значением `bizproc`, а также идентификаторы бизнес-процесса и документа.
