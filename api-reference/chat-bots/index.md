# Бот-платформа: обзор раздела

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Чат-боты в Битрикс24 отвечают в чатах, обрабатывают команды и события мессенджера, работают с файлами. Для новой разработки предназначена бот-платформа `imbot.v2`, для существующих интеграций сохранены устаревшие методы `imbot.*`.

> Быстрый переход: [как выбрать раздел](#choose)

## Что умеют чат-боты в Битрикс24

Чат-боты могут:

- отправлять и изменять сообщения в чатах
- получать события и реагировать на действия пользователей
- работать со слэш-командами
- загружать и скачивать файлы
- управлять групповыми чатами и участниками
- использовать клавиатуры, вложения и другие элементы интерфейса

## Актуальная версия API {#v2}

[Чат-боты 2.0](./chat-bots-v2/index.md) — основной раздел для новой разработки. Он включает:

- бот-платформу `imbot.v2` для регистрации и управления ботами
- методы `im.v2` для чтения событий и работы с чатом от имени пользователя, без регистрации бота
- новые методы для работы с чатами, сообщениями, файлами, командами и интерфейсом

Для нового бота используйте этот раздел.

{% note info "" %}

Если интеграция уже работает в проде или использует новые поля и методы, сначала проверьте [Журнал изменений API imbot.v2](./chat-bots-v2/change-log.md). Записи в нем расположены от новых к старым.

{% endnote %}

## Как начать работу

1. Выберите способ [авторизации](./chat-bots-v2/index.md#auth) — вебхук или OAuth — и посмотрите [формат ответа](./chat-bots-v2/index.md#format-otveta) методов в обзоре Чат-ботов 2.0
2. Чтобы увидеть путь целиком на живом примере, пройдите [быстрый старт](./chat-bots-v2/quick-start.md): регистрация, прием события, ответ в чат
3. В своем приложении зарегистрируйте бота методом [imbot.v2.Bot.register](./chat-bots-v2/imbot.v2/bots/bot-register.md) — он возвращает идентификатор бота
4. Отправьте сообщение от имени бота методом [imbot.v2.Chat.Message.send](./chat-bots-v2/imbot.v2/messages/chat-message-send.md)
5. Уточните состав параметров запроса для вебхука и OAuth и порядок обновления токена в статье [Как вызывать методы чат-бота 2.0 и обновлять токен авторизации](./send-command.md)

## Устаревшие методы {#outdated}

[Устаревшее API](./outdated/index.md) содержит документацию по предыдущей версии методов `imbot.*`, `imbot.chat.*`, `imbot.dialog.get`, `imbot.message.*`, `imbot.command.*` и связанным событиям.

Эти методы оставлены для поддержки существующих интеграций. Для новых решений используйте [Чат-боты 2.0](./chat-bots-v2/index.md).
