# Файлы: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Методы позволяют загружать файлы в чат от имени бота и получать ссылку на скачивание уже загруженного файла.

> Быстрый переход: [все методы](#all-methods)

## Порядок работы с файлом {#how-to-start}

1. Загрузите файл методом [imbot.v2.File.upload](./file-upload.md). Метод объединяет три шага устаревшего API в один вызов: загружает файл на Диск, прикрепляет его к чату и отправляет сообщение.
2. Сохраните из ответа `result.file.id` — это ID файла на Диске, и `result.messageId` — ID созданного сообщения с файлом.
3. Чтобы выдать пользователю или внешней системе ссылку на файл, вызовите [imbot.v2.File.download](./file-download.md), передав этот ID в параметре `fileId`.

Файл всегда загружается в конкретный диалог: адресат задается параметром `dialogId` — [Формат dialogId](../../index.md#dialog-id). Описание полей объекта File — [Объекты и поля](../../entities.md#file).

Оба метода появились только в `imbot.v2`. В устаревшем API те же действия выполнялись тремя отдельными вызовами: загрузка файла на Диск, прикрепление к чату и отправка сообщения. Полная таблица соответствия версий — [Миграция с imbot на imbot.v2](../../migration.md).

## Ограничения {#limits}

#|
|| **Ограничение** | **Значение** ||
|| Максимальный размер файла | 100 МБ ||
|| Формат передачи содержимого | Строка Base64 в `fields.content`, без префикса `data:*/*;base64,` ||
|| Текст сообщения вместе с файлом | Необязательный параметр `fields.message` ||
|#

Как подготовить содержимое файла — [Как загружать файлы](../../../../files/how-to-upload-files.md).

## Связь с другими объектами {#relations}

**Бот.** Файл загружается от имени зарегистрированного бота: в вызовах передается `botId`, а при авторизации через вебхук — еще и `botToken` — [Боты](../bots/index.md).

**Сообщения.** Загрузка файла создает сообщение в чате, поэтому отдельно вызывать [imbot.v2.Chat.Message.send](../messages/chat-message-send.md) не нужно. Работа с этим сообщением дальше идет обычными методами группы [Сообщения](../messages/index.md).

**Вложения.** Если нужно оформить файл как структурированную карточку, а не как обычное вложение сообщения, используйте [блок с файлами в ATTACH](../messages/attachments/block-collections/files.md).

**Файлы от имени пользователя.** Те же операции без регистрации бота выполняют методы [im.v2.File.upload и im.v2.File.download](../../im.v2/files/index.md) — они работают от имени текущего пользователя и не требуют `botId`.
