# Интерфейс чата: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Методы управляют элементами интерфейса чата от имени бота: индикатором действия и доступностью поля ввода.

> Быстрый переход: [все методы](#all-methods)

## Когда использовать методы раздела {#when-to-use}

#|
|| **Задача** | **Метод** | **Как это выглядит у пользователя** ||
|| Показать, что бот работает над ответом, пока идет долгая обработка | [imbot.v2.Chat.InputAction.notify](./chat-input-action-notify.md) | В шапке чата появляется индикатор действия — стандартное «печатает» или один из статусов агента, например «Агент ищет информацию...» ||
|| Провести пользователя по шагам сценария и не дать отправить произвольный текст | [imbot.v2.Chat.TextField.enabled](./chat-text-field-enabled.md) | Поле ввода отключается, пользователь отвечает только кнопками клавиатуры ||
|#

Текст индикатора выбирается кодом `statusMessageCode` — список доступных кодов приведен на странице [imbot.v2.Chat.InputAction.notify](./chat-input-action-notify.md#status-codes). Если код не указан, показывается стандартный индикатор «печатает».

## Ограничения {#limits}

#|
|| **Ограничение** | **Значение** ||
|| Длительность индикатора действия | 1–600 секунд. Если `duration` не указан, значение определяет сервер ||
|| Доступ к методам раздела | Проверяется по членству бота в чате: `ACCESS_DENIED` возвращается, если бот не является участником указанного диалога ||
|| Типы чатов | Оба метода работают и в групповых, и в личных чатах с ботом ||
|#

Адресат задается параметром `dialogId` — [Формат dialogId](../../index.md#dialog-id).

## Связь с другими объектами {#relations}

**Бот.** Методы выполняются от имени зарегистрированного бота: в вызовах передается `botId`, а при авторизации через вебхук — еще и `botToken` — [Боты](../bots/index.md).

**Сообщения.** Индикатор действия обычно показывают между получением события и отправкой ответа методом [imbot.v2.Chat.Message.send](../messages/chat-message-send.md) — [Сообщения](../messages/index.md).

**Клавиатуры.** Отключенное поле ввода обычно сочетают с кнопками: пользователь продолжает сценарий нажатием, а не текстом — [Работа с клавиатурами](../messages/message-keyboards.md).
