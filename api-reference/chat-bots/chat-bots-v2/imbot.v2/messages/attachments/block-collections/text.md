# Блок с текстом MESSAGE

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../../../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../../../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Блок `MESSAGE` выводит текстовую часть вложения: заголовок, пояснение или комментарий. Блок передается элементом массива `BLOCKS` вложения — общие правила и лимиты описаны на странице [Вложения в сообщениях ATTACH](../index.md#limits).

Для пар «название — значение» используйте блок [GRID](./grid.md), для отдельной карточки ссылки с описанием и превью — блок [LINK](./links.md).

## Поддерживаемые BB-коды {#bb-codes}

Коды из таблицы работают в веб-клиенте. Мобильное приложение в блоках вложения разбирает только упоминания, действия и перенос строки, остальные коды выводит как текст. Регистр тегов не важен: `[B]` и `[b]` равнозначны.

#|
|| **Код** | **Назначение** | **Пример записи** | **Мобильное приложение** ||
|| `USER` | Упоминание пользователя со ссылкой на профиль в чате | `[USER=1]Иван Иванов[/USER]` | Да ||
|| `CHAT` | Ссылка на чат | `[CHAT=456]Отдел продаж[/CHAT]` | Да ||
|| `SEND` | Кликабельное действие «отправить текст в чат» | `[SEND=/start]Начать[/SEND]` | Да ||
|| `PUT` | Кликабельное действие «подставить текст в поле ввода» | `[PUT=/help]Справка[/PUT]` | Да ||
|| `CALL` | Кликабельное действие для звонка | `[CALL=+79991234567]Позвонить[/CALL]` | Да ||
|| `BR` | Перенос строки | `Строка 1[BR]Строка 2` | Да ||
|| `B` | Жирный текст | `[B]жирный[/B]` | Нет ||
|| `U` | Подчеркнутый текст | `[U]подчеркнутый[/U]` | Нет ||
|| `I` | Курсив | `[I]курсив[/I]` | Нет ||
|| `S` | Зачеркнутый текст | `[S]зачеркнутый[/S]` | Нет ||
|| `URL` | Ссылка | `[URL=https://example.com]текст ссылки[/URL]` | Нет ||
|#

Веб-клиент обрабатывает во вложении и остальные коды из статьи [Форматирование текста (BB-коды)](../../message-formatting.md), например `[SIZE]`, `[COLOR]` и `[CODE]`. Там же описан полный синтаксис.

## Пример

{% include [Сноска о примерах](../../../../../../../_includes/examples.md) %}

Пример показывает один элемент массива `BLOCKS`. По клику на «Подписаться на новости» в чат отправится текст `/subscribe`.

{% list tabs %}

- JS

    ```js
    {
        MESSAGE: 'API будет доступно в обновлении [B]im 24.0.0[/B][BR][SEND=/subscribe]Подписаться на новости[/SEND]'
    }
    ```

- Python

    ```python
    block = {
        "MESSAGE": "API будет доступно в обновлении [B]im 24.0.0[/B][BR][SEND=/subscribe]Подписаться на новости[/SEND]",
    }
    ```

- PHP

    ```php
    [
        'MESSAGE' => 'API будет доступно в обновлении [B]im 24.0.0[/B][BR][SEND=/subscribe]Подписаться на новости[/SEND]'
    ]
    ```

{% endlist %}
