# Блок со ссылками LINK

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../../../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../../../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Блок `LINK` выводит ссылку с заголовком, описанием и необязательным изображением-превью. Блок передается элементом массива `BLOCKS` вложения — общие правила и лимиты описаны на странице [Вложения в сообщениях ATTACH](../index.md#limits).

![Блок со ссылками](./_images/link.png){width=420}

## Когда использовать LINK

Используйте `LINK`, когда ссылку нужно показать отдельной карточкой: с заголовком, описанием и превью. Например, ссылка на задачу, документ или сделку в уведомлении бота.

Выберите другой блок, если:

- ссылка — часть текста. Используйте BB-код `[URL=https://example.com]текст[/URL]` в блоке [MESSAGE](./text.md)
- нужно показать сотрудника с аватаром. Используйте блок [USER](./user.md)
- ссылка — значение в карточке свойств. Используйте поле `LINK` элемента блока [GRID](./grid.md)

## Параметры блока

#|
|| **Название**
`тип` | **Описание** ||
|| **LINK***
[`string`](../../../../../../data-types.md) | URL ссылки. Допускаются абсолютные URL (`http://`, `https://`) и относительные пути от корня Битрикс24, например `/crm/deal/details/142/`. Единственное поле, которое делает блок кликабельным. Блок с недопустимым URL пропускается без ошибки ||
|| **NAME**
[`string`](../../../../../../data-types.md) | Заголовок ссылки. Если не задан, отображается `LINK` ||
|| **DESC**
[`string`](../../../../../../data-types.md) | Описание под заголовком ссылки ||
|| **HTML**
[`string`](../../../../../../data-types.md) | Устаревшая альтернатива `DESC`. Веб-клиент выводит теги как текст, мобильное приложение поле не показывает, а при заданном `HTML` игнорируются `PREVIEW`, `WIDTH` и `HEIGHT`. Используйте `DESC` ||
|| **PREVIEW**
[`string`](../../../../../../data-types.md) | URL изображения-превью ||
|| **WIDTH**
[`integer`](../../../../../../data-types.md) | Ширина превью в пикселях. Учитывается только вместе с `PREVIEW` ||
|| **HEIGHT**
[`integer`](../../../../../../data-types.md) | Высота превью в пикселях. Учитывается только вместе с `PREVIEW` ||
|| **USER_ID**
[`integer`](../../../../../../data-types.md) | ID пользователя Битрикс24. Сохраняется во вложении, но переход по нему в веб-клиенте не реализован ||
|| **CHAT_ID**
[`integer`](../../../../../../data-types.md) | ID чата Битрикс24. Сохраняется во вложении, но переход по нему в веб-клиенте не реализован ||
|| **NETWORK_ID**
[`string`](../../../../../../data-types.md) | Идентификатор сетевого пользователя Bitrix24 Network: буква и число. Если переданы несколько ID, сохраняется один по приоритету: `NETWORK_ID`, `USER_ID`, `CHAT_ID` ||
|#

## Примеры

{% include [Сноска о примерах](../../../../../../../_includes/examples.md) %}

Примеры показывают один элемент массива `BLOCKS`.

### Внешняя страница с превью {#external-link}

{% list tabs %}

- JS

    ```js
    {
        LINK: {
            PREVIEW: 'https://dev.1c-bitrix.ru/bitrix/templates/1c-bitrix-new/images/logo.png',
            WIDTH: 1000,
            HEIGHT: 638,
            NAME: 'Тикет #12345: новое API для модуля "Веб-мессенджер"',
            DESC: 'Необходимо реализовать к релизу!',
            LINK: 'https://api.bitrix24.com/'
        }
    }
    ```

- Python

    ```python
    block = {
        "LINK": {
            "PREVIEW": "https://dev.1c-bitrix.ru/bitrix/templates/1c-bitrix-new/images/logo.png",
            "WIDTH": 1000,
            "HEIGHT": 638,
            "NAME": 'Тикет #12345: новое API для модуля "Веб-мессенджер"',
            "DESC": "Необходимо реализовать к релизу!",
            "LINK": "https://api.bitrix24.com/",
        },
    }
    ```

- PHP

    ```php
    [
        'LINK' => [
            'PREVIEW' => 'https://dev.1c-bitrix.ru/bitrix/templates/1c-bitrix-new/images/logo.png',
            'WIDTH' => 1000,
            'HEIGHT' => 638,
            'NAME' => 'Тикет #12345: новое API для модуля "Веб-мессенджер"',
            'DESC' => 'Необходимо реализовать к релизу!',
            'LINK' => 'https://api.bitrix24.com/'
        ]
    ]
    ```

{% endlist %}

### Страница Битрикс24 {#portal-link}

Относительный путь открывает страницу на том же Битрикс24, из которого отправлено сообщение.

{% list tabs %}

- JS

    ```js
    {
        LINK: {
            NAME: 'Сделка #142: поставка оборудования',
            DESC: 'Ответственный: Иван Иванов',
            LINK: '/crm/deal/details/142/'
        }
    }
    ```

- Python

    ```python
    block = {
        "LINK": {
            "NAME": "Сделка #142: поставка оборудования",
            "DESC": "Ответственный: Иван Иванов",
            "LINK": "/crm/deal/details/142/",
        },
    }
    ```

- PHP

    ```php
    [
        'LINK' => [
            'NAME' => 'Сделка #142: поставка оборудования',
            'DESC' => 'Ответственный: Иван Иванов',
            'LINK' => '/crm/deal/details/142/'
        ]
    ]
    ```

{% endlist %}
