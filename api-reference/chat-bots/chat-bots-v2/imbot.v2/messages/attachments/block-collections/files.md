# Блок с файлами FILE

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../../../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../../../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Блок `FILE` добавляет в сообщение файлы по ссылке — например, отчет, договор или выгрузку, которые уже лежат на сайте или в облачном хранилище. Так бот может прислать сотруднику готовый отчет из вашей учетной системы. Значение ключа `FILE` — массив объектов, по одному на файл. Одиночный объект тоже принимается. Блок передается элементом массива `BLOCKS` вложения — общие правила и лимиты описаны на странице [Вложения в сообщениях ATTACH](../index.md#limits).

Битрикс24 не копирует файл из `LINK` к себе и не управляет правами на него: получатель откроет файл, только если у него есть доступ к сайту или хранилищу с этим файлом.

Выберите другой способ, если нужно:

- загрузить файл в Битрикс24 и отправить в чат — используйте метод [imbot.v2.File.upload](../../../files/file-upload.md)
- показать изображение прямо в сообщении — используйте блок [IMAGE](./images.md)

## Параметры элемента FILE

#|
|| **Название**
`тип` | **Описание** ||
|| **LINK***
[`string`](../../../../../../data-types.md) | URL файла: абсолютный `http://`/`https://` или путь от корня Битрикс24. Файл со ссылкой в другом формате не попадет в сообщение, а остальные файлы блока останутся ||
|| **NAME**
[`string`](../../../../../../data-types.md) | Название файла с расширением, например `report.pdf`. По расширению веб-клиент подбирает иконку, а файл без названия подписывает «Без названия» ||
|| **SIZE**
[`integer`](../../../../../../data-types.md) | Размер файла в байтах. Битрикс24 не сверяет его с самим файлом. Если поле не задано или равно `0`, сообщение покажет файл без размера ||
|#

## Пример

{% include [Сноска о примерах](../../../../../../../_includes/examples.md) %}

Пример показывает один элемент массива `BLOCKS` с двумя файлами. В веб-клиенте у каждого файла видны название и размер, а по клику ссылка из `LINK` открывается в новой вкладке.

{% list tabs %}

- JS

    ```js
    {
        FILE: [
            {
                NAME: 'Отчет за сентябрь.pdf',
                LINK: 'https://example.com/files/report-september.pdf',
                SIZE: 1500000
            },
            {
                NAME: 'Прайс-лист.xlsx',
                LINK: 'https://example.com/files/price-list.xlsx',
                SIZE: 48213
            }
        ]
    }
    ```

- Python

    ```python
    block = {
        "FILE": [
            {
                "NAME": "Отчет за сентябрь.pdf",
                "LINK": "https://example.com/files/report-september.pdf",
                "SIZE": 1500000,
            },
            {
                "NAME": "Прайс-лист.xlsx",
                "LINK": "https://example.com/files/price-list.xlsx",
                "SIZE": 48213,
            },
        ],
    }
    ```

- PHP

    ```php
    [
        'FILE' => [
            [
                'NAME' => 'Отчет за сентябрь.pdf',
                'LINK' => 'https://example.com/files/report-september.pdf',
                'SIZE' => 1500000
            ],
            [
                'NAME' => 'Прайс-лист.xlsx',
                'LINK' => 'https://example.com/files/price-list.xlsx',
                'SIZE' => 48213
            ]
        ]
    ]
    ```

{% endlist %}
