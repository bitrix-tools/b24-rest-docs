# Файлы: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Методы позволяют загружать файлы в чат и получать ссылку на скачивание файла от имени пользователя или приложения.

> Быстрый переход: [все методы](#all-methods)

## Порядок работы с файлом {#how-to-start}

1. Загрузите файл методом [im.v2.File.upload](./file-upload.md). Метод объединяет три шага устаревшего API в один вызов: загружает файл на Диск, прикрепляет его к чату и отправляет сообщение.
2. Сохраните из ответа `result.file.id` — это ID файла на Диске, и `result.messageId` — ID созданного сообщения с файлом.
3. Чтобы получить ссылку на скачивание, вызовите [im.v2.File.download](./file-download.md), передав `dialogId` и этот ID файла в параметре `fileId`.

Адресат задается параметром `dialogId`: для групповых чатов — `chat{chatId}`, для личных — ID собеседника. Подробнее — [Формат dialogId](../../index.md#dialog-id). Описание полей объекта File — [Объекты и поля](../../entities.md#file).

Оба метода появились в `im.v2`. В предыдущем поколении ту же задачу решала цепочка вызовов `im.disk.*` и методов Диска — она описана в подразделе [Файлы в чатах](../../../../chats/files/index.md).

## Ограничения {#limits}

#|
|| **Ограничение** | **Значение** ||
|| Максимальный размер файла | 100 МБ ||
|| Формат передачи содержимого | Строка Base64 в `fields.content`, без префикса `data:*/*;base64,` ||

## Связь с другими объектами {#relations}

**Пользователь.** Методы работают от имени текущего пользователя: файл появляется в чате как файл этого пользователя, отдельная регистрация бота не нужна.

**Чаты.** Файл загружается в конкретный диалог. Сами чаты создают и настраивают методами раздела [Чаты с пользователем](../../../../chats/index.md).

**События.** Загрузка файла создает сообщение в чате, поэтому подписанное приложение получит событие [ONIMV2MESSAGEADD](../events/events.md#onimv2messageadd) — [События im.v2](../events/index.md).

**Файлы от имени бота.** Те же операции от имени зарегистрированного чат-бота выполняют методы [imbot.v2.File.upload и imbot.v2.File.download](../../imbot.v2/files/index.md) — они дополнительно требуют `botId`.
