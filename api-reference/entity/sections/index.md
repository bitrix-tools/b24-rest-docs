# Разделы хранилища данных: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

Разделы хранилища данных помогают группировать элементы внутри приложения и строить иерархию.

Группа методов `entity.section.*` позволяет создавать разделы, получать их список, менять параметры и удалять ненужные.

> Быстрый переход: [все методы](#all-methods)

{% note info "" %}

Методы раздела работают только в контексте [приложения](../../../settings/app-installation/index.md).

{% endnote %}

## Как начать работу

1. Получите идентификатор хранилища методом [entity.get](../entities/entity-get.md)
2. Если в хранилище нужна иерархия, создайте первый раздел методом [entity.section.add](./entity-section-add.md)
3. Получите список разделов и их идентификаторы методом [entity.section.get](./entity-section-get.md)
4. Измените параметры раздела методом [entity.section.update](./entity-section-update.md)
5. Удалите ненужный раздел методом [entity.section.delete](./entity-section-delete.md)

## Что можно задать в разделе

**Основные поля.** Название, символьный код, описание, флаг активности и индекс сортировки. Их передают отдельными параметрами методов [entity.section.add](./entity-section-add.md) и [entity.section.update](./entity-section-update.md).

**Пользовательские поля.** Поля `UF_*` передают отдельными параметрами в формате `"UF_КОД": значение`, например `"UF_COLOR": "#ff6600"`.

**Файлы.** Картинку и детальную картинку раздела передают в формате из статьи [Как загрузить файлы](../../files/how-to-upload-files.md). В ответе метода [entity.section.get](./entity-section-get.md) такие поля содержат ссылку на файл.

## Как получать списки разделов

Метод [entity.section.get](./entity-section-get.md) возвращает разделы постранично: размер страницы фиксирован — `50` записей, следующую страницу запрашивают параметром `start`. Отбор и сортировку задают параметрами `FILTER` и `SORT`, в ключах фильтра поддерживаются префиксы сравнения, например `>=`, `%` или `!`.

Подробнее о постраничной навигации — в статье [Особенности списочных методов](../../../settings/how-to-call-rest-api/list-methods-pecularities.md).

## Связь с другими объектами

**Хранилище данных.** Каждый метод группы работает с конкретным хранилищем данных приложения. Для этого в методы передается параметр `ENTITY` — идентификатор хранилища. Требования к идентификатору описаны в разделе [Идентификатор хранилища](../index.md#entity-id), а получить значение можно методом [entity.get](../entities/entity-get.md). Уровень прав, который нужен для работы с разделами, — в разделе [Уровни прав доступа](../index.md#access-levels).

**Элементы хранилища.** Разделы используются для группировки элементов. Элемент привязывают к разделу параметром `SECTION`. Для работы с элементами используйте методы [entity.item.*](../items/index.md).

**Родительский раздел.** В методах [entity.section.add](./entity-section-add.md) и [entity.section.update](./entity-section-update.md) можно указать параметр `SECTION`, чтобы создать вложенный раздел или перенести раздел внутрь другого. Раздел верхнего уровня создают без этого параметра.
