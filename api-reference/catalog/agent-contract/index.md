# Агентские договоры: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Агентский договор связывает поставщика с товарами, которые компания продает по договору комиссии. В договоре указывают название, поставщика и список товаров.

Договоры создают и изменяют в интерфейсе Битрикс24: CRM → Продажи → Управление продажами → Центр продаж → Платежные системы → Агентские схемы. В REST 3.0 для агентских договоров есть только метод удаления [catalog.contract.agent.delete](./catalog-contract-agent-delete.md).

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [Агентские схемы: как печатать чеки с агентскими реквизитами](https://helpdesk.bitrix24.ru/open/17917894/)

## Как начать работу

1. Узнайте идентификатор договора в интерфейсе Битрикс24, в карточке договора
2. Удалите договор методом [catalog.contract.agent.delete](./catalog-contract-agent-delete.md)

Метод удаления не проверяет, существует ли договор: для несуществующего идентификатора он тоже возвращает `true`.

## Связь с другими объектами

**Товары.** При удалении договора удаляется список товаров договора. Сами товары каталога остаются, работать с ними можно методами [catalog.product.*](../product/index.md).

**Поставщики.** В договоре указан поставщик — комитент, от имени которого продаются товары.
