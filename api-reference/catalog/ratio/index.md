# Коэффициенты единиц измерения в Торговом каталоге: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Коэффициент единицы измерения показывает, сколько единиц товара продают за раз. Например, у воды, которую отпускают упаковками по шесть бутылок, единица измерения — бутылка, а коэффициент — 6.

Через REST коэффициенты можно только прочитать. Задают их в карточке товара в Битрикс24, в колонке «Коэффициент единицы измерения» таблицы вариаций. Если колонки не видно, ее включают в настройках списка.

{% note warning "" %}

Методы [catalog.product.add](../product/catalog-product-add.md) и [catalog.product.update](../product/catalog-product-update.md) не сохраняют коэффициент. Поле `measureRatio` они пропустят без ошибки и вернут успешный ответ, но коэффициент товара не изменится.

{% endnote %}

## Как начать работу

1. Получите идентификатор товара методом [catalog.product.list](../product/catalog-product-list.md)
2. Получите коэффициенты товара методом [catalog.ratio.list](./catalog-ratio-list.md) с фильтром `{"productId": <идентификатор товара>}`. Имя поля пишите так же, как в ответе: поле `PRODUCT_ID` метод пропустит без ошибки и вернет коэффициенты всех товаров
3. Возьмите запись с `isDefault`, равным `Y`. Если такой записи нет, Битрикс24 использует для товара коэффициент 1. Так бывает, например, у товаров, созданных через REST
4. Запрашивайте известную запись по ее `id` методом [catalog.ratio.get](./catalog-ratio-get.md)

## Формат ответа

Методы возвращают данные в таких полях:

- [catalog.ratio.get](./catalog-ratio-get.md) — объект коэффициента в `result.ratio`
- [catalog.ratio.list](./catalog-ratio-list.md) — массив объектов в `result.ratios`, до 50 записей за вызов. Общее число найденных записей приходит в `total`. Если есть следующая страница, в `next` придет значение `start` для нее
- [catalog.ratio.getFields](./catalog-ratio-get-fields.md) — описание полей в `result.ratio`

У объекта коэффициента четыре поля:

- `id` — идентификатор записи коэффициента
- `productId` — идентификатор товара
- `ratio` — значение коэффициента, например `6`
- `isDefault` — `Y`, если это коэффициент товара по умолчанию, иначе `N`

## Связь с другими объектами

Коэффициент связан с товаром, а через товар — с единицей измерения.

**Товар.** Идентификатор товара хранится в поле `productId` коэффициента. Его возвращает метод [catalog.product.list](../product/catalog-product-list.md), а данные товара по нему — метод [catalog.product.get](../product/catalog-product-get.md).

**Единица измерения.** Значение коэффициента указано в единице измерения товара. Идентификатор этой единицы хранится в поле `measure` товара. Список единиц возвращает метод [catalog.measure.list](../measure/catalog-measure-list.md) из группы [catalog.measure.*](../measure/index.md).
