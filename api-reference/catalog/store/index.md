# Склады в Торговом каталоге: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга

Склады помогают контролировать остатки, перемещения и поступления товаров. Вы всегда будете знать, где находятся нужные товары, и сможете вовремя распределять их между складами.

Вы можете настроить права доступа для каждого склада. Тогда сотрудники будут видеть только свои документы складского учета и не смогут случайно выбрать другой склад при создании новых документов.

## Как начать работу

1. Проверьте доступные поля склада методом [catalog.store.getFields](./catalog-store-get-fields.md)
2. Создайте склад методом [catalog.store.add](./catalog-store-add.md)
3. Сохраните идентификатор склада из ответа — поле `result.store.id`. Идентификаторы существующих складов вернет метод [catalog.store.list](./catalog-store-list.md)
4. Используйте идентификатор склада в документах складского учета или при чтении остатков

Удалить склад, который указан в позициях документов складского учета, нельзя — сначала удалите такие позиции или документы. Изображение склада методами предыдущей версии задать нельзя.

## Склады в REST 3.0

В [REST 3.0](../../rest-v3.md) склады можно создавать, изменять, получать и удалять. Описание полей склада возвращают методы `catalog.store.field.list` и `catalog.store.field.get`. Методы, которые есть в обеих версиях API, помечены в таблице как `v 3.0`.

Особенности методов новой версии:

- поля `active` и `issuingCenter` принимают и возвращают `true` или `false`, значения `Y` и `N` не поддерживаются
- изображение склада можно загрузить в поле `image` при создании и изменении. Чтобы удалить изображение, передайте `image: null`. В ответе приходят идентификатор файла `imageId` и ссылка `imageUrl`
- служебные поля, например `id` и `dateCreate`, и неизвестные поля в `fields` вызывают ошибку, а не пропускаются молча. Пользовательские поля склада не поддерживаются
- незаполненные строковые поля приходят пустой строкой, а не `null`

## Связь с другими объектами

**Остатки по складам.** Узнайте, сколько товаров осталось на складе, с помощью методов [catalog.storeproduct.*](../store-product/index.md).

**Складской учет.** Добавляйте и изменяйте документы складского учета, используя методы [catalog.document.*](../document/index.md). При добавлении товаров в документ методом [catalog.document.element.add](../document/document-element/catalog-document-element-add.md) укажите в полях `storeFrom` и `storeTo` идентификаторы склада-отправителя и склада-получателя. Получить идентификаторы складов можно с помощью метода [catalog.store.list](./catalog-store-list.md).

## Обзор методов {#all-methods}

> Scope: [`catalog`](../../scopes/permissions.md)
>
> Кто может выполнять методы:
> - чтение — пользователь с правом «Просмотр каталога товаров» или «Просмотр и выбор склада»
> - создание, изменение и удаление — пользователь с правом «Редактирование складов»
> - `catalog.store.field.list` и `catalog.store.field.get` — любой пользователь
