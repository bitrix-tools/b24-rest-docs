# Удалить торговый каталог catalog.catalog.delete

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

> Scope: [`catalog`](../../scopes/permissions.md)
>
> Кто может выполнять метод: администратор

{% note info "" %}

Метод относится к REST 3.0. Особенности вызова и формат ответа новой версии API описаны в [обзоре REST 3.0](../../rest-v3.md).

{% endnote %}

Метод `catalog.catalog.delete` снимает с инфоблока признак торгового каталога. Сам инфоблок и его элементы остаются.

## Параметры метода

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

#|
|| **Название**
`тип` | **Описание** ||
|| **id***
[`integer`](../../data-types.md) | Идентификатор торгового каталога, который нужно удалить.

Каталог вариаций удалить нельзя. Проверить, является ли каталог каталогом вариаций, можно методом [catalog.catalog.isoffers](./catalog-catalog-is-offers-rest-v3.md).

Идентификатор можно получить методом [catalog.catalog.list](./catalog-catalog-list-rest-v3.md) ||
|#

### Возможные коды ошибок

#### Ошибки валидации запроса

Код ошибки: `BITRIX_REST_V3_EXCEPTION_VALIDATION_REQUESTVALIDATIONEXCEPTION`

#|
|| **Поле** | **Описание ошибки** | **Как исправить** ||
|| `-` | Не заполнено значение хотя бы одного обязательного поля: id, filter | Передайте в `id` положительное число. Вместе с этим сообщением приходит второе: «Должно быть передано только одно из значений: id, filter» ||
|| `-` | Catalog is offers and cannot be deleted | Каталог вариаций удалить нельзя. Проверьте каталог методом [catalog.catalog.isoffers](./catalog-catalog-is-offers-rest-v3.md) ||
|| `-` | delete catalog error | Каталог не удален: удаление отменил обработчик события. Повторите запрос или проверьте каталог ||
|#

#### Ошибка формата фильтра

Код ошибки: `BITRIX_REST_V3_EXCEPTION_INVALIDFILTEREXCEPTION`

#|
|| **Поле** | **Описание ошибки** | **Как исправить** ||
|| `filter` | Не удается распознать выражение фильтра `filter` | Метод не поддерживает `filter`. Передайте `id` торгового каталога ||
|#

#### Ошибка отсутствия объекта

Код ошибки: `BITRIX_REST_V3_EXCEPTION_ENTITYNOTFOUNDEXCEPTION`

#|
|| **Поле** | **Описание ошибки** | **Как исправить** ||
|| `id` | Запись с ID = `#ID#` не найдена | Торгового каталога с таким идентификатором нет. Проверьте идентификатор методом [catalog.catalog.list](./catalog-catalog-list-rest-v3.md) ||
|#

#### Ошибка доступа

Код ошибки: `BITRIX_REST_V3_EXCEPTION_ACCESSDENIEDEXCEPTION`

#|
|| **Поле** | **Описание ошибки** | **Как исправить** ||
|| `-` | Доступ запрещен | Нет прав на изменение настроек торгового каталога. Вызовите метод от имени администратора ||
|#
