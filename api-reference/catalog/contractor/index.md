# Поставщики Складского учета: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

Справочник поставщиков — прежний способ хранить поставщиков Складского учета: поставщик в нем — юридическое лицо с названием компании. Метод `catalog.contractor.add` добавляет поставщика в справочник, а методы `catalog.contractor.field.list` и `catalog.contractor.field.get` возвращают описание полей поставщика.

{% note warning "" %}

Метод `catalog.contractor.add` работает, только если поставщики Складского учета не перенесены в CRM. Если поставщиков ведет CRM, справочник не используется: поставщиков добавляют как компании и контакты CRM и привязывают к документам прихода методами [catalog.document.contractor.*](../documentcontractor/index.md).

{% endnote %}

## Как начать работу

1. Проверьте доступные поля поставщика методом [catalog.contractor.field.list](./catalog-contractor-field-list.md)
2. Добавьте поставщика методом [catalog.contractor.add](./catalog-contractor-add.md) и сохраните `id` из ответа
3. Укажите `id` поставщика в поле `contractorId` документа прихода методами [catalog.document.*](../document/index.md)

Методов получения списка поставщиков справочника в REST 3.0 нет. Идентификатор нового поставщика возвращает метод [catalog.contractor.add](./catalog-contractor-add.md).

## Связь с другими объектами

**Документы складского учета.** Поставщик из справочника указывается в поле `contractorId` документа прихода. Для работы с документами используйте методы [catalog.document.*](../document/index.md).

**CRM-поставщики.** Если поставщики перенесены в CRM, вместо справочника используются компании и контакты CRM. Привязать их к документу можно методами [catalog.document.contractor.*](../documentcontractor/index.md).

## Обзор методов {#all-methods}

> Scope: [`catalog`](../../scopes/permissions.md)
>
> Кто может выполнять методы:
> - пользователь с правом «Просмотр и выбор склада» — для `catalog.contractor.add`
> - любой пользователь — для `catalog.contractor.field.list` и `catalog.contractor.field.get`
