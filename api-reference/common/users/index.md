# Информация о пользователе: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Методы этой группы работают только с текущим пользователем: получают базовые данные профиля, проверяют коды доступа и права администратора Битрикс24. Методам не нужен отдельный scope.

Информацию об остальных пользователях получает группа методов [Пользователи](../../user/index.md).

> Быстрый переход: [все методы](#all-methods)

## Как выбрать метод

#|
|| **Если вам нужно** | **Используйте** ||
|| Получить данные профиля: имя, часовой пояс, признак администратора | [profile](./profile.md) ||
|| Проверить, входит ли пользователь в отдел, группу или проект по коду доступа | [user.access](./user-access.md) ||
|| Проверить, является ли пользователь администратором Битрикс24 | [user.admin](./user-admin.md) ||
|#

Форматы кодов доступа описаны на странице [user.access](./user-access.md), а их названия получает метод [access.name](../system/access-name.md).

## Обзор методов      {#all-methods}

> Scope: [`базовый`](../../scopes/permissions.md)
>
> Кто может выполнять метод: любой пользователь

#|
|| **Метод** | **Описание** ||

|#
