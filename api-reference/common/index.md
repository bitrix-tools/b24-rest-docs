# Общие методы и события: обзор

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Общие методы и события помогают проверить контекст приложения, получить данные текущего пользователя, сохранить настройки интеграции и обработать жизненный цикл приложения.

Для методов раздела не нужны отдельные scope. Исключение — событие [onUserAdd](./events/on-user-add.md), для него нужен scope `user`, `user_basic` или `user_brief`.

## Как начать работу

1. [Установите приложение](../../settings/app-installation/index.md) и обработайте событие [onAppInstall](./events/on-app-install.md) или получите токены на странице установки. Если тиражному приложению нужна работа без участия сотрудника, используйте [ONAPPUSERREADY](./events/on-app-user-ready.md) — оно передает авторизацию системного пользователя приложения.
2. Проверьте права текущего пользователя методом [user.admin](./users/user-admin.md).
3. Сохраните общие настройки приложения методом [app.option.set](./settings/app-option-set.md).
4. Храните персональные настройки сотрудников через [user.option.set](./settings/user-option-set.md) и читайте их через [user.option.get](./settings/user-option-get.md).

## Что учитывать перед началом работы

**Контекст приложения.** Методы `app.option.*`, `user.option.*` и события `onApp*` работают только в контексте [приложения](../../settings/app-installation/index.md). Событие onUserAdd доступно и исходящему вебхуку. Системные методы и методы группы «Информация о пользователе» можно вызывать и через вебхук.

**Права пользователя.** Метод [app.option.set](./settings/app-option-set.md) выполняет только администратор Битрикс24, остальным пользователям он вернет `ACCESS_DENIED` с текстом `Access denied! Administrator authorization required`. Остальные методы раздела доступны любому авторизованному пользователю.

## Связь с другими объектами

Раздел связан с приложением и текущим пользователем.

**Приложение.** Методы [app.info](./system/app-info.md), [app.option.get](./settings/app-option-get.md) и [app.option.set](./settings/app-option-set.md) работают с данными и настройками текущего приложения.

**Пользователь.** Метод [profile](./users/profile.md) получает ID, имя, фамилию и другие данные текущего пользователя. Методы [user.admin](./users/user-admin.md) и [user.access](./users/user-access.md) проверяют его права перед вызовом методов с ограничениями.
