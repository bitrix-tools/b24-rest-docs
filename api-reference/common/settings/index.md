# Настройки приложения: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Настройки приложения хранят общие параметры интеграции и персональные значения для каждого пользователя.

{% note info "" %}

Методы раздела работают только в контексте [приложения](../../../settings/app-installation/index.md).

{% endnote %}

## Как выбрать группу методов

Если настройка одна для всего приложения, используйте группу методов `app.option.*`. Она подходит для общих параметров интеграции, которые не зависят от пользователя.

Если у каждого пользователя должны быть свои значения, используйте группу методов `user.option.*`. Она хранит настройки того пользователя, чьим токеном выполнен вызов, например персональные настройки интерфейса.

## Что можно хранить

Настройки хранятся парами «ключ — значение». Ключ — строка, которую вы передаете в методы `*.set` и затем в параметре `option` методов `*.get`.

- **Зарезервированные ключи.** Не используйте ключи `next` и `total`: REST API выносит их из `result` в корень ответа.
- **Объем.** Размер значений методы не проверяют, но все настройки приложения или пользователя хранятся одной записью и целиком читаются при каждом вызове `*.get`. Храните в настройках параметры интеграции, а не рабочие данные.

## Права доступа

Вызов любого метода раздела через входящий вебхук вернет ошибку `ACCESS_DENIED` с текстом `Access denied! Application context required`.

Метод [app.option.set](./app-option-set.md) доступен только администратору Битрикс24, для остальных пользователей он вернет `ACCESS_DENIED` с текстом `Access denied! Administrator authorization required`. Методы [app.option.get](./app-option-get.md), [user.option.set](./user-option-set.md) и [user.option.get](./user-option-get.md) доступны любому авторизованному пользователю приложения.

## Связь с другими объектами

**Приложение.** [Системные методы](../system/index.md) проверяют контекст приложения, доступные scope и наличие метода в Битрикс24. Например, [app.info](../system/app-info.md) получает информацию о приложении, а [scope](../system/scope.md) возвращает список доступных scope.

**Пользователь.** Проверьте права через [user.admin](../users/user-admin.md) перед вызовом `app.option.set`. Базовые данные текущего пользователя получает [profile](../users/profile.md).
