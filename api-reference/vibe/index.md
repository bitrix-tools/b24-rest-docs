# Вайб: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Вайб — это страница Битрикс24, которая заменяет привычную [Ленту новостей](../log/index.md) и позволяет создавать более персонализированный интерфейс.

Администратор настраивает страницу в конструкторе из готовых блоков и виджетов так же, как это делается в [Сайтах](../landing/index.md). Кроме системных виджетов самого Битрикс24 разработчики могут добавлять собственные с помощью методов `landing.repowidget.*`.

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [Главная страница: наш вайб. Как выбрать и настроить шаблон](https://helpdesk.bitrix24.ru/open/22089066/)

{% note info " " %}

**Виджет** — динамический элемент Вайба, который отображает данные, полученные с помощью соответствующего серверного обработчика. Это позволяет делать виджеты интерактивными, отображая изменяющиеся данные в ответ на действия пользователя.

Например, можно отсортировать данные в таблице, подгрузить новые данные или открыть слайдер с дополнительным интерфейсом вашего решения.

{% endnote %}

Кроме того, Вайб, созданный на вашем Битрикс24, можно экспортировать в виде готового решения для публикации в [Маркет](../../market/index.md).

## Как начать работу

1. Подготовьте верстку виджета на Vue и обработчик — внешний скрипт, который вернет данные для шаблона в виде JSON-строки.
2. Зарегистрируйте виджет методом [landing.repowidget.register](./landing-repowidget-register.md). В нем передайте уникальный код виджета, верстку, стили и адрес обработчика.
3. Проверьте список своих виджетов методом [landing.repowidget.getlist](./landing-repowidget-get-list.md).
4. Включите режим отладки методом [landing.repowidget.debug](./landing-repowidget-debug.md), чтобы Vue выводил в консоль браузера больше ошибок.
5. Добавьте виджет на страницу Вайба в конструкторе Битрикс24 — это делает администратор.
6. Ненужный виджет удалите методом [landing.repowidget.unregister](./landing-repowidget-unregister.md).

{% note info " " %}

Если виджет зарегистрировало приложение, виджет привязывается к нему по коду приложения. Режим отладки работает только в контексте приложения: вызванный вебхуком метод `landing.repowidget.debug` вернет ошибку `APP_NOT_FOUND`.

{% endnote %}

## Принцип работы виджетов

Интерфейс виджета реализуется на базе [шаблонизатора Vue](https://vuejs.org). Данные для отображения виджет получает, делая запрос к внешнему обработчику.

Чтобы добавить свой виджет в Битрикс24, передайте верстку шаблона на базе Vue, необходимые для нее CSS-классы и адрес обработчика — он отвечает за передачу данных в шаблон.

### Директивы Vue

В виджетах для Вайба поддерживаются следующие директивы и конструкции Vue:

- переменные `not_var{{ your_variable_name }}`
- условный оператор `v-if` / `v-else`
- условные атрибуты `:class`, `:disabled` и другие
- цикл `v-for`
- выражения, например, `not_var{{ number + 1 }}`
- обработчики `@click` и `v-on:click`

### Интерактивные действия

В виджетах нельзя использовать собственный JS-код. Обработчиком событий `@click` и `v-on:click` могут быть только предопределенные функции:

- `fetch(?params)` — вызывает обработчик виджета за новыми данными и передает в него параметры `params`
- `openApplication(?params)` — открывает слайдер вашего приложения и передает в него произвольные параметры `params`. Это способ вызвать [openApplication](../widgets/bx24-widget-methods.md) из интерфейса виджета Вайба
- `openPath(url)` — открывает в слайдере страницу Битрикс24 по указанному `url`. Это способ вызвать [openPath](../widgets/bx24-widget-methods.md) из интерфейса виджета Вайба

## Как работает виджет {#anchor-handler}

Основная часть работы виджета построена на функции `fetch(?params)` и обработчике виджета.

1. Администратор добавляет ваш виджет на страницу Вайба, а пользователь открывает уже опубликованную страницу. В обоих случаях Битрикс24 делает запрос к URL обработчика, который вы указали при регистрации виджета.
2. Обработчик возвращает данные в виде JSON-строки. Структуру данных вы определяете сами.
3. Vue выполняет код шаблона вашего виджета, подставляя в него данные, полученные от обработчика на шаге 2. Таким образом, формируется изначальный полноценный внешний вид виджета.
4. Если вы использовали в шаблоне функцию `fetch` — например, с параметрами `{'action': 'getItems'}` — то при нажатии на ссылку Битрикс24 снова вызовет обработчик вашего виджета и передаст туда те же параметры `{'action': 'getItems'}` в POST-запросе.
5. Обработчик анализирует входные параметры, формирует новый набор данных и возвращает его в виде JSON-строки. Набор может быть полным или частичным — частичный экономит трафик и ускоряет работу виджета.
6. Новые полученные данные будут снова подставлены в ваш шаблон.

Таким образом виджет изменяет свой внешний вид и отображаемые данные в ответ на действия пользователя.

## Примеры синтаксиса Vue для виджетов Вайба

### Локализация

Используйте стандартный синтаксис обращения к переменным Vue для вызова `$Bitrix.Loc.getMessage`, чтобы вывести значение константы в видимой части верстки:

```html
<h3 class="w-title">{{ $Bitrix.Loc.getMessage('W_TITLE') }}</h3>
```

Используйте синтаксис «условных» атрибутов Vue, чтобы присвоить значение `$Bitrix.Loc.getMessage` нужному атрибуту узла:

```html
<input
    type="text"
    class="task-widget__filter"
    :placeholder="$Bitrix.Loc.getMessage('W_FILTER')"
    v-model="taskFilter"
/>
```

### Переменные

Используйте стандартный синтаксис обращения к переменным Vue, чтобы вывести значения в видимой части верстки:

```html
<td class="task-widget__cell">not_var{{ task.id }}</td>
```

Используйте синтаксис «условных» атрибутов Vue, чтобы присвоить значение переменной нужному атрибуту узла:

```html
<img :src="user.avatar" class="task-widget__avatar" />
```

Используйте логические выражения для применения опциональных классов:

```html
<a href="#" :class="{ 'task-widget__link--disabled': currentPage === 1 }">
```

### Использование переменных в openPath

Используйте апострофы, чтобы обращаться к переменным Vue при формировании нужного пути:

```html
<tr
    v-for="(task, index) in taskItems"
    :key="task.id"
    @click="openPath(`/company/personal/user/${task.responsibleId}/tasks/task/view/${task.id}/`)"
>
```

Используйте объединение строк для формирования пути:

```html
<tr
    v-for="(task, index) in taskItems"
    :key="task.id"
    @click="openPath('/company/personal/user/' + task.responsibleId + '/tasks/task/view/' + task.id)"
>
```
