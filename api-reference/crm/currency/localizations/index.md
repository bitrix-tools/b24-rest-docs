Локализация валют — это правила написания чисел и расположения знака валюты на разных языках.

Локализации не существуют сами по себе: каждый набор правил принадлежит конкретной валюте раздела [Валюты в CRM](../index.md) и хранится под идентификатором языка. У одной валюты может быть своя локализация для каждого языка Битрикс24.

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [валюты в Битрикс24](https://helpdesk.bitrix24.ru/open/6987305/)

## Идентификатор валюты и код языка

**Идентификатор валюты.** Все методы раздела принимают его в параметре `id` — это символьный код валюты по стандарту ISO 4217, например `RUB`. Список кодов, заведенных в Битрикс24, возвращает метод [crm.currency.list](../crm-currency-list.md).

**Код языка.** Локализация хранится отдельно для каждого языка, например `ru` или `en`. В методе [crm.currency.localizations.set](./crm-currency-localizations-set.md) код языка — это ключ объекта `localizations`, в методе [crm.currency.localizations.delete](./crm-currency-localizations-delete.md) коды передают массивом в параметре `lids`.

## Из чего состоит локализация

Набор правил для одного языка описан типом данных [`crm_currency_localization`](../../data-types.md#crm_currency_localization):

- `FULL_NAME` — название валюты на этом языке
- `FORMAT_STRING` — шаблон вывода суммы, вместо символа `#` подставляется значение, например `$ #`
- `DECIMALS` — число знаков дробной части
- `DEC_POINT` — разделитель дробной части
- `THOUSANDS_VARIANT` и `THOUSANDS_SEP` — разделитель триад, при заданном `THOUSANDS_VARIANT` значение `THOUSANDS_SEP` игнорируется
- `HIDE_ZERO` — скрывать незначащие нули или нет

Актуальный перечень полей с типами возвращает метод [crm.currency.localizations.fields](./crm-currency-localizations-fields.md). Существующие локализации, которые не переданы в метод [crm.currency.localizations.set](./crm-currency-localizations-set.md), не изменяются, а для языков без своей локализации применяются значения по умолчанию.

## Использование локализации

**Битрикс24.** Вывод валюты зависит от языка интерфейса Битрикс24 в аккаунте сотрудника. В интерфейсе на русском языке сумма выводится в формате `12 345,67 ₽`, на английском — `₽ 12,345.67`.

**Битрикс24.Сайты.** В настройках сайта можно выбрать язык стандартных фраз для блоков конструктора. Язык сайта влияет на формат вывода цен в блоках магазина.

## Права доступа

Права зависят от операции:

- читать локализации может пользователь с доступом на чтение объектов CRM
- изменять и удалять локализации может пользователь с правом «Изменять настройки» в CRM
