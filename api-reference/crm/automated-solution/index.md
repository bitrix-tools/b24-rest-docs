# Цифровые рабочие места: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Цифровые рабочие места — это отдельный раздел для смарт-процессов, которые не обязаны быть связаны с лидами, сделками, контактами и компаниями. Рабочее место может состоять из одного или нескольких процессов. В каждом есть свои карточки, воронки, стадии канбана, роботы и другие функции.

В Битрикс24 они находятся в разделе *Автоматизация > Цифровые рабочие места > Список цифровых рабочих мест*.

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [Цифровые рабочие места](https://helpdesk.bitrix24.ru/open/18913896)

## Как начать работу

1. Получите `id` типа смарт-процесса методом [crm.type.list](../universal/user-defined-object-types/crm-type-list.md) или создайте тип методом [crm.type.add](../universal/user-defined-object-types/crm-type-add.md)
2. Создайте рабочее место методом [crm.automatedsolution.add](./crm-automated-solution-add.md) и передайте `id` типов в поле `typeIds`
3. Проверьте результат методом [crm.automatedsolution.get](./crm-automated-solution-get.md) или найдите рабочие места по фильтру методом [crm.automatedsolution.list](./crm-automated-solution-list.md)
4. Измените название или состав смарт-процессов методом [crm.automatedsolution.update](./crm-automated-solution-update.md)
5. Удалите рабочее место методом [crm.automatedsolution.delete](./crm-automated-solution-delete.md). Перед удалением уберите из него смарт-процессы: передайте в `crm.automatedsolution.update` пустой `typeIds`, и смарт-процессы вернутся в CRM

## Связь с другими объектами

**Смарт-процессы.** Привязка смарт-процессов задается на стороне рабочего места — полем `typeIds`. В `typeIds` передают идентификаторы типов смарт-процессов (`id`) из раздела [Смарт-процессы](../universal/user-defined-object-types/index.md), а не `entityTypeId`. Параметры `customSectionId` и `customSections` в методах `crm.type.*` устарели, рабочие места через них не настраивают.

**CRM.** Рабочие места и их смарт-процессы работают на механизмах CRM и управляются методами со scope `crm`, но выводятся в разделе *Автоматизация*. Смарт-процесс может находиться только в одном месте: в CRM или в одном рабочем месте. При привязке к рабочему месту он убирается из прежнего места.

## Ограничения

- Количество цифровых рабочих мест ограничено. При превышении лимита метод `crm.automatedsolution.add` вернет ошибку `LIMIT_EXCEEDED`
- Чтобы перенести в рабочее место смарт-процесс из CRM или вернуть его в CRM, кроме прав на цифровые рабочие места нужно право «Разрешить изменять настройки» CRM

{% note info "" %}

В коробочной версии Битрикс24 цифровые рабочие места доступны с версии CRM [24.300.0](../../../settings/cloud-and-on-premise/on-premise/versions.md).

{% endnote %}
