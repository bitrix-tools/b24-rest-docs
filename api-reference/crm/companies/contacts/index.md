При помощи группы методов `crm.company.contact.*` можно управлять связями контактов с компанией: устанавливать или удалять связь для контакта или для группы контактов.

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [Связь между сделками, контактами и компаниями](https://helpdesk.bitrix24.ru/open/2501159)

## Что дает связь между компанией и контактами

- контакты компании подтягиваются автоматически, когда вы выбираете ее в поле `Клиент` сделки или смарт-процесса
- карточка компании показывает данные связанных контактов: имя, номер телефона, e-mail, должность
- из карточки компании можно позвонить или написать письмо без перехода в карточку контакта
- символьные коды при [генерации документов по шаблону](../../document-generator/index.md) подставляют данные связанных контактов в документ
