# Настройки поиска дубликатов по дополнительным полям: обзор методов

Методы `crm.duplicate.volatileType.*` расширяют стандартный набор полей для поиска дубликатов — в поиск можно добавить доступные стандартные и пользовательские поля лида, контакта или компании.

Добавленное поле появляется в настройках поиска дубликатов в интерфейсе Битрикс24 у всех сотрудников. На поиск методом [crm.duplicate.findbycomm](../crm-duplicate-find-by-comm.md) эти настройки не влияют: он работает только по телефону и адресу электронной почты. Как устроена работа с дубликатами целиком, описано в разделе [Поиск и обработка дубликатов в CRM](../index.md).

Например, можно добавить в поиск название лида — тогда лиды с одинаковым названием Битрикс24 покажет как дубликаты.

## Какие поля доступны по умолчанию

В интерфейсе Битрикс24 сотрудник выбирает поля для поиска дубликатов:

- **Лиды** — Ф.И.О., название компании, телефон, адрес электронной почты
- **Контакты** — Ф.И.О., телефон, адрес электронной почты, реквизиты и банковские реквизиты
- **Компании** — название компании, телефон, адрес электронной почты, реквизиты и банковские реквизиты

Состав реквизитов зависит от страны. Для России это ИНН, ОГРН, ОГРНИП и расчетный счет.

## Как настроить поиск по дополнительным полям

1. Получите список доступных полей методом [crm.duplicate.volatileType.fields](./crm-duplicate-volatile-type-fields.md) — в ответе придут пары `entityTypeId` и `fieldCode`
2. Проверьте, какие поля уже подключены, методом [crm.duplicate.volatileType.list](./crm-duplicate-volatile-type-list.md)
3. Подключите нужное поле методом [crm.duplicate.volatileType.register](./crm-duplicate-volatile-type-register.md), передав `entityTypeId` и `fieldCode` из первого шага
4. Если поле больше не нужно для поиска, отключите его методом [crm.duplicate.volatileType.unregister](./crm-duplicate-volatile-type-unregister.md), передав `id` записи из [crm.duplicate.volatileType.list](./crm-duplicate-volatile-type-list.md)

### Пример выбора поля

Фрагмент ответа `crm.duplicate.volatileType.fields` для лида:

```json
{
    "result": [
        {
            "entityTypeId": 1,
            "fieldCode": "TITLE",
            "fieldTitle": "Название лида"
        }
    ]
}
```

Чтобы подключить название лида к поиску дубликатов, передайте в `crm.duplicate.volatileType.register` значения из этого элемента: `entityTypeId: 1` и `fieldCode: "TITLE"`.

## Что важно учитывать

- Подключить можно не более семи полей суммарно для лидов, контактов и компаний. Если все семь мест заняты, попытка подключить новое поле методом [crm.duplicate.volatileType.register](./crm-duplicate-volatile-type-register.md) вернет ошибку `MAX_TYPES_COUNT_EXCEEDED`. Повторная регистрация уже подключенного поля вернет его `id`
- После подключения поля индекс дубликатов пересчитывается фоновым агентом, поэтому новые совпадения появятся в интерфейсе не сразу
