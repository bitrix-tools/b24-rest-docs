# Размещение CRM-формы и каналы: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Готовую CRM-форму можно показать посетителям несколькими способами: встроить в страницу сайта, открывать по клику на кнопку, показывать автоматически через заданное время или отправить клиенту публичную ссылку. Методы `crm.form.embedding.*` возвращают код и ссылку для этих вариантов и сохраняют настройки показа. Методы `crm.form.sitebutton.*` и `crm.form.openline.*` показывают, в каких виджетах на сайт и открытых линиях уже используется форма.

## Варианты размещения формы

- `inline` — форма встроена в страницу сайта. Настроек показа у варианта нет
- `click` — форма открывается по клику на кнопку или ссылку. Можно настроить вид и положение окна, а также кнопку Битрикс24: текст, шрифт, выравнивание, цвета
- `auto` — форма открывается автоматически. Можно настроить вид и положение окна и задержку показа в секундах
- `link` — публичная ссылка на форму. Ее можно отправить клиенту в письме или мессенджере

## Порядок работы с размещением

1. Получите идентификатор формы методом [crm.form.list](../crm-form-list.md). Чтобы форма принимала заполнения, она должна быть активна: включить ее можно методом [crm.form.activate](../crm-form-activate.md)
2. Получите все варианты размещения методом [crm.form.embedding.get](./crm-form-embedding-get.md). В ответе есть код для каждого варианта, публичная ссылка, текущие настройки показа и их допустимые значения
3. Если нужно изменить показ по клику или автопоказ, получите `updatedTime` формы методом [crm.form.get](../crm-form-get.md) и передайте новые настройки в [crm.form.embedding.update](./crm-form-embedding-update.md)
4. Вставьте код нужного варианта на страницу сайта или отправьте клиенту публичную ссылку. Чтобы получить только один вариант, передайте в [crm.form.embedding.get](./crm-form-embedding-get.md) параметр `variant`. Для вариантов `click` и `auto` в этом же запросе можно получить код с другим текстом кнопки или задержкой без сохранения настроек
5. Проверьте, где форма уже используется: в виджетах на сайт — методом [crm.form.sitebutton.list](./crm-form-sitebutton-list.md), в открытых линиях — методом [crm.form.openline.list](./crm-form-openline-list.md)

## Особенности работы методов

**Версия формы.** Метод [crm.form.embedding.update](./crm-form-embedding-update.md) принимает обязательный параметр `updatedTime` — версию формы. Если форму изменили после того, как вы получили версию, метод вернет ошибку `CRM_FORM_VERSION_MISMATCH`. Сохранение настроек размещения меняет версию формы, поэтому перед следующим вызовом [crm.form.update](../crm-form-update.md) или [crm.form.embedding.update](./crm-form-embedding-update.md) получите новое значение `updatedTime`.

**Код на сайте обновляется сам.** После сохранения настроек Битрикс24 пересобирает файлы формы. Код, который уже вставлен на сайт, менять не нужно.

**Привязка к виджетам и открытым линиям.** Методы [crm.form.sitebutton.list](./crm-form-sitebutton-list.md) и [crm.form.openline.list](./crm-form-openline-list.md) только читают данные. Подключить форму к виджету на сайт или назначить ее приветственной формой открытой линии через REST нельзя, это делают в интерфейсе Битрикс24.

**Фильтр по форме обязателен.** Методы списков виджетов и открытых линий принимают ровно одно условие фильтра `[["formId", "=", <id формы>]]`, сортировку только по `id` и постраничную навигацию через `pagination`.

## Ограничения

- Изменять настройки размещения может пользователь с правом на изменение CRM-форм. Системные формы изменить нельзя
- Для списка виджетов нужно право на просмотр виджетов на сайт, для списка открытых линий — право на изменение открытых линий и установленный модуль «Открытые линии». Метод [crm.form.openline.list](./crm-form-openline-list.md) возвращает только линии, которые пользователь может изменять
- У открытой линии может быть только одна приветственная форма. Если линию занимает другая форма, ее идентификатор приходит в поле `welcomeFormId`
- Если Битрикс24 требует подтвердить номер телефона для работы с CRM-формами, методы вернут ошибку, пока номер не подтвержден
- На тарифах, где редактирование CRM-форм недоступно, [crm.form.embedding.update](./crm-form-embedding-update.md) вернет ошибку `CRM_FORM_WRITE_RESTRICTED`
