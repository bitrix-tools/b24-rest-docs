# Действия с записями в таймлайне: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга

Методы `crm.timeline.item.*` закрепляют и открепляют записи в таймлайне элемента CRM. В одном элементе можно закрепить до семи записей. Закрепленные записи одновременно отображаются под формой создания дела и на своем месте в таймлайне по хронологии. После открепления запись остается на своем месте в хронологии.

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [Таймлайн в элементе CRM](https://helpdesk.bitrix24.ru/open/23960160/)

## Как начать работу

1. Получите идентификатор записи таймлайна `id`. Методы, которые его возвращают, перечислены в блоке [Связь с другими объектами](#links)
2. Укажите элемент CRM, к которому привязана запись, в `ownerTypeId` и `ownerId`
3. Закрепите запись методом [crm.timeline.item.pin](./crm-timeline-item-pin.md)
4. Открепите запись методом [crm.timeline.item.unpin](./crm-timeline-item-unpin.md), если она больше не должна быть закрепленной или нужно освободить место под новую

## Связь с другими объектами {#links}

**Элемент CRM.** Запись закрепляется в таймлайне конкретного элемента CRM. [Тип объекта](../../data-types.md#object_type) передают в `ownerTypeId`, идентификатор элемента — в `ownerId`. Запись должна быть привязана к этому элементу.

**Записи таймлайна.** Методы принимают в `id` идентификатор записи таймлайна. Это не идентификатор дела. Через REST такой `id` возвращают:

- комментарии — методы [crm.timeline.comment.add](../comments/crm-timeline-comment-add.md) и [crm.timeline.comment.list](../comments/crm-timeline-comment-list.md)
- записи лога — методы [crm.timeline.logmessage.add](../logmessage/crm-timeline-logmessage-add.md) и [crm.timeline.logmessage.list](../logmessage/crm-timeline-logmessage-list.md)
