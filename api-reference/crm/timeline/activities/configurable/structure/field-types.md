# Типы полей

В полях [структуры конфигурируемого дела](./layout.md) встречаются два особых типа значений: текст с переводами и область видимости. Типы остальных полей указаны в таблицах на страницах структуры.

## textWithTranslation {#textwithtranslation}

Текст, который можно передать сразу на нескольких языках.

Если переводы не нужны, в поле передают строку — она и будет показана. Если у приложения пользователи с разными языками интерфейса, вместо строки передают объект: ключ — код языка, значение — текст на этом языке.

```json
{
    "ru": "Сохранить",
    "en": "Save"
}
```

Правила для объекта с переводами:

- ключи — только языки, установленные в Битрикс24, иначе ошибка `WRONG_LANG`
- значение каждого ключа — строка
- объект не должен быть пустым: проверку он пройдет, но в записи окажется пустой текст

Битрикс24 хранит объект целиком, а нужный вариант подставляет при показе записи — по языку интерфейса того, кто смотрит таймлайн. Если перевода на его язык нет, Битрикс24 возьмет английский, а если нет и его — первое значение объекта.

Тип используется в заголовке записи, тегах и бейджах, текстовых блоках и ссылках, кнопках нижней части, пунктах и разделах меню. Рабочий пример — в разделе [Карточка на нескольких языках](./examples.md#kartochka-na-neskolkih-yazykah).

## scope {#scope}

Область видимости — на каких устройствах показывать элемент записи.

#|
|| **Значение** | **Где показывается элемент** ||
|| поле не передано | Везде ||
|| `web` | Только в браузере ||
|| `mobile` | Только в мобильном приложении ||
|#

Поле `scope` есть у [контентных блоков](./content-block.md), [кнопок нижней части](./footer.md) и [пунктов меню](./menu-item.md). У кнопок и пунктов меню Битрикс24 отклонит другое значение с ошибкой `ENUM_FIELD`, у контентных блоков значение не проверяет.
