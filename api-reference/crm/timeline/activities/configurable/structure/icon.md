# Иконка

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

`IconDto` — иконка слева от [записи таймлайна](../index.md). По ней пользователь с первого взгляда понимает, о чем запись: звонок, документ, сообщение. Иконка — не логотип: [`LogoDto`](./body.md#logo-dto) — это крупная картинка внутри контентной области, а иконка занимает узкую колонку слева от всей записи.

Объект передают в поле `icon` [структуры конфигурируемого дела](./layout.md), а саму структуру — в параметре `layout` методов [crm.activity.configurable.add](../crm-activity-configurable-add.md) и [crm.activity.configurable.update](../crm-activity-configurable-update.md). Поле `icon` обязательное: без него метод вернет ошибку `FIELD_IS_REQUIRED`. Условия вызова методов описаны [на странице структуры](./layout.md).

## Параметры объекта `IconDto`

{% include [Сноска об обязательных параметрах](../../../../../../_includes/required.md) %}

#|
|| **Поле** | **Описание** ||
|| **code^*^**
[`string`](../../../../../data-types.md) | Код иконки, например `call-completed` ||
|#

Других полей у объекта нет. Лишнее поле метод отклонит с ошибкой `FIELD_IS_REDUNDANT`, а неизвестный код иконки — с ошибкой `ENUM_FIELD`.

## Как выбрать код иконки

В Битрикс24 есть набор системных иконок для типовых событий таймлайна. Полный перечень возвращает метод [crm.timeline.icon.list](../../../logmessage/icons/crm-timeline-icon-list.md). У каждой иконки в ответе есть `code` и признак `isSystem`: `true` — иконка Битрикс24, `false` — иконка, которую загрузило приложение.

Часто используемые коды:

#|
|| **Код** | **Для какой записи** ||
|| `call`, `call-incoming`, `call-outcoming`, `call-completed`, `call-incoming-missed` | Звонки: общий, входящий, исходящий, завершенный, пропущенный ||
|| `sms`, `telegram`, `whatsapp`, `IM` | Сообщения в соответствующем канале ||
|| `mail-outcome` | Исходящее письмо ||
|| `document` | Документ ||
|| `task` | Задача ||
|| `info` | Информационное сообщение ||
|| `check`, `circle-check`, `complete` | Подтверждение или завершение ||
|| `clock` | Напоминание, ожидание ||
|| `stage-change`, `pipeline` | Изменение стадии, работа с воронкой ||
|#

Если подходящей иконки нет, загрузите свою методом [crm.timeline.icon.add](../../../logmessage/icons/crm-timeline-icon-add.md). Код для нее задает приложение, и после регистрации тот же код передают в поле `code` структуры дела. Метод [crm.timeline.icon.get](../../../logmessage/icons/crm-timeline-icon-get.md) проверяет, что иконка зарегистрирована.

## Пример объекта

Значение поля `icon`: иконка завершенного звонка.

```json
{
    "code": "call-completed"
}
```

Иконка в составе целой структуры — в [примере объекта `LayoutDto`](./layout.md#primer).
