# Дополнительные контентные блоки дела: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Дополнительные контентные блоки — это настраиваемые элементы интерфейса, которые приложение добавляет в карточку дела рядом с основным содержимым.

Блоки нужны, когда стандартного вида дела недостаточно и данные приложения нужно показать прямо в таймлайне элемента CRM без перехода в отдельный интерфейс. С помощью блоков можно вывести поясняющий текст, ссылку, заголовок с вложенным блоком и другие элементы.

> Быстрый переход: [все методы](#all-methods)

## Что учитывать перед вызовом методов

- Методы работают только в контексте [приложения](../../../../../settings/app-installation/index.md). При вызове через вебхук метод вернет ошибку `ERROR_WRONG_CONTEXT`.
- Приложение может получать и удалять только тот набор блоков, который установило само. Наборы других приложений оно не видит и не изменяет.
- Ограничение по приложению действует на набор блоков, а не на дело. Само дело может быть создано другим приложением или сотрудником — важны только права текущего пользователя на элемент CRM.
- При повторном вызове [crm.activity.layout.blocks.set](./crm-activity-layout-blocks-set.md) предыдущий набор блоков этого же приложения перезаписывается.

## Ограничения применения

- Наборы блоков нельзя установить для [конфигурируемого дела](../configurable/index.md): его внешний вид целиком задают методы [crm.activity.configurable.*](../configurable/index.md).
- Наборы блоков нельзя установить для дела устаревшего типа.
- Методы работают только с делами. Чтобы добавить блоки в комментарий или другую запись таймлайна, используйте методы [crm.timeline.layout.blocks.*](../../layout-blocks/index.md).

Если дело не подходит по типу, метод вернет ошибку `UNSUITABLE_ACTIVITY_TYPE_ERROR`.

## Дело, привязанное к нескольким элементам

Дело может быть связано сразу с несколькими элементами CRM, например письмо — со сделкой и с контактом. Набор блоков, добавленный такому делу, отрисуется в таймлайне каждого связанного элемента. Связями управляют методы [crm.activity.binding.*](../binding/index.md).

## Жизненный цикл наборов блоков

- При восстановлении дела из корзины наборы блоков, добавленные приложениями, восстанавливаются вместе с делом.
- При удалении приложения безвозвратно удаляются все наборы блоков, которые это приложение добавило в дела.

## Как работать с дополнительными блоками

1. Найдите дело: его идентификатор возвращают методы [crm.activity.add](../activity-base/crm-activity-add.md) и [crm.activity.list](../activity-base/crm-activity-list.md). Тип и идентификатор элемента CRM передаются в `entityTypeId` и `entityId`.
2. Подготовьте описание набора блоков в формате [RestAppLayoutDto](../configurable/structure/rest-app-layout-dto.md).
3. Установите набор методом [crm.activity.layout.blocks.set](./crm-activity-layout-blocks-set.md).
4. Получите установленный набор методом [crm.activity.layout.blocks.get](./crm-activity-layout-blocks-get.md).
5. Удалите набор методом [crm.activity.layout.blocks.delete](./crm-activity-layout-blocks-delete.md), если он больше не нужен.
6. Если нужен готовый рабочий сценарий, посмотрите [пример тестового приложения](../../layout-blocks/content-blocks-test-app.md).

## Обзор методов {#all-methods}

> Scope: [`crm`](../../../../scopes/permissions.md)
>
> Кто может выполнять метод: пользователь с правом на чтение элемента CRM — для [crm.activity.layout.blocks.get](./crm-activity-layout-blocks-get.md), с правом на изменение элемента — для [crm.activity.layout.blocks.set](./crm-activity-layout-blocks-set.md) и [crm.activity.layout.blocks.delete](./crm-activity-layout-blocks-delete.md)
