# Шаблоны реквизитов CRM: обзор методов

Шаблон реквизитов определяет, из каких полей состоит [реквизит](../index.md) контакта или компании. Каждый реквизит создается по одному из шаблонов, например:
* шаблон Организация состоит из полей юридических лиц типа ООО: `ОГРН`, `ОКТМО`
* шаблон ИП состоит из других полей: `ОГРНИП`, `ОКВЭД`

Набор полей зависит от страны: шаблон привязан к идентификатору страны, и добавить в него можно только поля, поддерживаемые этой страной.

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [Как создать и настроить шаблоны реквизитов в CRM](https://helpdesk.bitrix24.ru/open/7385595/)

## Как начать работу

1. Получите список стран методом [crm.requisite.preset.countries](./crm-requisite-preset-countries.md) — нужен идентификатор страны для нового шаблона
2. Создайте шаблон методом [crm.requisite.preset.add](./crm-requisite-preset-add.md). В нем передайте тип родительского объекта, страну и название
3. Настройте набор полей шаблона методами раздела [настраиваемых полей](./fields/index.md)
4. Получите список шаблонов методом [crm.requisite.preset.list](./crm-requisite-preset-list.md) — идентификатор шаблона нужен, чтобы создать реквизит методом [crm.requisite.add](../universal/crm-requisite-add.md)

## Идентификаторы шаблона

- `ID` — идентификатор шаблона. Его возвращают методы [crm.requisite.preset.add](./crm-requisite-preset-add.md), [crm.requisite.preset.get](./crm-requisite-preset-get.md) и [crm.requisite.preset.list](./crm-requisite-preset-list.md). Этот идентификатор передается в поле `PRESET_ID` при создании реквизита
- `ENTITY_TYPE_ID` — тип родительского объекта. Для шаблонов реквизитов это всегда `8` — «Реквизит». Все значения отдает метод [crm.enum.ownertype](../../auxiliary/enum/crm-enum-owner-type.md)
- `COUNTRY_ID` — идентификатор страны. Доступные значения возвращает метод [crm.requisite.preset.countries](./crm-requisite-preset-countries.md)
- `XML_ID` — внешний ключ для обмена данными. Значения вида `#CRM_REQUISITE_PRESET_DEF_...` зарезервированы за шаблонами по умолчанию, использовать их для своих целей нельзя

## Обзор методов {#all-methods}

> Scope: [`crm`](../../../scopes/permissions.md)
>
> Кто может выполнять методы: пользователь с правами на контакты и компании

Права на шаблоны проверяются сразу по двум объектам CRM — контактам и компаниям. Чтобы получить шаблон, нужен доступ на чтение обоих объектов. Чтобы создать, изменить или удалить шаблон, нужно право на добавление, изменение или удаление обоих объектов.
