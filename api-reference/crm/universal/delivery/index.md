Методы `crm.item.delivery.*` работают с доставками универсальных объектов CRM. Например, можно получить список доставок сделки или краткую информацию об одной доставке счета.

Доставка — это отгрузка заказа. Битрикс24 хранит ее отдельно от полей объекта CRM: доставка принадлежит заказу, а заказ привязан к сделке или счету.

{% note info "" %}

Методы `crm.item.delivery.*` работают только на чтение и возвращают краткий набор полей доставки. Создать отгрузку или получить все ее поля можно в интерфейсе Битрикс24 или методами [sale.shipment.*](../../../sale/shipment/index.md), которые доступны только администратору.

{% endnote %}

## Связь доставок с другими объектами

**Объект CRM.** Метод [crm.item.delivery.list](./crm-item-delivery-list.md) находит доставки по паре параметров `entityTypeId` и `entityId`. Первый указывает на [тип объекта CRM](../../data-types.md#object_type), второй — на конкретный элемент этого типа.

#|
|| **Объект CRM** | **`entityTypeId`** ||
|| Сделка | `2` ||
|| Счет | `31` ||
|#

У остальных объектов, например у лида или смарт-процесса, доставок не бывает — для них метод `crm.item.delivery.list` вернет пустой список.

**Заказ.** Заказ интернет-магазина связан с объектом CRM отдельной записью о привязке. Проверить и создать такую привязку можно группой методов [crm.orderentity.*](../order-entity/index.md).

**Служба доставки.** Каждая доставка содержит идентификатор службы доставки `deliveryId`. Список служб доставки с их идентификаторами возвращает метод [sale.delivery.getlist](../../../sale/delivery/delivery/sale-delivery-get-list.md).

**Оплата.** Одна доставка может быть частично или полностью оплачена. Позициями доставки внутри оплаты управляет группа методов [crm.item.payment.delivery.*](../payment/delivery-in-payment/index.md), самими оплатами — группа методов [crm.item.payment.*](../payment/index.md).

## Как работать с доставками в CRM

1. Определите тип объекта CRM `entityTypeId` и идентификатор самого объекта `entityId`.
2. Получите список доставок объекта методом [crm.item.delivery.list](./crm-item-delivery-list.md).
3. Выберите нужную доставку из списка и получите информацию по ее `id` методом [crm.item.delivery.get](./crm-item-delivery-get.md).
