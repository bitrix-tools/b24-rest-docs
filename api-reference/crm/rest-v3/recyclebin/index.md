Удаленные сделки, лиды, контакты, компании и элементы смарт-процессов попадают в корзину CRM, если она включена для типа объекта. Методы группы возвращают записи корзины и восстанавливают из нее элементы.

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [Что такое Корзина в CRM](https://helpdesk.bitrix24.ru/open/24668648/)

## Как начать работу

1. Удалите элемент методом [crm.<тип>.delete](../items/crm-entity-delete-rest-v3.md) — он попадет в корзину
2. Найдите запись корзины методом [crm.recyclebin.list](./crm-recyclebin-list-rest-v3.md), например с фильтром `[["entityTypeId","=",2],["title","=","Поставка оборудования"]]`. Запомните `recordId` записи
3. Восстановите элемент методом [crm.recyclebin.restore](./crm-recyclebin-restore-rest-v3.md) с этим `recordId`
4. Возьмите новый идентификатор элемента из `result.item.id` ответа и работайте с элементом методами [crm.<тип>.*](../items/index.md)

## Особенности

- **Два идентификатора.** В записи корзины `recordId` — идентификатор записи, `id` — идентификатор элемента до удаления. В [crm.recyclebin.restore](./crm-recyclebin-restore-rest-v3.md) передается `recordId`
- **Новый идентификатор после восстановления.** Восстановленный элемент получает новый `id`. Ссылки на элемент по старому идентификатору в своих данных обновите по ответу метода
- **История не переносится.** Записи, которые методы [истории изменений](../history/index.md) хранят у прежнего идентификатора, по новому идентификатору не возвращаются
- **Какие типы попадают в корзину.** Сделки, лиды, контакты, компании и элементы смарт-процессов, у которых включена корзина. Счета и предложения в эти методы не входят. У смарт-процесса корзину включает настройка типа `isRecyclebinEnabled`, ее значение возвращает метод [crm.type.list](../../universal/user-defined-object-types/crm-type-list.md)
- **Срок хранения.** В облачном Битрикс24 записи доступны 30 дней после удаления, в коробочной версии — срок из настроек корзины CRM. Более старые записи методы не возвращают и не восстанавливают
- **Права.** Администратор видит и восстанавливает все записи корзины CRM. Остальные пользователи — только элементы, которые удалили сами
- **Тариф.** Если корзина недоступна на тарифе Битрикс24, [crm.recyclebin.list](./crm-recyclebin-list-rest-v3.md) возвращает пустой список, а [crm.recyclebin.restore](./crm-recyclebin-restore-rest-v3.md) — ошибку `RECYCLEBIN_ITEM_UNAVAILABLE`
- **Окончательного удаления нет.** Методов REST, которые удаляют запись из корзины без восстановления, нет. Записи удаляются по истечении срока хранения или вручную в интерфейсе корзины

## Связь с другими объектами

**Элементы CRM.** Тип удаленного элемента — в поле `entityTypeId` записи корзины: `1` — лид, `2` — сделка, `3` — контакт, `4` — компания или идентификатор типа смарт-процесса. Список типов возвращает метод [crm.dictionary.entitytype.list](../dictionaries/crm-dictionary-list-rest-v3.md). Восстановленный элемент получают методом [crm.<тип>.get](../items/crm-entity-get-rest-v3.md).

**Пользователи.** Кто удалил элемент, указано в поле `deletedById`. Данные пользователя возвращает метод [user.get](../../../user/user-get.md).

## Поля записи корзины

Поля записи описаны на странице [crm.recyclebin.list](./crm-recyclebin-list-rest-v3.md#item). Описание полей с признаками `filterable` и `sortable` возвращают методы [crm.recyclebin.field.list](./crm-recyclebin-field-list-rest-v3.md) и [crm.recyclebin.field.get](./crm-recyclebin-field-get-rest-v3.md).
