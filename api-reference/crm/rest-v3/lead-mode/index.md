# Режим лидов CRM в REST 3.0: обзор методов

{% note tip "" %}

{% note info "" %}

Методы относятся к REST 3.0. Особенности вызова и формат ответа новой версии API описаны в [обзоре REST 3.0](../../../rest-v3.md).

{% endnote %}

CRM работает в одном из двух режимов: в классическом с лидами или в простом без лидов. Методы группы проверяют текущий режим и переключают его. Например, приложение, которое передает в CRM заявки с сайта, может сначала проверить режим и выбрать, что создать: лид или сразу сделку.

> Быстрый переход: [все методы](#all-methods)

## Классический и простой режим

#|
|| **Режим** | **Как работают лиды** | **Значение enabled** ||
|| Классический | Заявки можно принимать лидами. Менеджер работает с лидом и потом конвертирует его в сделку, контакт или компанию | `"enabled": true` ||
|| Простой | Новая заявка сразу становится сделкой | `"enabled": false` ||
|#

Подробнее о режимах — в статье [Режимы работы CRM](https://helpdesk.bitrix24.ru/open/17611420/) пользовательской документации.

## Как начать работу

1. Узнайте текущий режим методом [crm.lead.isenabled](./crm-lead-is-enabled-rest-v3.md)
2. Если метод вернул `"enabled": true`, создавайте лиды методом [crm.lead.add](../items/crm-entity-add-rest-v3.md). Если `false` — создавайте сделку методом [crm.deal.add](../items/crm-entity-add-rest-v3.md)
3. Чтобы сменить режим, вызовите [crm.lead.enable](./crm-lead-enable-rest-v3.md) или [crm.lead.disable](./crm-lead-disable-rest-v3.md). Режим меняется для всего Битрикс24, а не для одного пользователя

## Что меняется при переключении {#switch}

Когда лиды выключены:

- лиды, созданные до переключения, остаются в CRM, но методы группы [crm.lead.*](../items/index.md) с ними не работают. Любой вызов, например [crm.lead.list](../items/crm-entity-list-rest-v3.md), отвечает ошибкой `BITRIX_REST_V3_EXCEPTION_ACCESSDENIEDEXCEPTION` «Доступ запрещен» с HTTP-статусом 403. На методы проверки и переключения режима это не влияет
- Битрикс24 конвертирует каждый новый лид сразу после создания, по умолчанию — в сделку и контакт. Так происходит с лидом из любого источника, например из формы, звонка или чата. Роботы лида для него не запускаются

При любом переключении Битрикс24 сбрасывает настройки меню CRM у всех пользователей. Метод [crm.lead.enable](./crm-lead-enable-rest-v3.md) также включает настройку конвертации «Создавать контакты, компании, сделки, счета и предложения без участия пользователя». Метод [crm.lead.disable](./crm-lead-disable-rest-v3.md) эту настройку не выключает. Если режим в Битрикс24 ни разу не переключали, первый вызов [crm.lead.enable](./crm-lead-enable-rest-v3.md) сделает то же самое, даже когда лиды уже работают.

Сделки, контакты и компании при переключении не меняются.

## Права и ограничения

Все три метода, в том числе [crm.lead.isenabled](./crm-lead-is-enabled-rest-v3.md), может вызвать только администратор CRM. Для остальных пользователей режим возвращает метод предыдущей версии [crm.settings.mode.get](../../crm-settings-mode-get.md).

Если тариф Битрикс24 не включает лиды, [crm.lead.isenabled](./crm-lead-is-enabled-rest-v3.md) возвращает `false`, а [crm.lead.enable](./crm-lead-enable-rest-v3.md) отвечает ошибкой [«Функция недоступна на тарифе»](./crm-lead-enable-rest-v3.md#plan-restriction) и режим не меняет. Методы группы [crm.lead.*](../items/index.md) на таком тарифе отвечают той же ошибкой.
