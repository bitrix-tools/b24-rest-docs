## Лимиты и формат ответа

Правила ниже относятся к трем поисковым методам — `im.search.chat.list`, `im.search.department.list` и `im.search.user.list`. У методов истории поиска `im.search.last.*` ни поисковой фразы, ни пагинации нет.

- поиск идет по началу слов, а не по произвольной подстроке: «Небесн» найдет «Небесный чат», «ебесн» — нет
- [im.search.chat.list](./im-search-chat-list.md) и [im.search.user.list](./im-search-user-list.md) требуют минимум два символа: на более короткой фразе они возвращают ошибку `FIND_SHORT`
- [im.search.department.list](./im-search-department-list.md) ведет себя иначе: ошибку `FIND_SHORT` он возвращает, только если параметр `FIND` вообще не передан. Пустая или очень короткая фраза отключает фильтр, и метод отдает весь список подразделений — проверяйте длину фразы на своей стороне
- [im.search.chat.list](./im-search-chat-list.md) при одновременной передаче `FIND` и `FIND_LINES` отдает приоритет `FIND`, а поиск по Открытым линиям не выполняет
- выборка постраничная: смещение задает `OFFSET`, размер страницы — `LIMIT`. Ответ содержит `total`, а при наличии следующей страницы — `next`
- поля ответа возвращаются в `snake_case`
- формы ответа различаются: [im.search.chat.list](./im-search-chat-list.md) и [im.search.department.list](./im-search-department-list.md) возвращают `result` массивом, а [im.search.user.list](./im-search-user-list.md) — объектом, где ключ каждого элемента равен идентификатору пользователя. Пустая выборка у всех трех приходит пустым массивом

## Связь с другими объектами

**Чат.** Метод поиска возвращает `id` чата. Подставьте его в `DIALOG_ID` в формате `chatXXX`, чтобы отправить сообщение методом [im.message.add](../messages/im-message-add.md), или в `CHAT_ID` методов подраздела [Участники чата](../chat-users/index.md). Данные найденного чата вернет [im.dialog.get](../im-dialog-get.md).

**Пользователь.** Найденный `id` сотрудника подходит для личного диалога: передайте его в `DIALOG_ID` как число. Этот же идентификатор принимают методы подраздела [Пользователи в чатах](../users/index.md) и параметр `USERS` метода [im.chat.user.add](../chat-users/im-chat-user-add.md).

**Подразделение.** Найденный `id` подразделения принимают методы подраздела [Подразделения](../departments/index.md) — они возвращают руководителей и сотрудников подразделения. Идентификатор передается массивом: `ID: [107]`.

### Устаревшие методы

Методы `im.search.last.*` хранят историю поисковых запросов пользователя. Они устаревшие: разработаны для предыдущей версии чата и оставлены только для поддержки существующих интеграций. В текущей версии чата М1 методы работают, но результаты не отображаются в интерфейсе — подробнее о текущей версии в статье [Битрикс24 Чат: новый мессенджер](https://helpdesk.bitrix24.ru/open/19071750/). Замены им нет.
