# Сообщения: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Сообщения — это переписка в чатах Битрикс24: личная с коллегой, в групповом чате или в чате проекта. Методы группы отправляют, изменяют и удаляют сообщения, читают историю переписки, отмечают прочтение и добавляют в сообщение свои пункты контекстного меню. Например, приложение может написать ответственному в личный диалог, что пришла новая заявка. Подраздел входит в раздел [Чаты в Битрикс24](../index.md).

Методы `im.message.*` и `im.dialog.*` актуальны, устаревших вариантов у них нет.

## Идентификатор диалога

Любую переписку, личную или групповую, методы называют диалогом и работают с ней одинаково. Отличается только значение `DIALOG_ID`:

#|
|| **Формат** | **Диалог** | **Пример** ||
|| `XXX` | Личный диалог с пользователем, где `XXX` — идентификатор пользователя | `47` ||
|| `chatXXX` | Групповой чат, где `XXX` — идентификатор чата | `chat2935` ||
|| `sgXXX` | Чат группы или проекта, где `XXX` — идентификатор группы | `sg17` ||
|#

Метод [im.dialog.messages.search](./im-dialog-messages-search.md) принимает вместо `DIALOG_ID` числовой `CHAT_ID` — идентификатор чата без префикса `chat`: для `chat2935` это `2935`.

Метод [im.dialog.writing](./im-dialog-writing.md) формат `sgXXX` не поддерживает: для чата группы передайте идентификатор в формате `chatXXX`.

|#

## Как начать работу

1. Отправьте сообщение методом [im.message.add](./im-message-add.md)
2. При необходимости измените или удалите сообщение методами [im.message.update](./im-message-update.md) и [im.message.delete](./im-message-delete.md)
3. Получите сообщения диалога методом [im.dialog.messages.get](./im-dialog-messages-get.md)
4. Найдите нужное сообщение методом [im.dialog.messages.search](./im-dialog-messages-search.md)
5. Отметьте сообщения прочитанными или непрочитанными методами [im.dialog.read](./im-dialog-read.md) и [im.dialog.unread](./im-dialog-unread.md)

## Связь сообщений с другими объектами

**Пользователь.** Чтобы написать пользователю в личный диалог, передайте в `DIALOG_ID` его идентификатор, например `47`. Идентификатор вернут методы [user.get](../../user/user-get.md) и [user.search](../../user/user-search.md).

**Чат.** Идентификатор группового чата возвращает метод [im.chat.get](../im-chat-get.md). Заголовок, цвет, аватар и владельца чата меняют методы подраздела [Обновление чата](../chat-update/index.md).

**Участники чата.** Сообщение видят участники чата, поэтому адресата сначала нужно добавить в чат. Составом управляют методы подраздела [Участники чата](../chat-users/index.md).

**Чат-бот.** Команду чат-бота в контексте сообщения выполняет метод [im.message.command](./im-message-command.md): передайте в него `MESSAGE_ID`, `BOT_ID` и `COMMAND`. Список ботов возвращает метод [imbot.v2.Bot.list](../../chat-bots/chat-bots-v2/imbot.v2/bots/bot-list.md).

**Содержимое сообщения.** Примеры форматирования текста, вложений, кнопок и пунктов меню для методов `im.message.*` — на страницах [Форматирование](./formatting.md), [Вложения](./attachments.md), [Клавиатуры](./keyboards.md) и [Контекстное меню](./menu.md). Полные справочники полей — в разделе Чат-боты 2.0: [Форматирование imbot.v2](../../chat-bots/chat-bots-v2/imbot.v2/messages/message-formatting.md), [Вложения imbot.v2](../../chat-bots/chat-bots-v2/imbot.v2/messages/attachments/index.md), [Клавиатуры imbot.v2](../../chat-bots/chat-bots-v2/imbot.v2/messages/message-keyboards.md).

**Файлы.** Файл в чат отправляет метод [im.v2.File.upload](../../chat-bots/chat-bots-v2/im.v2/files/file-upload.md): он загружает файл и сам создает сообщение. Методом [im.message.add](./im-message-add.md) файл не отправить. Подробности — в подразделе [Файлы](../files/index.md).

**Список чатов.** Методы [im.dialog.read](./im-dialog-read.md) и [im.dialog.unread](./im-dialog-unread.md) отмечают прочтение в одном диалоге. Отметить прочитанными сразу все чаты пользователя можно методом [im.dialog.read.all](../special-operations/im-dialog-read-all.md). Метками в списке чатов управляют методы подраздела [Специальные операции](../special-operations/index.md).

## Как выбрать метод

#|

|| Получить историю диалога | [im.dialog.messages.get](./im-dialog-messages-get.md) — возвращает сообщения чата. Более ранние сообщения загружают через `LAST_ID`, более новые — через `FIRST_ID` ||

|| Отметить прочтение | [im.dialog.read](./im-dialog-read.md) — отмечает прочитанными сообщения до указанного, [im.dialog.unread](./im-dialog-unread.md) — отмечает непрочитанными начиная с указанного ||
|| Показать, что пользователь печатает | [im.dialog.writing](./im-dialog-writing.md) ||
|#

## Ответ методов

- метод отправки [im.message.add](./im-message-add.md) возвращает идентификатор созданного сообщения в поле `result`, тип `integer`. Его принимают параметры `MESSAGE_ID` других методов
- имена полей в ответе у методов разные. [im.dialog.messages.get](./im-dialog-messages-get.md) возвращает поля в `snake_case`, например `chat_id`, [im.dialog.read](./im-dialog-read.md) — в `camelCase`, например `chatId`. [im.dialog.messages.search](./im-dialog-messages-search.md) в объекте сообщения возвращает оба варианта
