# Сообщения: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Методы сообщений отправляют и изменяют сообщения, читают историю диалога, управляют признаком прочтения и контекстным меню сообщения.

Сообщение отправляют в диалог, а не в чат: адресат задается параметром `DIALOG_ID`. Один и тот же набор методов работает и для личной переписки, и для группового чата — меняется только значение `DIALOG_ID`. Подраздел входит в раздел [Чаты в Битрикс24](../index.md).

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [Чаты в Битрикс24: интерфейс и возможности](https://helpdesk.bitrix24.ru/open/21912520/)

## Идентификатор диалога

`DIALOG_ID` определяет, куда уйдет сообщение:

#|
|| **Формат** | **Куда отправляется** | **Пример** ||
|| `XXX` | Личный диалог с пользователем, где `XXX` — идентификатор пользователя | `47` ||
|| `chatXXX` | Групповой чат, где `XXX` — идентификатор чата | `chat2935` ||
|| `sgXXX` | Чат рабочей группы или проекта, где `XXX` — идентификатор группы | `sg17` ||
|#

В методах поиска по сообщениям вместо `DIALOG_ID` используется числовой `CHAT_ID` — это идентификатор чата без префикса `chat`.

## Лимиты и формат ответа

- размер сериализованного вложения `ATTACH` ограничен 60 000 символов, у `KEYBOARD` и `MENU` тоже есть предел. Коды ошибок при превышении у методов отправки и изменения различаются — смотрите раздел «Обработка ошибок» на странице нужного метода. Полный справочник по вложениям — в разделе [Вложения imbot.v2](../../chat-bots/chat-bots-v2/imbot.v2/messages/attachments/index.md)
- методы чтения истории отдают сообщения постранично: размер страницы и его максимум различаются, точные значения — в параметрах нужного метода
- редактирование и удаление сообщения ограничены по времени: срок задается настройками Битрикс24, после его истечения методы возвращают ошибку `CANT_EDIT_MESSAGE`
- поля ответа именуются по-разному, и обобщать один метод на весь подраздел нельзя:
    - [im.dialog.messages.get](./im-dialog-messages-get.md) отдает `snake_case`: `chat_id`, `author_id`
    - [im.dialog.read](./im-dialog-read.md) отдает `camelCase`: `dialogId`, `chatId`, `lastId`, `counter`
    - [im.dialog.messages.search](./im-dialog-messages-search.md) на верхнем уровне отдает `camelCase`, а внутри объекта сообщения одновременно возвращает `chatId` и `chat_id`, `authorId` и `author_id`

## Актуальность методов

Методы `im.message.*` и `im.dialog.*` актуальны, устаревших вариантов у них нет. Они отправляют сообщения от имени пользователя. Две смежные задачи решаются за пределами подраздела:

- сообщения от имени чат-бота отправляют методы подраздела [Сообщения imbot.v2](../../chat-bots/chat-bots-v2/imbot.v2/messages/index.md)
- сценарий открытия приложения из контекстного меню сообщения устарел, вместо него используйте [встройки мессенджера](../../widgets/im/index.md)

## Как начать работу

1. Отправьте сообщение методом [im.message.add](./im-message-add.md)
2. При необходимости измените или удалите сообщение методами [im.message.update](./im-message-update.md) и [im.message.delete](./im-message-delete.md)
3. Получите сообщения диалога методом [im.dialog.messages.get](./im-dialog-messages-get.md)
4. Найдите нужное сообщение методом [im.dialog.messages.search](./im-dialog-messages-search.md)
5. Управляйте признаком «прочитано» методами [im.dialog.read](./im-dialog-read.md), [im.dialog.unread](./im-dialog-unread.md) и индикатором «Пользователь пишет» через [im.dialog.writing](./im-dialog-writing.md)

## Связь с другими объектами

**Пользователь.** Для отправки сообщения в личный диалог укажите идентификатор пользователя в `DIALOG_ID` в формате `XXX`. Получить идентификатор пользователя можно методами [user.get](../../user/user-get.md) и [user.search](../../user/user-search.md).

**Чат.** Идентификатор группового чата возвращает метод [im.chat.get](../im-chat-get.md). Заголовок, цвет, аватар и владельца чата меняют методы подраздела [Обновление чата](../chat-update/index.md).

**Чат-бот.** Для выполнения команд чат-бота в контексте сообщения используйте метод [im.message.command](./im-message-command.md) и передавайте `BOT_ID`, `COMMAND`. Список ботов возвращает метод [imbot.v2.Bot.list](../../chat-bots/chat-bots-v2/imbot.v2/bots/bot-list.md) — он вызывается с токеном бота.

**Файлы.** Отправить файл в чат отдельным вызовом [im.message.add](./im-message-add.md) нельзя: файл загружает метод [im.v2.File.upload](../../chat-bots/chat-bots-v2/im.v2/files/file-upload.md), он же создает сообщение. Подробности — в подразделе [Файлы](../files/index.md).

**Участники чата.** Сообщение видят участники чата, поэтому адресата сначала нужно в чат добавить. Составом управляют методы подраздела [Участники чата](../chat-users/index.md).

**Уведомления.** Если сообщение не должно попадать в переписку, отправьте уведомление методами подраздела [Уведомления](../notifications/index.md).

**Список чатов.** Методы [im.dialog.read](./im-dialog-read.md) и [im.dialog.unread](./im-dialog-unread.md) работают с прочтением внутри диалога. Отметить прочитанными сразу все чаты пользователя можно методом [im.dialog.read.all](../special-operations/im-dialog-read-all.md), а метками на уровне списка чатов управляют методы подраздела [Специальные операции](../special-operations/index.md).
