# Подразделения в чатах: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Методы `im.department.*` получают информацию о пользователях подразделений из структуры компании. Они помогают собрать состав подразделения, найти руководителей и коллег, чтобы затем добавить этих людей в чат или отправить им уведомление. Подраздел входит в раздел [Чаты в Битрикс24](../index.md).

Методы `im.department.*` актуальны, аналогов в `im.v2` и устаревших вариантов у них нет.

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [Структура компании: интерфейс и возможности](https://helpdesk.bitrix24.ru/open/23039004/)

## Связь методов с другими объектами

**Подразделение.** Методы получают информацию о пользователях по идентификатору подразделения `ID`. Получить идентификатор подразделения можно методом [получения списка подразделений](../../departments/department-get.md) из раздела [Структура компании](../../departments/index.md) или методом [поиска подразделений по названию](../search/im-search-department-list.md).

**Пользователь.** Методы возвращают идентификаторы сотрудников. Эти идентификаторы подходят для методов чата: их можно передать в `USERS` метода [im.chat.user.add](../chat-users/im-chat-user-add.md) или в `USER_ID` метода [im.notify](../notifications/im-notify.md). Подробные данные пользователя мессенджера возвращают методы подраздела [Пользователи в чатах](../users/index.md).

## Особенности методов

- по умолчанию методы возвращают только идентификаторы пользователей, а [im.department.get](./im-department-get.md) — поля самого подразделения. Чтобы добавить в ответ подробные данные пользователей, передайте `USER_DATA` со значением `Y`
- постраничная навигация есть только у метода [im.department.colleagues.list](./im-department-colleagues-list.md): она задается параметрами `OFFSET` и `LIMIT`, ответ содержит `total` и `next`. Остальные методы возвращают результат целиком
- методы работают только для сотрудников компании: экстранет-пользователям и ботам они недоступны
