Групповые чаты помогают общаться нескольким пользователям одновременно. Составом участников управляет группа методов `im.chat.user.*`, к ней примыкают [im.dialog.users.list](./im-dialog-users-list.md) и [im.chat.leave](./im-chat-leave.md). Подраздел входит в раздел [Чаты в Битрикс24](../index.md).

Методы подраздела актуальны, устаревших вариантов у них нет. Если те же операции нужно выполнять от имени чат-бота, используйте методы `imbot.v2.Chat.User.*` из подраздела [Чаты imbot.v2](../../chat-bots/chat-bots-v2/imbot.v2/chats/index.md).

## Как начать работу

1. Получите идентификатор чата `CHAT_ID` методом [im.chat.add](../im-chat-add.md) или [im.chat.get](../im-chat-get.md)
2. Получите идентификаторы пользователей методом [user.get](../../user/user-get.md)
3. Добавьте участников методом [im.chat.user.add](./im-chat-user-add.md) и решите, показывать ли им историю переписки
4. Проверьте состав чата методом [im.chat.user.list](./im-chat-user-list.md) или [im.dialog.users.list](./im-dialog-users-list.md)
5. При необходимости исключите участника методом [im.chat.user.delete](./im-chat-user-delete.md) или выйдите из чата методом [im.chat.leave](./im-chat-leave.md)

## Связь участников чата с другими объектами

**Пользователь.** Для добавления участников в чат передайте список их идентификаторов в параметре `USERS`. Чтобы исключить участника, укажите его идентификатор в параметре `USER_ID`. Получить идентификатор пользователя можно методом [user.get](../../user/user-get.md).

**Чат.** Пользователи привязываются к чату по идентификатору чата `CHAT_ID`. Получить идентификатор чата можно методом [создания чата](../im-chat-add.md) или [получения идентификатора чата](../im-chat-get.md). Методы `im.chat.user.*` и [im.chat.leave](./im-chat-leave.md) принимают числовой `CHAT_ID`, а [im.dialog.users.list](./im-dialog-users-list.md) работает с `DIALOG_ID`: `chatXXX` — групповой чат, `sgXXX` — чат группы или проекта, `XXX` — идентификатор пользователя для личного чата.

**Владелец чата.** Владелец появляется автоматически при создании чата. Передать роль другому участнику можно методом [im.chat.setOwner](../chat-update/im-chat-set-owner.md) из подраздела [Обновление чата](../chat-update/index.md).

**Данные пользователя.** Методы подраздела возвращают идентификаторы и карточки участников в формате мессенджера. Полный профиль сотрудника отдают методы раздела [Пользователи](../../user/index.md), а данные для мессенджера — методы подраздела [Пользователи в чатах](../users/index.md). Найти сотрудника по имени можно методом [im.search.user.list](../search/im-search-user-list.md).

## Обзор методов {#all-methods}

> Scope: [`im`](../../scopes/permissions.md)
>
> Кто может выполнять метод: в зависимости от метода

Все методы подраздела доступны участнику чата. Добавлять и исключать участников может участник с соответствующим правом в чате, а [im.dialog.users.list](./im-dialog-users-list.md) — любой пользователь с доступом к чату. Если права не хватает, метод вернет ошибку `ACCESS_DENIED_EXTEND` или `ACCESS_ERROR`.
