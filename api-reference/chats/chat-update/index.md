После создания чата можно назначить другого владельца или изменить оформление: заголовок, цвет и аватар. В интерфейсе мессенджера заголовок называется названием чата, а аватар — иконкой. Каждое свойство меняет свой метод — чтобы изменить несколько свойств, вызовите нужные методы по очереди. Подраздел входит в раздел [Чаты в Битрикс24](../index.md).

Методы подраздела актуальны, устаревших вариантов у них нет — используйте их для обновления чата.

## Кто может менять чат

Сменить владельца может только текущий владелец чата.

Кто может менять оформление, задает настройка чата. Ее текущее значение возвращает метод [im.dialog.get](../im-dialog-get.md) в поле `manage_ui` объекта `permissions`:

- `member` — оформление меняет любой участник чата
- `manager` — владелец и администраторы чата
- `owner` — только владелец

Если нужного права нет, метод вернет ошибку. Точные коды перечислены в разделе «Обработка ошибок» на странице каждого метода.

Добавить будущего владельца в чат можно методами подраздела [Участники чата](../chat-users/index.md). Системные сообщения об изменениях приходят в переписку — работа с ними описана в подразделе [Сообщения](../messages/index.md).

## Связь методов с другими объектами

**Чат.** Чтобы изменить свойства чата, передайте в метод идентификатор чата `CHAT_ID`. Получить идентификатор чата можно методом:

- [создания чата](../im-chat-add.md)
- [получения идентификатора чата](../im-chat-get.md)
- [получения списка чатов](../im-recent-list.md)
- [получения сокращенного списка последних чатов](../im-recent-get.md)

В `CHAT_ID` передавайте только число: значение с префиксом, например `chat123`, метод отклонит с ошибкой `CHAT_ID_EMPTY`. Если удобнее работать с идентификатором диалога, передайте вместо `CHAT_ID` параметр `DIALOG_ID` со значением вида `chat123`.

Методы работают только с групповыми чатами. Для личного диалога они возвращают ошибку `DIALOG_ID_EMPTY`.

Проверить результат изменения можно методом [im.dialog.get](../im-dialog-get.md): он возвращает текущий заголовок, владельца, аватар и цвет чата. Цвет приходит HEX-кодом, например `#4ba984`, а не значением из списка `COLOR`.

**Пользователь.** Чтобы сменить владельца чата, укажите его идентификатор в параметре `USER_ID`. Получить идентификатор пользователя можно методом [получения списка пользователей](../../user/user-get.md) или методом [получения списка участников чата](../chat-users/im-chat-user-list.md).

## Что передать при изменении

#|
|| **Что изменить** | **Что передать** ||
|| Владелец чата | Идентификатор нового владельца — он должен быть участником чата ||
|| Заголовок чата | Новый заголовок строкой ||
|| Аватар чата | Само изображение строкой Base64, а не ссылку на файл ||
|| Цвет чата | Название цвета из фиксированного списка значений ||
|#

Какой метод отвечает за каждое свойство — в [обзоре методов](#all-methods).

Каждое изменение отражается в переписке системным сообщением, например: *Иван Иванов изменил цвет чата на «Мятный».*

Цвет система выбирает случайно при создании чата. Он отображается в мобильном приложении и там, где у чата нет аватара. Заголовок, не заданный при создании чата, система формирует автоматически — такой чат тоже можно переименовать.
