# Файлы в чатах: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Файл в чате — это объект Диска, привязанный к сообщению. Для новой разработки с файлами работают методы `im.v2.File.*`: один вызов загружает файл, создает сообщение с ним и возвращает данные файла. Подраздел входит в раздел [Чаты в Битрикс24](../index.md).

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [Чаты в Битрикс24: интерфейс и возможности](https://helpdesk.bitrix24.ru/open/21912520/)

## Порядок работы с файлами

1. Загрузите файл методом [im.v2.File.upload](../../chat-bots/chat-bots-v2/im.v2/files/file-upload.md)
2. Сохраните из ответа `result.file.id` — идентификатор файла и `result.messageId` — идентификатор созданного сообщения
3. Когда нужно отдать файл пользователю повторно, получите ссылку методом [im.v2.File.download](../../chat-bots/chat-bots-v2/im.v2/files/file-download.md) — ему нужны и идентификатор файла, и `dialogId` чата

Если файл уже лежит в чате и его идентификатор неизвестен, получите историю сообщений методом [im.dialog.messages.get](../messages/im-dialog-messages-get.md): он возвращает массив `files`, где у каждого файла есть поле `id`. Этот идентификатор принимают методы скачивания, сохранения на Диск и удаления.

## Идентификаторы и ограничения

- актуальные методы принимают `dialogId`: `chat{chatId}` для группового чата, `{userId}` для личного диалога
- у методов `im.disk.*` идентификаторы записываются в верхнем регистре и различаются от метода к методу — точный набор смотрите в параметрах нужного метода
- содержимое файла передается строкой Base64 — как его подготовить, описано в статье [Как загрузить файлы](../../files/how-to-upload-files.md)
- максимальный размер файла — 100 МБ

## Связь с другими объектами

**Диск.** Файл чата хранится на Диске: поле `result.file.id` — это идентификатор объекта Диска. Метод `im.v2.File.upload` обращается к Диску сам. В старом сценарии Диск вызывали вручную: папку чата возвращал метод [im.disk.folder.get](./im-disk-folder-get.md), файл загружал [disk.folder.uploadfile](../../disk/folder/disk-folder-upload-file.md), список файлов папки — [disk.folder.getchildren](../../disk/folder/disk-folder-get-children.md).

**Сообщения.** Загрузка файла создает в чате сообщение и возвращает его `messageId`, поэтому отдельный вызов [im.message.add](../messages/im-message-add.md) не нужен. Дальше с этим сообщением работают методы подраздела [Сообщения](../messages/index.md).

**События.** О новом сообщении с файлом подписанное приложение узнает из событий мессенджера — они собраны в разделе [im.v2: события](../../chat-bots/chat-bots-v2/im.v2/events/index.md).

**Чат-боты.** Те же операции от имени бота выполняют методы подраздела [Файлы imbot.v2](../../chat-bots/chat-bots-v2/imbot.v2/files/index.md).
