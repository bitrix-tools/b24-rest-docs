# Пользователи в чатах: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Для работы с пользователями в чатах используйте группу методов `im.user.*`. Они возвращают данные в том виде, в каком их показывает мессенджер: имя для отображения, аватар, цвет, статус в чате, время последней активности и признаки бота, внешнего пользователя или пользователя открытых линий. Подраздел входит в раздел [Чаты в Битрикс24](../index.md).

Методы `im.user.*` актуальны, аналогов в `im.v2` у них нет. Исключение — методы автоматического статуса «Отошел», они вынесены в отдельную группу [Методы для предыдущей версии чата](#legacy-methods).

## Связь методов с другими объектами

**Пользователь.** Методы получают информацию о пользователях по идентификатору `ID`. Узнать идентификаторы участников чата можно методом [im.chat.user.list](../chat-users/im-chat-user-list.md). Тот же идентификатор возвращают методы [user.get](../../user/user-get.md) и [user.search](../../user/user-search.md): в Битрикс24 у пользователя один идентификатор для всех методов.

**Подразделения.** Получить идентификаторы сотрудников и руководителей по структуре компании можно методами подраздела [Подразделения](../departments/index.md).

**Экстранет.** Экстранет-пользователю доступны только участники его экстранет-групп. Метод [im.user.get](./im-user-get.md) в этом случае вернет ошибку `ACCESS_DENIED`, а [im.user.list.get](./im-user-list-get.md) молча пропустит недоступные идентификаторы.

## Статус пользователя в чатах

Статус пользователя управляет уведомлениями и отображается в мессенджере. Методы [im.user.status.set](./im-user-status-set.md) и [im.user.status.get](./im-user-status-get.md) работают только для текущего пользователя: задать или прочитать статус другого сотрудника нельзя.

Метод [im.user.status.set](./im-user-status-set.md) принимает четыре значения: `online`, `dnd`, `away` и `break`. В интерфейсе текущей версии чата отображается только `online` — остальные статусы устанавливаются, но не показываются.

### Методы для предыдущей версии чата {#legacy-methods}

Методы автоматического статуса «Отошел» разработаны для предыдущей версии чата. В текущей версии чата М1 они работают, но результаты не отображаются в интерфейсе. Замены в текущей версии у них нет, для новой разработки они не подходят.
