Уровни прав определяют доступ пользователей к папкам и файлам на Диске. REST API использует их при загрузке файлов и назначении доступа к существующим папкам.

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [Права доступа к Моему диску в Битрикс24](https://helpdesk.bitrix24.ru/open/19492254/)

## Как начать работу

1. Получите уровни доступа методом [disk.rights.getTasks](./disk-rights-get-tasks.md)
2. Выберите нужный уровень доступа
3. Передайте его при загрузке файла или назначении доступа к существующей папке

## Особенности работы с правами доступа

Метод [disk.rights.getTasks](./disk-rights-get-tasks.md) возвращает идентификаторы трех уровней доступа:

- чтение
- редактирование
- полный доступ

При загрузке файла передавайте идентификатор уровня доступа в поле `TASK_ID` элемента массива `rights`. Параметр `rights` поддерживают методы [disk.storage.uploadFile](../storage/disk-storage-upload-file.md) и [disk.folder.uploadFile](../folder/disk-folder-upload-file.md).

Чтобы назначить доступ к существующей папке, используйте метод [disk.folder.shareToUser](../folder/disk-folder-share-to-user.md). Он принимает название уровня доступа в параметре `taskName`, а не идентификатор `TASK_ID`.
