# Задания бизнес-процессов: обзор методов

Бизнес-процессы могут создавать задания для участников, чтобы получить от них дополнительную информацию. Например, через задание можно согласовать документ в бухгалтерии, утвердить отпуск у руководителя или запросить договор у юриста. Пользователи видят свои задания в Битрикс24 и получают уведомления.

Существует четыре типа заданий:

- утверждение документа
- ознакомление с документом
- запрос дополнительной информации
- запрос дополнительной информации с отклонением

>

## Как начать работу

1. Получите список заданий методом [bizproc.task.list](./bizproc-task-list.md)
2. Найдите идентификатор нужного задания `TASK_ID`
3. Выполните задание методом [bizproc.task.complete](./bizproc-task-complete.md)
4. При необходимости делегируйте задание другому сотруднику методом [bizproc.task.delegate](./bizproc-task-delegate.md)

## Поля задания

Задания с запросом дополнительной информации выполняются методом [bizproc.task.complete](./bizproc-task-complete.md). Значения полей передаются в объекте `FIELDS` в формате `{"field_1": "value_1", ... , "field_N": "value_N"}`:

- `field_N` — символьный идентификатор поля задания
- `value_N` — значение поля

Какие поля нужно заполнить, можно узнать из ответа метода [bizproc.task.list](./bizproc-task-list.md). Поле `PARAMETERS.Fields` содержит описания всех полей задания.

## Что важно учитывать

- Выполнить можно только свои задания
- Для выполнения задания нужен идентификатор `TASK_ID`, его можно получить методом [bizproc.task.list](./bizproc-task-list.md)
- Задания с запросом дополнительной информации содержат поля, которые пользователь должен заполнить
- Для делегирования задания нужны идентификатор задания `TASK_IDS`, идентификатор текущего исполнителя `FROM_USER_ID` и идентификатор нового исполнителя `TO_USER_ID`

## Связь с другими объектами

**Пользователь.** Задание связано с исполнителем. Для делегирования передайте идентификатор текущего исполнителя `FROM_USER_ID` и идентификатор нового исполнителя `TO_USER_ID` в метод [bizproc.task.delegate](./bizproc-task-delegate.md). Идентификатор пользователя можно получить методом [user.get](../../user/user-get.md).

**Бизнес-процесс.** Задание создается в ходе выполнения бизнес-процесса. Получить список доступных пользователю заданий и их параметры можно методом [bizproc.task.list](./bizproc-task-list.md).
