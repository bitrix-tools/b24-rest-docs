# Задания бизнес-процессов: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Бизнес-процессы могут создавать задания для участников, чтобы получить от них решение или данные. Например, через задание можно согласовать документ в бухгалтерии, утвердить отпуск у руководителя или запросить договор у юриста. Пользователи видят свои задания в Битрикс24 и получают уведомления.

Метод [bizproc.task.complete](./bizproc-task-complete.md) выполняет задания четырех типов:

- утверждение документа
- ознакомление с документом
- запрос дополнительной информации
- запрос дополнительной информации с отклонением

> Быстрый переход: [все методы](#all-methods)
>
> Пользовательская документация: [Задания бизнес-процессов](https://helpdesk.bitrix24.ru/open/7451037/)

## Как начать работу

1. Получите список заданий методом [bizproc.task.list](./bizproc-task-list.md). Метод возвращает массив заданий, среди полей по умолчанию — `ID`, `WORKFLOW_ID`, `DOCUMENT_NAME` и `NAME`
2. Выберите идентификатор нужного задания `ID`: для выполнения передайте его в `TASK_ID`, для делегирования — в массиве `TASK_IDS`
3. Выполните задание методом [bizproc.task.complete](./bizproc-task-complete.md) или делегируйте его другому сотруднику методом [bizproc.task.delegate](./bizproc-task-delegate.md). Оба метода при успехе возвращают `true`

## Поля задания

Задания с запросом дополнительной информации выполняются методом [bizproc.task.complete](./bizproc-task-complete.md). Значения полей передаются в объекте `FIELDS` в формате `{"field_1": "value_1", ... , "field_N": "value_N"}`:

- `field_N` — значение `Id` поля из `PARAMETERS.Fields`
- `value_N` — значение поля

Какие поля нужно заполнить, можно узнать методом [bizproc.task.list](./bizproc-task-list.md): укажите `PARAMETERS` в параметре `SELECT`, описания полей вернутся в `PARAMETERS.Fields`. У остальных типов заданий `Fields` в ответе нет.

## Что важно учитывать

- Выполнить можно только свои задания
- Делегировать можно свои задания и задания подчиненных, администратор — задания любого сотрудника. Делегирует и получает задание только сотрудник компании
- Метод [bizproc.task.list](./bizproc-task-list.md) возвращает задания всех типов, например задания роботизации RPA. Тип задания — в поле `ACTIVITY`. Для неподдерживаемого типа метод [bizproc.task.complete](./bizproc-task-complete.md) вернет ошибку `ERROR_TASK_TYPE`
- Методы доступны, если тариф Битрикс24 включает бизнес-процессы

## Связь с другими объектами

**Пользователь.** Задание связано с исполнителем. Идентификаторы сотрудников для делегирования можно получить методом [user.get](../../user/user-get.md).

**Бизнес-процесс.** Задание создается в ходе выполнения бизнес-процесса. Идентификатор процесса возвращается в поле `WORKFLOW_ID` задания. По нему процесс можно найти методом [bizproc.workflow.instances](../bizproc-workflow-instances.md) или остановить методом [bizproc.workflow.terminate](../bizproc-workflow-terminate.md). Другие методы раздела — в [обзоре бизнес-процессов](../index.md).
