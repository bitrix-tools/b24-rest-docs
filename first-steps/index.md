# С чего начать

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Документация по REST API Битрикс24 описывает методы API, примеры запросов и сценарии интеграции для разработки приложений и внешних сервисов.

Ниже — рекомендуемая последовательность изучения документации, которая поможет:

- разобраться в структуре документации
- освоить базовые возможности API
- перейти к более сложным сценариям

После прохождения стартовых материалов вы сможете получить доступ к REST API, выполнить первый запрос, выбрать способ разработки и найти методы для своего сценария.

## Как выбрать маршрут

Выберите маршрут по задаче:

- если нужно быстро проверить REST API, начните с разделов [Доступ к REST API](#access) и [Первый запрос к API](#first-call)
- если нужно встроить REST API в свой проект, изучите [Настройку REST API](#settings), [Примеры кода](#examples), [SDK от Битрикс24](#sdk) и [Справочник API](#api-reference)
- если нужно создать решение внутри Битрикс24 без публикации в Маркетплейсе, перейдите к [Локальным интеграциям](#local-integrations)
- если нужно подготовить приложение для публикации и монетизации, изучите [Тиражные приложения](#market)
- если нужно повторить готовый сценарий, откройте [Готовые сценарии](#tutorials)
- если нужно работать с AI-агентом, выберите [AI-инструменты](#ai-tools)

## Что подготовить перед началом

Перед началом убедитесь, что:

- у вас есть Битрикс24, в котором доступна работа с REST API. Если доступа нет, начните со статьи [Как получить доступ к REST API](./access-to-rest-api.md)
- выбран способ авторизации: входящий вебхук, локальное приложение или тиражное приложение. Настройки описаны в разделе [Настройка и использование REST API](../settings/index.md)
- у интеграции настроены права доступа к нужным инструментам Битрикс24. Список [доступных скоупов](../api-reference/scopes/permissions.md) зависит от методов, которые будет вызывать приложение
- секреты вебхуков, токены и ключи приложения не попадают в публичный код и логи
- для интеграции учтены [лимиты REST API](../settings/performance/limits.md) на количество запросов

{% note tip "" %}

Чтобы понять архитектуру приложений, принципы авторизации, работу с REST API и структуру окружения, изучите [курс по разработке приложений для Битрикс24](https://dev.1c-bitrix.ru/learning/course/index.php?COURSE_ID=266&INDEX=Y).

{% endnote %}
