# Как написать в поддержку

С вопросами по работе REST API Битрикс24 можно обратиться в техническую поддержку. В чате отвечает виртуальный помощник. Если помощник не находит ответ, он передает чат специалисту поддержки — тот уточняет детали, объясняет работу метода или регистрирует заявку.

{% note warning "" %}

Чат с [виртуальным помощником](https://helpdesk.bitrix24.ru/open/24351052/) доступен на любом тарифе. Передать чат специалисту поддержки помощник может только на коммерческих тарифах.
Если в Битрикс24 подключена партнерская поддержка, чат с поддержкой Битрикс24 недоступен.

{% endnote %}

## С чем поможет поддержка

- Разобраться в документации, например найти метод по описанию.
- Принять запрос на новый функционал.
- Объяснить работу метода или события.
- Принять заявку о неработающем методе или событии.

## Куда обратиться с другими вопросами

Поддержка отвечает на вопросы по работе REST API. Остальные темы разбирают другие площадки.

| Вопрос | Куда обратиться |
| --- | --- |
| Партнерский статус, публикация решения в Битрикс24.Маркетплейс | [Технологическое партнерство](./market/technology-partnership.md) |
| Ошибка или предложение по документации | [Обратная связь](./feedback.md) |
| Обсуждение сценария с другими разработчиками | [Поддержка и комьюнити для разработчиков](./support.md) |

## Где найти чат с поддержкой

Чат с поддержкой открывается из интерфейса Битрикс24. На компьютере кнопка _Помощь_ находится в правом верхнем углу, дальше путь зависит от поколения интерфейса.

- **Классический интерфейс.** Нажмите _Помощь > Написать в чат > Мне нужна помощь > Написать в поддержку_ и задайте вопрос.
- **Новый интерфейс.** Нажмите _Помощь > Поддержка_. Откроется раздел со статусом Битрикс24, списком ваших обращений и переходом в чат.

Классический интерфейс сейчас работает на большинстве Битрикс24, новый раскатывается постепенно.

В мобильном приложении нажмите _Меню > Поддержка_.

В одном чате специалист поддержки решает только один вопрос. Если вопросов несколько, создайте [параллельные диалоги](https://helpdesk.bitrix24.ru/open/17585752/).

## Что прислать в поддержку

Чем полнее исходные данные, тем быстрее поддержка разберется в вопросе.

{% note warning "" %}

Уберите из примеров конфиденциальные данные: секретный код входящего вебхука, access token и параметр `auth`. Замените их значения на звездочки.

{% endnote %}

### Вопрос по работе метода

1. Напишите, с каким методом сложности. Можно приложить ссылку на страницу документации.

2. Пришлите код запроса.

3. Ответ на запрос: JSON ответ, сообщение об ошибке.

4. Опишите, что ожидаете от метода.

{% cut "Пример кода запроса" %}

```javascript
BX24.callMethod(
    'crm.item.productrow.add', {
        fields: {
            ownerId: 13142,
            ownerType: 'D',
            productId: 9621,
            price: 80000.000000,
            quantity: 2,
            discountTypeId: 2,
            discountRate: 20,
            taxRate: 20,
            taxIncluded: 'Y',
            measureCode: 796,
            sort: 10,
        },
    },
    function(result) {
        if (result.error()) {
            console.error(result.error());
        } else {
            console.log(result.data());
        }
    }
);
```

{% endcut %}

### Вопрос по работе события

1. Напишите, с каким событием возникли сложности. Можно приложить ссылку на страницу документации.

2. Укажите URL обработчика, который подписан на событие:
	- URL из поля `handler` метода [event.bind](./api-reference/events/event-bind.md),
	- URL из поля `URL вашего обработчика*` [исходящего вебхука](./local-integrations/local-webhooks.md).

3. Напишите дату и время, когда событие не сработало в последний раз.
