# Туториалы: готовые сценарии использования REST API

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Туториал — это разбор одной практической задачи: какие методы вызвать, в каком порядке, какие данные передать между вызовами и как проверить результат. Туториалы собраны по типовым задачам разработчика: создать или изменить объект, получить список, встроить интерфейс приложения, связать Битрикс24 с внешним сервисом.

Туториал не заменяет справочник. Параметры, ответ и ошибки каждого метода описаны в [Справочнике REST API](../api-reference/index.md).

> Быстрый переход: [все категории туториалов](#categories)

## Что нужно перед началом

- **Способ вызова методов.** Методы вызывают через [входящий вебхук](../first-steps/first-rest-api-call.md), если интеграция работает внутри одного Битрикс24, или из [приложения](../settings/app-installation/index.md), если решение устанавливается на разные Битрикс24. Часть сценариев работает только в приложении — например, коннектор открытых линий и СМС-провайдер. Их методы требуют контекста приложения и через вебхук возвращают ошибку
- **Scope и права.** В начале туториала указаны scope, которые нужны приложению, и права пользователя, от имени которого выполняются методы. Без нужного scope метод вернет ошибку. Полный список — на странице [Доступные скоупы Битрикс24](../api-reference/scopes/permissions.md)
- **Данные для примеров.** Многие сценарии создают, изменяют и удаляют объекты. Выполняйте примеры на тестовом Битрикс24 или на тестовых объектах. Как подставить свои значения в код примера, описано на странице [Как использовать примеры в документации](../first-steps/how-to-use-examples.md)

## Как использовать туториалы

- **Как обучающий материал.** Туториалы показывают, как формировать запросы и обрабатывать ответы. Начните с простого сценария, например [Как отфильтровать элементы по названию стадии](./crm/how-to-get-lists/how-to-get-elements-by-stage-filter.md) — он только читает данные, поэтому объекты в Битрикс24 останутся без изменений
- **Как шаблон для своего решения.** Адаптируйте пример под свои данные, добавьте обработку ошибок и логирование. Например, туториал [Как подключить кассу к Битрикс24](./sale/cashbox-add-example.md)
- **Как готовый фрагмент кода.** Найдите сценарий под конкретную задачу и перенесите код в свой проект. Например, туториал [Как настроить округление для пользовательского поля типа «Число»](./crm/how-to-add-crm-objects/how-to-add-precision-to-user-field.md)

## Структура туториалов

Туториалы построены по общей схеме:

- краткое описание задачи, scope и прав
- список методов сценария в порядке вызова
- примеры кода на JS, PHP и Python
- описание параметров, которые нужно передать
- примеры ответа сервера в формате JSON
- пояснения, ограничения и ссылки на связанные статьи

## Как начать работу

1. Выберите категорию в таблице [Категории туториалов](#categories)
2. Найдите туториал, который решает вашу задачу
3. Подготовьте идентификаторы и другие данные, которые нужны сценарию
4. Выполните методы в порядке, описанном в туториале
5. Проверьте результат в интерфейсе Битрикс24

Если вы еще не выполняли запросы к API, начните с раздела [С чего начать](../first-steps/index.md). Приложение [Документация по REST API](https://www.bitrix24.ru/apps/app/bitrix.restapi/) показывает документацию и выполняет запросы в одном окне.
