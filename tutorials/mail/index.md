# Почта: типовые сценарии

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Сценарии помогают выбрать методы для типовых задач с почтой: отправить письмо из подключенного ящика, найти входящее письмо и создать из него дело CRM.

Сценарий описывает одну практическую задачу и порядок методов для ее выполнения.

> Быстрый переход: [все сценарии](#choose-tutorial)

## Связь с другими объектами

- **Почтовые ящики и отправители.** Чтобы отправить письмо, сначала получите доступных отправителей методом [mail.mailbox.senders](../../api-reference/mail/mailbox/mail-mailbox-senders.md). Метод возвращает адреса из ящиков, к которым есть доступ у пользователя вебхука или приложения
- **Получатели.** Перед отправкой можно найти контакт по имени, телефону или e-mail методом [mail.recipient.listcontacts](../../api-reference/mail/recipient/mail-recipient-listcontacts.md). В сценарии результат поиска используется для выбора адреса получателя
- **Письма и дела CRM.** Входящие письма можно получить методом [mail.message.list](../../api-reference/mail/message/mail-message-list.md). Метод [mail.message.createcrmactivity](../../api-reference/mail/message/mail-message-createcrmactivity.md) создает из письма дело CRM, если пользователь имеет доступ к почтовому ящику и CRM

{% note info "" %}

Методы почты относятся к REST 3.0. Их нужно вызывать по адресу с сегментом `/rest/api/`, а тело запроса передавать в JSON. Особенности вызова методов и формат JSON-запроса описаны в [обзоре REST 3.0](../../api-reference/rest-v3.md).

{% endnote %}

## Как начать работу

1. Создайте [входящий вебхук](../../local-integrations/local-webhooks.md#incoming-webhook) или приложение со scope `mail`
2. Проверьте, что пользователь вебхука видит нужный почтовый ящик
3. Если нужно создать дело из письма, проверьте доступ пользователя к CRM
4. Выберите сценарий в таблице [Как выбрать сценарий](#choose-tutorial)
5. Выполните методы в порядке, который описан в сценарии
