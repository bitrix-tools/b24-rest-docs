# BX24.js: обзор библиотеки

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

BX24.js — JavaScript-библиотека для приложений, встроенных в интерфейс Битрикс24. Она позволяет вызывать методы Битрикс24 из клиентской части приложения и автоматически добавляет данные авторизации OAuth 2.0.

Библиотека также связывает интерфейс приложения с интерфейсом Битрикс24. С ее помощью можно управлять размером фрейма, открывать стандартные диалоги и страницы Битрикс24, получать данные о среде выполнения, хранить настройки пользователя и приложения.

> Быстрый переход: [обзор страниц BX24.js](#all-pages)

## Как начать работу

1. Подключите библиотеку на странице приложения:

   ```html
   <script src="//api.bitrix24.tech/api/v1/"></script>
   ```

2. Дождитесь инициализации библиотеки с помощью [BX24.init](./system-functions/bx24-init.md)
3. Выберите группу функций в таблице [Обзор страниц BX24.js](#all-pages)
4. Вызовите нужную функцию и обработайте результат в клиентском коде приложения

Например, так приложение узнает, кто его открыл, — через метод [user.current](../../api-reference/user/user-current.md). Для этого метода у приложения должен быть scope `user`, `user_brief` или `user_basic`:

```html
<script src="//api.bitrix24.tech/api/v1/"></script>
<script>
    BX24.init(function () {
        BX24.callMethod('user.current', {}, function (result) {
            if (result.error()) {
                console.error(result.error());
                return;
            }

            console.log('Текущий пользователь:', result.data().NAME, result.data().LAST_NAME);
        });
    });
</script>
```

## Связь с другими инструментами

**Места встраивания.** Приложение можно открыть в выбранном месте интерфейса Битрикс24, например во вкладке карточки CRM. Для этого зарегистрируйте обработчик места встраивания методом [placement.bind](../../api-reference/widgets/placement-bind.md): передайте код места в параметре `PLACEMENT`, а в параметре `HANDLER` — адрес страницы приложения, которую Битрикс24 откроет в этом месте. Метод доступен администратору.

**UI Kit.** BX24.js отвечает за взаимодействие приложения с Битрикс24, а [Битрикс24 UI Kit](../../api-reference/widgets/ui-kit/index.md) помогает собрать интерфейс из готовых компонентов, дизайн-токенов и иконок.

## Что важно учитывать

- Для внешних приложений и вебхуков выберите другую библиотеку в [обзоре SDK](../index.md)
- Необходимый scope зависит от вызываемого метода. Значения scope смотрите в справочнике [Права доступа](../../api-reference/scopes/permissions.md)
- Доступ к данным зависит от прав пользователя, от имени которого приложение выполняет запрос
- Частоту запросов к Битрикс24 ограничивают [лимиты REST API](../../settings/performance/limits.md), а в пакет [BX24.callBatch](./how-to-call-rest-methods/bx24-call-batch.md) входит не больше 50 команд
- Функции BX24.js не возвращают Promise, поэтому `.then()` после вызова не сработает. Результат метода REST и выбор в системном диалоге приходят в функцию обратного вызова, которую вы передаете отдельным параметром
- После инициализации функции возвращают данные о среде и сохраненные настройки синхронно, без обратного вызова: например, так работают [BX24.getLang](./additional-functions/bx24-get-lang.md), [BX24.getAuth](./system-functions/bx24-get-auth.md) и [BX24.appOption.get](./options/bx24-app-option-get.md)
- Обработчик одиночного вызова метода REST получает объект [ajaxResult](./how-to-call-rest-methods/bx24-call-method.md#ajax-result): `result.data()` возвращает данные, а `result.error()` — объект ошибки или `undefined`, если ошибки нет. В пакетном вызове ошибку проверяют у результата каждой команды. Какие сбои в обратный вызов не попадают, описано в разделе [Обработка ошибок](./how-to-call-rest-methods/index.md#errors)
