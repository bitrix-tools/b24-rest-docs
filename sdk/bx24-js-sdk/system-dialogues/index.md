# Системные диалоги: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Системные диалоги — стандартные окна выбора Битрикс24. Приложение вызывает диалог из своего фрейма, а рисует окно сам Битрикс24 поверх фрейма, поэтому приложению не нужно собирать список пользователей или объектов CRM и следить за правами доступа. Диалоги используют, когда нужно выбрать пользователя, права доступа или элементы CRM.

> Быстрый переход: [все методы](#all-methods)

## Как выбрать диалог

1. Если нужно выбрать одного сотрудника, используйте [BX24.selectUser](./bx24-select-user.md), а для нескольких — [BX24.selectUsers](./bx24-select-users.md)
2. Если нужно выбрать права доступа, используйте [BX24.selectAccess](./bx24-select-access.md)
3. Если нужно выбрать лиды, контакты, компании, сделки или предложения, используйте [BX24.selectCRM](./bx24-select-crm.md)

## Что приходит в обработчик

Диалоги не возвращают данные напрямую. Результат выбора приходит в функцию обратного вызова `callback`, которую вы передаете при вызове.

#|
|| **Метод** | **Что получает `callback`** ||
|| [BX24.selectUser](./bx24-select-user.md) | Объект `{id, name}` выбранного пользователя ||
|| [BX24.selectUsers](./bx24-select-users.md) | Массив объектов `{id, name}` ||
|| [BX24.selectAccess](./bx24-select-access.md) | Массив объектов `{id, name}`, где `id` — код доступа вида `U1`, `SG4`, `AU` ||
|| [BX24.selectCRM](./bx24-select-crm.md) | Объект с ключами `lead`, `contact`, `company`, `deal`, `quote`. В каждом ключе — массив выбранных объектов ||
|#

Обработчик срабатывает только при подтвержденном выборе. Если пользователь закрыл диалог, ничего не выбрав, обработчик не вызывается. Кодов ошибок диалоги не возвращают.

## Что важно учитывать

- Вызвать диалог можно только из приложения, встроенного в Битрикс24, и только после [BX24.init](../system-functions/bx24-init.md)
- Собственный scope диалогам не нужен: они открывают интерфейс Битрикс24, а не обращаются к REST API. Права и scope проверяются в тех методах, которые вы вызываете с полученными идентификаторами
- Пользователь видит в диалоге только те объекты, к которым у него есть доступ
- В `id` элемента CRM приходит составное значение с префиксом типа, например `L_1348` для лида и `C_2` для контакта. Числовую часть используйте как идентификатор объекта в методах CRM

## Связь с другими объектами

**Пользователь.** Методы [BX24.selectUser](./bx24-select-user.md) и [BX24.selectUsers](./bx24-select-users.md) отдают числовой `id` сотрудника. Этот идентификатор подставляют в методы Битрикс24, где нужен `USER_ID`: например, в [user.get](../../../api-reference/user/user-get.md), чтобы получить карточку сотрудника, или в поле ответственного при создании объектов.

**Права доступа.** Метод [BX24.selectAccess](./bx24-select-access.md) отдает коды доступа — `U1` для пользователя, `SG4` для группы соцсети, `AU` для всех авторизованных. Такие коды принимают параметры видимости и прав в других объектах Битрикс24, где список получателей задается не одним пользователем, а набором кодов.

**CRM.** Метод [BX24.selectCRM](./bx24-select-crm.md) отдает выбранные лиды, контакты, компании, сделки и предложения. Числовую часть `id` передают в методы соответствующего объекта CRM, например в [crm.item.get](../../../api-reference/crm/universal/crm-item-get.md), а тип объекта берут из ключа ответа.

**Приложение.** Диалог вызывают после инициализации библиотеки — ее описывает раздел [Инициализация и авторизация](../system-functions/index.md). Выбранные идентификаторы передают в методы Битрикс24 средствами раздела [Вызов методов REST](../how-to-call-rest-methods/index.md), а чтобы пользователь не выбирал одно и то же при каждом запуске, результат сохраняют функциями раздела [Настройки приложения](../options/index.md).
