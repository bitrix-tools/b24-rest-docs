# Настройки приложения в BX24.JS: обзор методов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Для работы с настройками приложения используются два объекта:

- `BX24.userOption` — работа с настройками текущего пользователя. Установка значения пользовательских настроек происходит сразу
- `BX24.appOption` — работа с общими настройками приложения. Для настроек приложения может потребоваться обработчик завершения, параметр `callback` в [BX24.appOption.set](./bx24-app-option-set.md)

> Быстрый переход: [все методы](#all-methods)

## Условия работы

- функции `BX24.userOption` и `BX24.appOption` доступны в приложении после инициализации библиотеки методом [BX24.init](../system-functions/bx24-init.md)
- `BX24.userOption` читает и сохраняет настройки текущего пользователя
- `BX24.appOption` читает и сохраняет общие настройки текущего приложения
- сохранение общих настроек приложения доступно только пользователям с правом управления приложениями. Перед вызовом [BX24.appOption.set](./bx24-app-option-set.md) проверьте права методом [BX24.isAdmin](../additional-functions/bx24-is-admin.md)

## Как выбрать объект настроек

## Как начать работу

1. Инициализируйте библиотеку методом [BX24.init](../system-functions/bx24-init.md)
2. Если нужна настройка приложения, проверьте права администратора методом [BX24.isAdmin](../additional-functions/bx24-is-admin.md)
3. Сохраните значение методом `set`
4. Получите значение методом `get`

## Как выполняются операции

#|
|| **Объект** | **Запись** | **Чтение** | **Несохраненный код** ||
|| `BX24.userOption` | `set` сразу обновляет настройку текущего пользователя | `get` синхронно возвращает значение | `undefined` ||
|| `BX24.appOption` | `set` сохраняет настройку асинхронно и вызывает `callback`. Для записи нужны права управления приложениями | `get` синхронно возвращает значение, загруженное при инициализации | `undefined` ||
|#

## Пример работы

Сохранить настройку текущего пользователя и прочитать ее значение:

```js
BX24.init(() => {
    BX24.userOption.set('theme', 'dark');

    console.log(BX24.userOption.get('theme')); // вернет dark
    console.log(BX24.userOption.get('unknown')); // вернет undefined
});
```

Сохранить общую настройку приложения и обработать результат записи:

```js
BX24.init(() => {
    if (!BX24.isAdmin()) {
        return;
    }

    BX24.appOption.set('theme', 'dark', (options) => {
        console.log(options.theme); // вернет dark
    });
});
```
