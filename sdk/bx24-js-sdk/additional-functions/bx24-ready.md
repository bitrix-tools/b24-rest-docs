# Установить обработчик готовности DOM-структуры BX24.ready

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

```js
BX24.ready(handler: callable): void;
```

Метод `BX24.ready` добавляет функцию-обработчик, которая выполнится, когда DOM-структура документа будет готова: браузер разобрал страницу приложения, и ее элементы доступны для скрипта. По назначению метод похож на `jQuery.ready`.

Готовность страницы и готовность библиотеки — разные события. `BX24.ready` ждет только страницу приложения, а данные от Битрикс24 к этому моменту могут еще не прийти. Если обработчику нужны данные Битрикс24 или вызовы его методов, используйте [BX24.init](../system-functions/bx24-init.md).

Метод работает на странице приложения, где подключена [библиотека BX24.js](../index.md), и не обращается к Битрикс24. Собственный scope методу не нужен.

#|
|| **Название**
`тип` | **Описание** ||
|| **handler***
[`callable`](../../../api-reference/data-types.md) | Функция-обработчик. Вызывается без параметров, когда DOM-структура документа готова ||
|#

## Пример кода

{% include [Сноска о примерах](../../../_includes/examples.md) %}

```html
<p id="status">Загрузка...</p>

<script>
    BX24.ready(function () {
        document.getElementById('status').textContent = 'Страница загружена';
    });
</script>
```

## Обработка ответа

Метод не возвращает данные (`void`). Если DOM-структура уже готова к моменту вызова, обработчик все равно выполнится не сразу, а после того, как закончится текущий код. Поэтому строки, которые идут после `BX24.ready`, выполнятся раньше обработчика.

Если библиотеку подключили из кода, а не тегом `<script>` в разметке, обработчик может выполниться позже — только когда загрузятся все картинки и стили страницы.

## Обработка ошибок

Кодов ошибок метод не возвращает.

#|
|| **Ситуация** | **Что происходит** | **Что делать** ||
|| В `handler` передана не функция | Ничего не происходит, ошибки нет | Передать функцию ||
|| Обработчик читает данные Битрикс24, например язык через [BX24.getLang](./bx24-get-lang.md) | Данных еще может не быть. Тогда [BX24.getLang](./bx24-get-lang.md) вернет пустую строку | Перенести код в обработчик [BX24.init](../system-functions/bx24-init.md) ||
|#
