# Установить заголовок страницы BX24.setTitle

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

```js
BX24.setTitle(title: string, callback?: callable): void;
```

Метод `BX24.setTitle` меняет заголовок страницы Битрикс24 над фреймом приложения. Название вкладки браузера при этом не меняется.

Метод работает, только когда приложение открыто на своей странице в Битрикс24. В [местах встраивания](../../../api-reference/widgets/index.md), например во вкладке карточки CRM, Битрикс24 команду не выполняет. Вызывайте метод после инициализации библиотеки в обработчике [BX24.init](../system-functions/bx24-init.md). Собственный scope методу не нужен: он управляет интерфейсом, а не обращается к REST API.

## Параметры метода

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

#|
|| **Название**
`тип` | **Описание** ||
|| **title***
[`string`](../../../api-reference/data-types.md) | Новый заголовок. Число библиотека превратит в строку ||
|| **callback**
[`callable`](../../../api-reference/data-types.md) | Функция обратного вызова. Получает объект с новым заголовком [(подробное описание)](#callback) ||
|#

## Пример кода

{% include [Сноска о примерах](../../../_includes/examples.md) %}

```js
BX24.init(function () {
    BX24.setTitle('Заявки за неделю', function (result) {
        console.log('Новый заголовок:', result.title);
    });
});
```

## Обработка ответа {#callback}

Метод не возвращает данные (`void`). Когда Битрикс24 обработает команду, он вызовет `callback` и передаст объект с новым заголовком:

```json
{
    "title": "Заявки за неделю"
}
```

### Возвращаемые данные

#|
|| **Название**
`тип` | **Описание** ||
|| **title**
[`string`](../../../api-reference/data-types.md) | Новый заголовок страницы ||
|#

## Обработка ошибок

Кодов ошибок метод не возвращает.

#|
|| **Ситуация** | **Что происходит** | **Что делать** ||
|| Метод вызван в месте встраивания | Заголовок не меняется, `callback` не вызывается | Показать заголовок в интерфейсе самого приложения ||
|| Метод вызван в окне, которое открыл [BX24.openApplication](./bx24-open-application.md) | Меняется заголовок страницы под окном. У самого окна заголовка нет. `callback` вызывается как обычно | Показать заголовок в интерфейсе самого приложения ||
|| В `title` передан `null` или `undefined` | Код приложения завершается ошибкой JavaScript `TypeError`, команда не уходит в Битрикс24 | Передать строку ||
|#
