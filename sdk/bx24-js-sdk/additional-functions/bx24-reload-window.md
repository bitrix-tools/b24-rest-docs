# Перезагрузить страницу BX24.reloadWindow

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

```js
BX24.reloadWindow(callback?: callable): void;
```

Метод `BX24.reloadWindow` перезагружает страницу Битрикс24, на которой открыто приложение. Вместе со страницей заново загружается и само приложение. Начиная с версии модуля `rest` `25.800.0` метод можно использовать в [местах встраивания](../../../api-reference/widgets/index.md) приложения.

Чтобы перезагрузить только приложение, а страницу Битрикс24 оставить, вызовите `location.reload()` в коде страницы приложения: библиотека инициализируется заново.

Метод работает только внутри фрейма приложения в Битрикс24. Вызывайте его после инициализации библиотеки в обработчике [BX24.init](../system-functions/bx24-init.md). Собственный scope методу не нужен: он управляет интерфейсом, а не обращается к REST API.

## Параметры метода

#|
|| **Название**
`тип` | **Описание** ||
|| **callback**
[`callable`](../../../api-reference/data-types.md) | Библиотека принимает параметр, но Битрикс24 эту функцию не вызывает: страница перезагружается вместе с приложением ||
|#

## Пример кода

{% include [Сноска о примерах](../../../_includes/examples.md) %}

Перезагрузить страницу по кнопке:

```html
<button id="reload-page">Обновить страницу</button>

<script>
    BX24.init(function () {
        document.getElementById('reload-page').addEventListener('click', function () {
            BX24.reloadWindow();
        });
    });
</script>
```

## Обработка ответа

Метод не возвращает данные (`void`). Код, который должен выполниться после перезагрузки, разместите в обработчике [BX24.init](../system-functions/bx24-init.md): после перезагрузки приложение снова пройдет инициализацию.

## Обработка ошибок

Кодов ошибок метод не возвращает.

#|
|| **Ситуация** | **Что происходит** | **Что делать** ||
|| Метод вызван сразу в обработчике [BX24.init](../system-functions/bx24-init.md) | Страница перезагружается без остановки: после каждой перезагрузки обработчик срабатывает снова | Вызывать метод по действию пользователя или при условии, которое после перезагрузки не повторится ||
|| Метод вызван в окне, которое открыл [BX24.openApplication](./bx24-open-application.md) | Перезагружается вся страница под окном, окно закрывается | Чтобы обновить только приложение в окне, вызвать `location.reload()` в коде его страницы ||
|#
