# Подстроить размер фрейма под содержимое BX24.fitWindow

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

```js
BX24.fitWindow(callback?: callable): void;
```

Метод `BX24.fitWindow` растягивает фрейм приложения на всю доступную ширину и подгоняет его высоту под содержимое страницы. Высоту метод берет из [BX24.getScrollSize](./bx24-get-scroll-size.md).

Метод работает только внутри фрейма приложения в Битрикс24. Вызывайте его после инициализации библиотеки в обработчике [BX24.init](../system-functions/bx24-init.md) и каждый раз, когда содержимое страницы выросло. Собственный scope методу не нужен: он управляет интерфейсом, а не обращается к REST API.

## Параметры метода

#|
|| **Название**
`тип` | **Описание** ||
|| **callback**
[`callable`](../../../api-reference/data-types.md) | Функция обратного вызова. Получает объект с новым размером фрейма [(подробное описание)](#callback) ||
|#

{% note warning "" %}

Метод не уменьшает фрейм. Если содержимое страницы стало короче, фрейм останется прежней высоты: [BX24.getScrollSize](./bx24-get-scroll-size.md) не возвращает высоту меньше видимой части фрейма. Чтобы уменьшить фрейм, передайте нужную высоту в [BX24.resizeWindow](./bx24-resize-window.md).

{% endnote %}

## Пример кода

{% include [Сноска о примерах](../../../_includes/examples.md) %}

```js
BX24.init(function () {
    BX24.fitWindow(function (size) {
        console.log('Новый размер фрейма:', size.width, size.height);
    });
});
```

## Обработка ответа {#callback}

Метод не возвращает данные (`void`). Когда Битрикс24 изменит размер фрейма, он вызовет `callback` и передаст объект с новыми шириной и высотой:

```json
{
    "width": 1108,
    "height": 1579
}
```

### Возвращаемые данные

#|
|| **Название**
`тип` | **Описание** ||
|| **width**
[`integer`](../../../api-reference/data-types.md) | Ширина фрейма в пикселях. Равна ширине области, в которой Битрикс24 показывает приложение ||
|| **height**
[`integer`](../../../api-reference/data-types.md) | Высота фрейма в пикселях ||
|#

## Обработка ошибок

Кодов ошибок метод не возвращает. Если Битрикс24 не выполнил команду, `callback` не вызывается. Так происходит в окне, которое открыл [BX24.openApplication](./bx24-open-application.md): высоту такого окна задает Битрикс24, а содержимое длиннее окна прокручивается внутри него. Ширину окна можно передать параметром `width` в `settings` при вызове [BX24.openApplication](./bx24-open-application.md#settings).
