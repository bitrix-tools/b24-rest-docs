# Позвонить на телефонный номер BX24.im.phoneTo

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

{% include notitle [Приложение работает во фрейме](../../../_includes/app-runs-in-iframe.md) %}

```js
BX24.im.phoneTo(string phone): void;
```

Метод `BX24.im.phoneTo` передает телефонный номер в Мессенджер Битрикс24 и запускает исходящий звонок.

Метод работает после [BX24.init](../system-functions/bx24-init.md). Для звонка в Битрикс24 должна быть доступна телефония.

## Параметры метода

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

#|
|| **Название**
`тип` | **Описание** ||
|| **phone***
[`string`](../../../api-reference/data-types.md) | Телефонный номер для звонка. Передавайте номер в международном формате, например `+74951234567`. Метод передает строку в Мессенджер без проверки и преобразования формата ||
|#

## Пример кода

{% include [Сноска о примерах](../../../_includes/examples.md) %}

```js
BX24.init(function () {
    BX24.im.phoneTo('+74951234567');
});
```

## Обработка ответа

Метод передает команду на звонок и ничего не возвращает.

## Обработка ошибок

Метод не передает приложению коды ошибок. Если звонки недоступны по тарифу, Битрикс24 открывает окно с информацией об ограничении.
