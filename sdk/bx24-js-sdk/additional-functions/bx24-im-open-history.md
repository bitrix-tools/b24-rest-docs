# Открыть окно истории BX24.im.openHistory

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

{% include notitle [Приложение работает во фрейме](../../../_includes/app-runs-in-iframe.md) %}

```js
BX24.im.openHistory(dialogId: string): void;
```

Метод `BX24.im.openHistory` передает идентификатор диалога в Мессенджер Битрикс24 и открывает окно истории сообщений.

Метод работает после [BX24.init](../system-functions/bx24-init.md).

## Параметры метода

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

#|
|| **Название**
`тип` | **Описание** ||
|| **dialogId***
[`string`](../../../api-reference/data-types.md) | Идентификатор диалога. Поддерживаются форматы:

- идентификатор пользователя, например `42`
- идентификатор чата в формате `chatXXX`, например `chat123`
- идентификатор диалога открытой линии в формате `imol|XXXX`, например `imol|1234` ||
|#

{% note info "" %}

Метод передает `dialogId` в Мессенджер без проверки и преобразования.

{% endnote %}

## Пример кода

{% include [Сноска о примерах](../../../_includes/examples.md) %}

```js
BX24.init(function () {
    BX24.im.openHistory('chat123');
});
```

## Обработка ответа

Метод передает команду на открытие истории и ничего не возвращает.

## Обработка ошибок

Метод не передает приложению коды ошибок. Если `dialogId` не соответствует доступному диалогу, приложение не получает описание причины.
