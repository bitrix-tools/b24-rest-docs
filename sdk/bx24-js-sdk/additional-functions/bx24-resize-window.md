# Изменить размер фрейма BX24.resizeWindow

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

```js
BX24.resizeWindow(width: integer | string, height: integer | string, callback?: callable): void;
```

Метод `BX24.resizeWindow` задает ширину и высоту фрейма, в котором Битрикс24 показывает приложение.

Метод работает только внутри фрейма приложения в Битрикс24. Вызывайте его после инициализации библиотеки в обработчике [BX24.init](../system-functions/bx24-init.md). Собственный scope методу не нужен: он управляет интерфейсом, а не обращается к REST API.

## Параметры метода

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

#|
|| **Название**
`тип` | **Описание** ||
|| **width***
[`integer`\|`string`](../../../api-reference/data-types.md) | Ширина фрейма в пикселях, больше нуля. Можно передать и строку, которая начинается с числа, например `'980px'` ||
|| **height***
[`integer`\|`string`](../../../api-reference/data-types.md) | Высота фрейма в пикселях, больше нуля. Строку библиотека читает так же, как у `width` ||
|| **callback**
[`callable`](../../../api-reference/data-types.md) | Функция обратного вызова. Получает объект с новым размером фрейма [(подробное описание)](#callback) ||
|#

{% note warning "" %}

Строка `'100%'` не растягивает фрейм: библиотека прочитает ее как 100 пикселей. Чтобы растянуть фрейм на всю ширину и подогнать высоту под содержимое, используйте [BX24.fitWindow](./bx24-fit-window.md).

{% endnote %}

## Пример кода

{% include [Сноска о примерах](../../../_includes/examples.md) %}

```js
BX24.init(function () {
    BX24.resizeWindow(980, 700, function (size) {
        console.log('Новый размер фрейма:', size.width, size.height);
    });
});
```

## Обработка ответа {#callback}

Метод не возвращает данные (`void`). Когда Битрикс24 изменит размер фрейма, он вызовет `callback` и передаст объект с шириной и высотой, которые он установил:

```json
{
    "width": 980,
    "height": 700
}
```

### Возвращаемые данные

#|
|| **Название**
`тип` | **Описание** ||
|| **width**
[`integer`](../../../api-reference/data-types.md) | Ширина фрейма в пикселях ||
|| **height**
[`integer`](../../../api-reference/data-types.md) | Высота фрейма в пикселях. Это высота, которую установил Битрикс24, а не видимая на экране — подробнее в предупреждении ниже ||
|#

{% note warning "" %}

Когда приложение открыто на своей странице в Битрикс24, фрейм на экране не бывает ниже 600 пикселей. Если передать меньшую высоту, `callback` получит ее, но фрейм останется высотой 600 пикселей.

{% endnote %}

## Обработка ошибок

Кодов ошибок метод не возвращает. Если Битрикс24 не выполнил команду, `callback` не вызывается.

#|
|| **Ситуация** | **Что происходит** | **Что делать** ||
|| Из ширины или высоты не получается положительное число: передан `0`, отрицательное число или строка вроде `'auto'` | Размер фрейма не меняется, `callback` не вызывается | Передать оба размера положительными числами ||
|| Метод вызван в окне, которое открыл [BX24.openApplication](./bx24-open-application.md) | Размер окна не меняется, `callback` не вызывается | Не менять размер изнутри окна. Высоту окна задает Битрикс24, а ширину можно передать параметром `width` в `settings` при вызове [BX24.openApplication](./bx24-open-application.md#settings) ||
|#
