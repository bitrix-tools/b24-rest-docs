# Загрузить javascript-файлы BX24.loadScript

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

```js
BX24.loadScript(script: string | array, callback?: callable): void;
```

Метод `BX24.loadScript` подключает к странице приложения один или несколько javascript-файлов и выполняет их. Файлы из массива загружаются по очереди: следующий — после того, как загрузился предыдущий. Так можно подключить библиотеку, а за ней скрипт, который ее использует.

Если страница еще не готова, метод сам дождется ее готовности — того же момента, когда срабатывают обработчики [BX24.ready](./bx24-ready.md). Метод не обращается к Битрикс24, поэтому ждать [BX24.init](../system-functions/bx24-init.md) не нужно. Собственный scope методу не нужен.

{% note warning "" %}

Если файл не загрузился, например его нет на сервере, метод остановится без ошибки: следующие файлы не загрузятся, а `callback` не будет вызван. Сбой загрузки видно в консоли браузера.

{% endnote %}

## Параметры метода

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

#|
|| **Название**
`тип` | **Описание** ||
|| **script***
[`string`\|`array`](../../../api-reference/data-types.md) | Адрес javascript-файла или массив адресов. Относительный адрес браузер отсчитывает так же, как у тега `<script>` на странице приложения: от ее адреса или от адреса в теге `<base>`, если он есть, но не от адреса Битрикс24 ||
|| **callback**
[`callable`](../../../api-reference/data-types.md) | Функция обратного вызова. Вызывается без параметров, когда загружены все файлы ||
|#

## Пример кода

{% include [Сноска о примерах](../../../_includes/examples.md) %}

Подключить библиотеку графиков, затем скрипт отчета, который ее использует:

```js
BX24.loadScript(
    [
        'js/chart.min.js',
        'js/report.js'
    ],
    function () {
        console.log('Все скрипты загружены');
    }
);
```

## Обработка ответа

Метод не возвращает данные (`void`). Когда загрузится последний файл, библиотека вызовет `callback` без параметров. Если страница уже готова и передан пустой массив, `callback` выполнится сразу.

## Обработка ошибок

Кодов ошибок метод не возвращает.

#|
|| **Ситуация** | **Что происходит** | **Что делать** ||
|| Файл не загрузился: его нет на сервере или пропала сеть | Загрузка молча останавливается, как описано в предупреждении выше | Проверить адреса файлов. Если приложению важно знать о сбое, ограничить ожидание `callback` таймером ||
|| В файле синтаксическая ошибка | Браузер не выполняет этот файл, но загрузка продолжается, и `callback` вызывается | Не считать вызов `callback` доказательством, что каждый файл сработал: проверить, что нужные объекты появились на странице ||
|| `script` не передан или равен `null` | Возникает исключение `TypeError`, `callback` не вызывается. Если страница еще не готова, исключение возникнет позже, когда метод дождется ее готовности, и блок `try...catch` вокруг вызова его не перехватит | Передать адрес файла или массив адресов ||
|| В `callback` передана не функция | Файлы загружаются без ошибки, но вызова не будет | Передать функцию ||
|| В `script` передана пустая строка или массив из пустых строк | Файлы не загружаются, ошибки нет, а `callback` вызывается | Если адреса собираются в коде, проверять их перед вызовом ||
|#
