# Проверить готовность DOM-структуры BX24.isReady

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

```js
BX24.isReady(): boolean;
```

Метод `BX24.isReady` сразу сообщает, готова ли DOM-структура документа: браузер разобрал страницу приложения, и ее элементы доступны для скрипта. Если код должен дождаться готовности страницы, используйте [BX24.ready](./bx24-ready.md).

Это признак библиотеки, а не браузера. Если библиотеку подключили из кода, а не тегом `<script>` в разметке, метод может вернуть `false` на уже разобранной странице. Готовность страницы не означает, что библиотека получила данные от Битрикс24: для этого используйте [BX24.init](../system-functions/bx24-init.md).

Метод работает на странице приложения, где подключена [библиотека BX24.js](../index.md), и не обращается к Битрикс24. Собственный scope методу не нужен.

## Параметры метода

Без параметров.

## Пример кода

{% include [Сноска о примерах](../../../_includes/examples.md) %}

Скрипт стоит в разметке страницы и выполняется, пока браузер ее разбирает:

```html
<script>
    console.log(BX24.isReady()); // false: браузер еще разбирает страницу

    BX24.ready(function () {
        console.log(BX24.isReady()); // true
    });
</script>
```

## Обработка ответа

Метод синхронно возвращает результат типа `boolean`. Пример результата, когда страница готова:

```json
true
```

### Возвращаемые данные

#|
|| **Название**
`тип` | **Описание** ||
|| **result**
[`boolean`](../../../api-reference/data-types.md) | `true`, если библиотека зафиксировала готовность DOM-структуры документа, иначе `false` ||
|#

## Обработка ошибок

Кодов ошибок метод не возвращает. Пока браузер разбирает страницу, метод возвращает `false`, и это не ошибка.
