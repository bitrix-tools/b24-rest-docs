# Позвонить по внутренней связи BX24.im.callTo

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

{% include notitle [Приложение работает во фрейме](../../../_includes/app-runs-in-iframe.md) %}

```js
BX24.im.callTo(userId: integer, video?: boolean): void;
```

Метод `BX24.im.callTo` передает идентификатор пользователя в Мессенджер Битрикс24 и запускает звонок по внутренней связи.

Метод работает после [BX24.init](../system-functions/bx24-init.md).

## Параметры метода

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

#|
|| **Название**
`тип` | **Описание** ||
|| **userId***
[`integer`](../../../api-reference/data-types.md) | Идентификатор пользователя Битрикс24, которому нужно позвонить ||
|| **video**
[`boolean`](../../../api-reference/data-types.md) | Формат звонка. Возможные значения:

- `true` — видеозвонок
- `false` — аудиозвонок

По умолчанию — `false` ||
|#

## Пример кода

{% include [Сноска о примерах](../../../_includes/examples.md) %}

```js
BX24.init(function () {
    BX24.im.callTo(42, true);
});
```

## Обработка ответа

Метод передает команду на звонок и ничего не возвращает.

## Обработка ошибок

Метод не передает приложению коды ошибок. Если звонок не может быть запущен, приложение не получает описание причины.
