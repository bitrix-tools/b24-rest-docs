# Прокрутить родительское окно BX24.scrollParentWindow

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

```js
BX24.scrollParentWindow(scroll: integer | string, callback?: callable): void;
```

Метод `BX24.scrollParentWindow` прокручивает родительское окно — страницу Битрикс24, внутри которой находится фрейм приложения, — до указанной позиции по вертикали. Например, если фрейм приложения выше экрана, кнопка «Наверх» внизу приложения может вернуть пользователя к началу страницы.

Начиная с версии модуля `rest` `25.800.0` метод можно использовать в [местах встраивания](../../../api-reference/widgets/index.md) приложения. Прокрутка работает, если приложение открыто не в слайдере, например на своей странице в Битрикс24. В окне, которое открыл [BX24.openApplication](./bx24-open-application.md), страница не прокручивается.

Метод работает только внутри фрейма приложения в Битрикс24. Вызывайте его после инициализации библиотеки в обработчике [BX24.init](../system-functions/bx24-init.md). Собственный scope методу не нужен: он управляет интерфейсом, а не обращается к REST API.

## Параметры метода

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

#|
|| **Название**
`тип` | **Описание** ||
|| **scroll***
[`integer`\|`string`](../../../api-reference/data-types.md) | Позиция в пикселях от верха страницы Битрикс24. `0` — начало страницы. Если число больше высоты страницы, Битрикс24 прокрутит ее до конца. Можно передать и строку, которая начинается с числа: из `'150px'` библиотека возьмет `150` ||
|| **callback**
[`callable`](../../../api-reference/data-types.md) | Функция обратного вызова. Получает объект с переданной позицией [(подробное описание)](#callback) ||
|#

## Пример кода

{% include [Сноска о примерах](../../../_includes/examples.md) %}

Прокрутить страницу Битрикс24 к началу по кнопке:

```html
<button id="scroll-top">Наверх</button>

<script>
    BX24.init(function () {
        document.getElementById('scroll-top').addEventListener('click', function () {
            BX24.scrollParentWindow(0, function (result) {
                console.log('Позиция:', result.scroll);
            });
        });
    });
</script>
```

## Обработка ответа {#callback}

Метод не возвращает данные (`void`). Когда Битрикс24 обработает команду, он вызовет `callback` и передаст объект с позицией, которую вы указали:

```json
{
    "scroll": 0
}
```

### Возвращаемые данные

#|
|| **Название**
`тип` | **Описание** ||
|| **scroll**
[`integer`](../../../api-reference/data-types.md) | Позиция из параметра `scroll`. Это не фактическое положение страницы: `callback` приходит и тогда, когда страница не прокрутилась ||
|#

## Обработка ошибок

Кодов ошибок метод не возвращает.

#|
|| **Ситуация** | **Что происходит** | **Что делать** ||
|| Из `scroll` не получается число, например передана строка `'top'` | Страница не прокручивается, `callback` не вызывается | Передать число ||
|| В `scroll` передано отрицательное число | Страница не прокручивается, `callback` вызывается | Передать `0` или положительное число ||
|| Приложение открыто в слайдере, например в окне [BX24.openApplication](./bx24-open-application.md) | Страница не прокручивается, `callback` вызывается | Прокрутить содержимое внутри фрейма средствами страницы приложения, например `window.scrollTo` ||
|#
