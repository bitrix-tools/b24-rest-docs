# Проверить право пользователя на установку приложения BX24.isAdmin

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

```js
BX24.isAdmin(): boolean;
```

Метод `BX24.isAdmin` проверяет, может ли текущий пользователь устанавливать это приложение в Битрикс24. Несмотря на название, `true` получает не только администратор:

- администратор Битрикс24 — всегда
- сотрудник, которому администратор разрешил устанавливать приложения, — если это приложение можно устанавливать сотрудникам

Права в CRM, задачах и других инструментах метод не проверяет: их Битрикс24 проверяет, когда приложение вызывает методы REST. Чтобы узнать, администратор ли пользователь, вызовите метод [user.admin](../../../api-reference/common/users/user-admin.md).

Значение приходит от Битрикс24 при инициализации библиотеки, поэтому вызывайте метод в обработчике [BX24.init](../system-functions/bx24-init.md). Собственный scope методу не нужен.

## Параметры метода

Без параметров.

## Пример кода

{% include [Сноска о примерах](../../../_includes/examples.md) %}

Показать кнопку настроек приложения только тем, кто может его устанавливать:

```html
<button id="settings" hidden>Настройки</button>

<script>
    BX24.init(function () {
        if (BX24.isAdmin()) {
            document.getElementById('settings').hidden = false;
        }
    });
</script>
```

## Обработка ответа

Метод синхронно возвращает результат типа `boolean`. Пример результата для администратора:

```json
true
```

### Возвращаемые данные

#|
|| **Название**
`тип` | **Описание** ||
|| **result**
[`boolean`](../../../api-reference/data-types.md) | `true`, если пользователь — администратор Битрикс24 или может сам установить это приложение. Иначе `false` ||
|#

## Обработка ошибок

Кодов ошибок метод не возвращает.

#|
|| **Ситуация** | **Что происходит** | **Что делать** ||
|| Метод вызван до инициализации библиотеки | Возвращает `false` даже администратору | Вызывать метод в обработчике [BX24.init](../system-functions/bx24-init.md) ||
|| Нужно проверить именно права администратора | Метод может вернуть `true` и сотруднику с правом устанавливать приложения | Вызвать метод [user.admin](../../../api-reference/common/users/user-admin.md) ||
|#
