# Получить размеры страницы приложения BX24.getScrollSize

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

```js
BX24.getScrollSize(): object;
```

Метод `BX24.getScrollSize` возвращает ширину и высоту страницы приложения внутри фрейма. Эту высоту использует [BX24.fitWindow](./bx24-fit-window.md), когда подгоняет фрейм под содержимое.

Размеры не бывают меньше видимой части фрейма: если содержимое короче фрейма, метод вернет высоту фрейма. Чтобы узнать высоту самого содержимого, измерьте элемент, в котором оно лежит, например через его свойство `offsetHeight`.

Метод измеряет страницу приложения и не обращается к Битрикс24, поэтому работает и до [BX24.init](../system-functions/bx24-init.md). Собственный scope методу не нужен.

## Параметры метода

Без параметров.

## Пример кода

{% include [Сноска о примерах](../../../_includes/examples.md) %}

```js
BX24.init(function () {
    const size = BX24.getScrollSize();
    console.log(size.scrollWidth, size.scrollHeight); // 1108 604
});
```

## Обработка ответа

Метод синхронно возвращает объект с размерами страницы приложения:

```json
{
    "scrollWidth": 1108,
    "scrollHeight": 604
}
```

## Обработка ошибок

Кодов ошибок метод не возвращает.
