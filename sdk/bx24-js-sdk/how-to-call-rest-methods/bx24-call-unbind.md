# Вызвать интерфейс удаления зарегистрированного обработчика события BX24.callUnbind

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

```js
BX24.callUnbind(
    String event,
    String handler[,
        Integer|null auth_type[,
            Function callback
        ]
    ]
);
```

Функция `BX24.callUnbind` удаляет обработчик [события](../../../api-reference/common/events/index.md), зарегистрированный для текущего приложения. Библиотека вызывает метод [event.unbind](../../../api-reference/events/event-unbind.md) от имени пользователя, который открыл приложение. Написание `BX24.callUnBind` — это тот же вызов, оставленный для совместимости.

Удаляются только обработчики того приложения, из которого выполнен вызов, и только обработчики онлайн-событий. Обработчик [офлайн-события](../../../api-reference/events/offline-events.md) удаляют методом [event.unbind](../../../api-reference/events/event-unbind.md) с параметром `event_type=offline`: у функции нет параметра, который переключает тип события.

Вызвать функцию можно только из приложения, встроенного во фрейм Битрикс24.

Если вызвать функцию до [BX24.init](../system-functions/bx24-init.md), библиотека дождется инициализации и повторит вызов, но синхронно вернет `false`. При отправленном запросе функция возвращает `undefined`, поэтому строгая проверка `=== false` отличает отказ от отправки только внутри обработчика `BX24.init`.

{% note info %}

Функция работает только у пользователя с правами администратора Битрикс24. У остальных пользователей она синхронно возвращает `false`, не отправляет запрос и не вызывает `callback`. Ограничение задает библиотека: метод [event.unbind](../../../api-reference/events/event-unbind.md) доступен любому пользователю, но BX24.js проверяет права до отправки запроса.

{% endnote %}

## Параметры

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

#|
|| **Название**
`тип` | **Описание** ||
|| **event***
[`string`](../../../api-reference/data-types.md) | Имя события, например `ONAPPUNINSTALL`. Регистр значения не важен ||
|| **handler***
[`string`](../../../api-reference/data-types.md) | Адрес обработчика события. Значение сравнивается точно, вместе со схемой и завершающим слешем ||
|| **auth_type**
[`integer`](../../../api-reference/data-types.md) | Идентификатор пользователя, от имени которого авторизуется обработчик события. По умолчанию параметр не передается.

Значение выбирают по тому, как обработчик регистрировали через [BX24.callBind](./bx24-call-bind.md):

- `0` или пустое значение — обработчики, зарегистрированные без `auth_type`, то есть с авторизацией от имени пользователя, действия которого привели к срабатыванию события
- `15` или другой идентификатор пользователя — обработчики, зарегистрированные с `auth_type` этого пользователя
- `null` или пропущенный параметр — обработчики события со всеми значениями `auth_type`

Параметры позиционные: чтобы удалить обработчики со всеми значениями `auth_type` и получить результат, передайте `null` третьим параметром ||
|| **callback**
[`function`](../../../api-reference/data-types.md) | Функция-обработчик результата вызова метода [(подробное описание)](#response) ||
|#

## Примеры кода

{% include [Сноска о примерах](../../../_includes/examples.md) %}

Удалить все обработчики события по адресу, независимо от `auth_type`:

```js
BX24.init(() => {
    BX24.callUnbind('ONAPPUNINSTALL', 'https://www.my-domain.ru/handler/');
});
```

Удалить обработчики, зарегистрированные без `auth_type`, и разобрать результат:

```js
BX24.init(() => {
    BX24.callUnbind(
        'ONAPPUNINSTALL',
        'https://www.my-domain.ru/handler/',
        0,
        (result) => {
            if (result.error())
            {
                console.error(result.error());
            }
            else
            {
                console.log('Удалено обработчиков: ' + result.data().count);
            }
        }
    );
});
```

## Обработка ответа {#response}

Функция `callback` получает объект `ajaxResult` — такой же, как у [BX24.callMethod](./bx24-call-method.md#ajax-result). Данные ответа возвращает метод `data()`, ошибку — метод `error()`.

```json
{
    "count": 1
}
```

### Возвращаемые данные

#|
|| **Название**
`тип` | **Описание** ||
|| **count**
[`integer`](../../../api-reference/data-types.md) | Количество удаленных обработчиков события. Значение `0` означает, что ни один обработчик не подошел под условия вызова ||
|#

## Обработка ошибок

```json
{
    "status": 400,
    "ex": {
        "error": "ERROR_ARGUMENT",
        "error_description": "Argument 'HANDLER' is null or empty",
        "argument": "HANDLER"
    }
}
```

Код ошибки доступен как `result.error().ex.error`, текст — как `result.error().ex.error_description`, имя параметра, из-за которого возникла ошибка, — как `result.error().ex.argument`. HTTP-статус возвращают `result.error().status` и метод `getStatus()`, а готовую строку с кодом, текстом и статусом — метод `toString()`.

{% include notitle [обработка ошибок](../../../_includes/error-info.md) %}

### Возможные коды ошибок

#|
|| **Статус** | **Код** | **Описание** | **Значение** ||
|| `400` | `ERROR_ARGUMENT` | Argument 'EVENT' is null or empty | Не передано имя события ||
|| `400` | `ERROR_ARGUMENT` | Argument 'HANDLER' is null or empty | Не передан адрес обработчика ||
|#

Ошибки метода `event.unbind` про нехватку прав администратора через эту функцию не приходят — запрос до сервера не доходит.

Ответы со статусом `5xx` в `callback` тоже не попадают. Библиотека выбрасывает исключение `Query error!` из асинхронного обработчика запроса, поэтому `try/catch` вокруг вызова его не перехватит.
