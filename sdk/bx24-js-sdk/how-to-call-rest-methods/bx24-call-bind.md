# Зарегистрировать обработчик события BX24.callBind

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

```js
BX24.callBind(
    String event,
    String handler[,
        Integer auth_type[,
            Function callback
        ]
    ]
);
```

Функция `BX24.callBind` регистрирует для текущего приложения обработчик [онлайн-события](../../../api-reference/common/events/index.md). Библиотека вызывает метод [event.bind](../../../api-reference/events/event-bind.md) от имени пользователя, который открыл приложение.

Вызвать функцию можно только из приложения, встроенного во фрейм Битрикс24. Если вызвать функцию до [BX24.init](../system-functions/bx24-init.md), библиотека дождется инициализации и повторит вызов, но синхронно вернет `false`.

После удаления или обновления приложения зарегистрированные обработчики удаляются. Регистрируйте их заново при установке каждой версии приложения. События начнут поступать только после завершения установки методом [BX24.installFinish](../system-functions/bx24-install-finish.md).

{% note info %}

Функция работает только у пользователя с правами администратора Битрикс24. У остальных пользователей она синхронно возвращает `false`, не отправляет запрос и не вызывает `callback`. Ограничение задает библиотека: метод [event.bind](../../../api-reference/events/event-bind.md) разрешает обычному пользователю регистрировать онлайн-события с ограничениями.

{% endnote %}

## Параметры метода

{% include [Сноска об обязательных параметрах](../../../_includes/required.md) %}

#|
|| **Название**
`тип` | **Описание** ||
|| **event***
[`string`](../../../api-reference/data-types.md) | Имя события, например `ONAPPUNINSTALL`. Регистр значения не важен ||

[`string`](../../../api-reference/data-types.md) | Адрес обработчика события. Адрес должен быть доступен для внешних запросов с серверов Битрикс24 ||

[`integer`](../../../api-reference/data-types.md) | Идентификатор пользователя, от имени которого будет авторизован обработчик события.

|| **callback**
[`function`](../../../api-reference/data-types.md) | Функция-обработчик результата вызова метода [(подробное описание)](#response) ||
|#

## Примеры кода

{% include [Сноска о примерах](../../../_includes/examples.md) %}

Зарегистрировать обработчик с авторизацией от имени пользователя, действие которого вызвало событие:

```js
BX24.init(() => {
    BX24.callBind(
        'ONAPPUNINSTALL',
        'https://www.my-domain.ru/handler/'
    );
});
```

Зарегистрировать обработчик с авторизацией от имени пользователя с идентификатором `15` и проверить результат:

```js
BX24.init(() => {
    BX24.callBind(
        'ONAPPUNINSTALL',
        'https://www.my-domain.ru/handler/',
        15,
        (result) => {
            if (result.error())
            {
                console.error(result.error());
            }
            else if (result.data() === true)
            {
                console.log('Обработчик зарегистрирован');
            }
        }
    );
});
```

## Обработка ответа {#response}

Функция `callback` получает объект `ajaxResult` — такой же, как у [BX24.callMethod](./bx24-call-method.md#ajax-result). Данные ответа возвращает метод `data()`, ошибку — метод `error()`.

```json
true
```

### Возвращаемые данные

#|
|| **Название**
`тип` | **Описание** ||
|| **result**
[`boolean`](../../../api-reference/data-types.md) | Результат регистрации обработчика. Значение `true` означает, что обработчик зарегистрирован. Значение `false` означает, что адрес обработчика не прошел проверку ||
|#

## Обработка ошибок

```json
{
    "status": 400,
    "ex": {
        "error": "ERROR_ARGUMENT",
        "error_description": "Argument 'EVENT' is null or empty",
        "argument": "EVENT"
    }
}
```

Код ошибки доступен как `result.error().ex.error`, текст — как `result.error().ex.error_description`, имя некорректного параметра — как `result.error().ex.argument`. HTTP-статус возвращают `result.error().status` и метод `getStatus()`, а готовую строку с кодом, текстом и статусом — метод `toString()`.

{% include notitle [обработка ошибок](../../../_includes/error-info.md) %}

### Возможные коды ошибок

#|
|| **Статус** | **Код** | **Описание** | **Значение** ||
|| `400` | `ERROR_ARGUMENT` | Argument 'EVENT' is null or empty | Не передано имя события ||
|| `400` | `ERROR_ARGUMENT` | Argument 'HANDLER' is null or empty | Не передан адрес обработчика ||
|| `400` | `ERROR_EVENT_NOT_FOUND` | Event not found | Указанное событие не найдено ||
|| `400` | `ERROR_CORE` | Unable to set event handler | Не удалось зарегистрировать обработчик ||
|#

Ошибки метода `event.bind` про нехватку прав администратора через эту функцию не приходят — запрос до сервера не доходит.

Ответы со статусом `5xx` в `callback` не попадают. Библиотека выбрасывает исключение `Query error!` из асинхронного обработчика запроса, поэтому `try/catch` вокруг вызова его не перехватит.
