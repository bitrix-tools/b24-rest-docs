# Вызов методов REST через BX24.js

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

BX24.js позволяет вызывать методы Битрикс24 из интерфейса приложения. Библиотека отправляет запрос от имени пользователя, который открыл приложение, и автоматически добавляет данные авторизации OAuth 2.0.

Для внешних приложений и вебхуков библиотека недоступна.

> Быстрый переход: [функции BX24.js для вызова методов](#all-pages)

## Как начать работу

1. Подключите библиотеку BX24.js и дождитесь ее инициализации с помощью [BX24.init](../system-functions/bx24-init.md)
2. Выберите функцию в таблице [Функции BX24.js](#all-pages)
3. Подготовьте данные для вызова: название метода и его параметры, пакет запросов или сведения об обработчике события
4. Передайте функцию-обработчик, чтобы получить результат вызова или информацию об ошибке

Пример: получить данные пользователя, который открыл приложение, методом [user.current](../../../api-reference/user/user-current.md). Для этого метода приложению нужен один из scope: `user`, `user_brief` или `user_basic`.

```js
BX24.init(() => {
    BX24.callMethod('user.current', {}, (result) => {
        if (result.error())
        {
            // например: insufficient_scope: The request requires higher privileges than provided by the access token (401)
            console.error(result.error().toString());
            return;
        }

        const user = result.data();
        console.log(user.ID, user.NAME, user.LAST_NAME); // 1 Иван Петров
    });
});
```

{% include [Сноска о примерах](../../../_includes/examples.md) %}

Обработчик получает объект результата: данные ответа возвращает его метод `data()`, ошибку — метод `error()`. Остальные методы объекта описаны в разделе [Обработка ответа](./bx24-call-method.md#ajax-result).

## Что важно учитывать

- Необходимый scope зависит от вызываемого метода. Значения scope смотрите в справочнике [Права доступа](../../../api-reference/scopes/permissions.md)
- Доступ к данным дополнительно зависит от прав пользователя, от имени которого выполняется запрос
- Если вызвать [`BX24.callMethod`](./bx24-call-method.md), [`BX24.callBatch`](./bx24-call-batch.md), [`BX24.callBind`](./bx24-call-bind.md) или [`BX24.callUnbind`](./bx24-call-unbind.md) до [`BX24.init`](../system-functions/bx24-init.md), библиотека отложит запрос до завершения инициализации
- Библиотека работает и в облачном, и в коробочном Битрикс24
- В пакет [`BX24.callBatch`](./bx24-call-batch.md) входит не больше 50 команд. Команды сверх лимита Битрикс24 не выполнит, какие ошибки при этом придут — в разделе [Обработка ошибок](./bx24-call-batch.md#errors) этой функции
- Регистрировать и удалять обработчики онлайн-событий можно с помощью [`BX24.callBind`](./bx24-call-bind.md) и [`BX24.callUnbind`](./bx24-call-unbind.md)
- Частоту запросов к Битрикс24 ограничивают [лимиты REST API](../../../settings/performance/limits.md)

## Обработка ошибок {#errors}

Ошибку, которую вернул Битрикс24, библиотека передает в тот же обработчик. Метод `result.error()` возвращает объект ошибки, а если ошибки нет — `undefined`. Строку с кодом, текстом и HTTP-статусом возвращает `result.error().toString()`, например `ERROR_METHOD_NOT_FOUND: Method not found! (404)`.

В обработчик не попадают:

- ответ со статусом `5xx`, сетевой сбой и ответ, который не удалось разобрать как JSON. Библиотека выбрасывает исключение `Query error!` из асинхронного обработчика запроса, поэтому `try/catch` вокруг вызова его не перехватит
- ошибка `expired_token`. Библиотека сама обновляет авторизацию и повторяет запрос, а обработчик получает результат повтора

В пакете запросов ошибки устроены иначе: они приходят по каждой команде, а ошибка всего пакета в обработчик не попадает. Подробности — на странице [BX24.callBatch](./bx24-call-batch.md#errors).
