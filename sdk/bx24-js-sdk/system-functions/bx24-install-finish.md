# Оповестить об окончании работы инсталлятора BX24.installFinish

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

```js
BX24.installFinish(): void;
```

Функция `BX24.installFinish` сигнализирует об окончании работы инсталлятора или настройщика приложения.

Если функция вызывается на этапе запуска инсталлятора, то произойдет перезагрузка страницы и запуск приложения. Если на этапе настройки — запуск обработчиков [BX24.init](./bx24-init.md). В остальных случаях никакого эффекта от вызова не будет.

Приложению без интерфейса, которое использует только API, вызов `installFinish` не нужен: его установка завершается автоматически. Подробнее — [{#T}](../../../settings/app-installation/installation-finish.md).

Без параметров.

{% note warning "" %}

Пока `installFinish` не вызван, приложение с интерфейсом считается не установленным, и Битрикс24 не доставляет ему события: обработчики чат-ботов и обработчики, зарегистрированные через [event.bind](../../../api-reference/events/event-bind.md), не получают запросов. Встройки, зарегистрированные через [placement.bind](../../../api-reference/widgets/placement-bind.md), не появятся в интерфейсе.

Ошибки при этом нет: регистрация проходит успешно, обработчики видны при запросе, но трафика нет.

Вызывайте `installFinish` последним шагом установочного сценария — после того как зарегистрировали встройки и подписались на события.

Проверить состояние установки можно методом [app.info](../../../api-reference/common/system/app-info.md): значение `false` в поле `INSTALLED` означает, что `installFinish` не был выполнен.

{% endnote %}

## Пример

```js
document.addEventListener("DOMContentLoaded", function() {
    BX24.init(function(){
        BX24.installFinish();
    });
});

```
