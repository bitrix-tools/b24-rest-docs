# Оповестить об окончании работы инсталлятора BX24.installFinish

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

```js
BX24.installFinish(): void;
```

Функция `BX24.installFinish` сигнализирует об окончании работы инсталлятора или настройщика приложения.

Если функция вызывается на этапе запуска инсталлятора, то произойдет перезагрузка страницы и запуск приложения. Если на этапе настройки — запуск обработчиков [BX24.init](./bx24-init.md). В остальных случаях никакого эффекта от вызова не будет.

{% note warning "" %}

Пока `installFinish` не вызван, приложение с интерфейсом остается установленным не до конца, и портал не доставляет ему события: обработчики чат-ботов, обработчики, зарегистрированные через [event.bind](../../../api-reference/events/event-bind.md), и другие исходящие вызовы не доходят до ваших адресов. Встройки, зарегистрированные через [placement.bind](../../../api-reference/widgets/placement-bind.md), тоже не появятся в интерфейсе.

Ошибки при этом нет. Регистрация проходит успешно, методы возвращают результат, обработчики видны при запросе — а трафика нет. Все видимые признаки говорят, что настройка верна, поэтому проблему обычно ищут в nginx, туннелях, сертификатах и маршрутизации.

Вызывайте `installFinish` один раз, со страницы настройки приложения, последним шагом установочного сценария — после того как зарегистрировали встройки и подписались на события.

Проверить состояние уже установленного приложения можно методом [app.info](../../../api-reference/common/system/app-info.md): поле `INSTALLED` со значением `false` означает, что `installFinish` не был выполнен.

{% endnote %}

Приложению без интерфейса, которое использует только API, вызов `installFinish` не нужен: его установка завершается автоматически, а сам метод работает только во фрейме интерфейса приложения в браузере. Подробнее — [{#T}](../../../settings/app-installation/installation-finish.md).

Без параметров.

## Пример

```js
document.addEventListener("DOMContentLoaded", function() {
    BX24.init(function(){
        BX24.installFinish();
    });
});

```
