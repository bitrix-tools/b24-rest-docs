# SDK для разработки под Битрикс24

SDK от Битрикс24 — это готовые библиотеки для REST API. Они берут на себя авторизацию, сборку HTTP-запросов, разбор ответов и обработку ошибок, поэтому в коде остается только вызов нужного метода и работа с результатом.

SDK не меняют состав и поведение методов: полный справочник методов, параметров и событий лежит в разделе [Справочник REST API](../api-reference/index.md). Выбор SDK определяют три вещи — язык проекта, место выполнения кода и способ авторизации.

## Что важно учитывать

- Вебхук подходит для интеграции в одном Битрикс24, OAuth — для приложения, которое устанавливают в разные Битрикс24. Подробности — в разделах [Вебхуки](../local-integrations/local-webhooks.md) и [Протокол OAuth 2.0](../settings/oauth/index.md)
- Ключ вебхука и токены OAuth дают доступ к данным Битрикс24. Не размещайте их в клиентском коде и не публикуйте в репозитории
- Доступ к данным ограничен правами того пользователя, от имени которого работает вебхук или приложение, и списком scope. Значения scope смотрите в справочнике [Права доступа](../api-reference/scopes/permissions.md)
- SDK не отменяет ограничения платформы. Интенсивность и ресурсоемкость запросов описывает страница [Лимиты REST API](../limits.md)

## JavaScript SDK

[B24JsSDK](./b24jssdk/index.md) — универсальная JavaScript-библиотека для браузера и Node.js. Поддерживает современные возможности языка, такие как async/await, и автоматическое преобразование типов данных.

Используйте B24JsSDK, если:

- разрабатываете внешнее веб-приложение или бэкенд-сервис на Node.js
- нужны пакетные запросы [batch](../settings/how-to-call-rest-api/batch.md), типовые объекты Битрикс24 и логирование
- нужна гибкая авторизация: вебхук для одного Битрикс24 или OAuth для тиражного приложения

[BX24.js](./bx24-js-sdk/index.md) — библиотека для приложений, встроенных внутрь интерфейса Битрикс24. Код выполняется во фрейме приложения, поэтому библиотека получает данные авторизации от самого Битрикс24 и подставляет их в запросы.

Используйте BX24.js, если:

- приложение работает внутри интерфейса Битрикс24
- нужен доступ к методам Битрикс24 с готовой авторизацией, без своего сервера
- нужны системные диалоги выбора, управление окном приложения и хранение настроек на стороне Битрикс24

## PHP SDK

[B24PhpSDK](./b24phpsdk/index.md) — полноценный PHP-клиент со строгой типизацией, автодополнением и поддержкой генераторов для эффективной работы с большими данными.

Используйте B24PhpSDK, если:

- создаете сложное тиражное приложение для Маркетплейса
- нужны автодополнение в IDE, строгая типизация и события для обработки токенов
- нужна эффективная работа с большими данными через генераторы PHP

[CRest PHP SDK](./crest-php-sdk/index.md) — стартовый набор на PHP. Поставляется с готовым классом `CRest`.

Используйте CRest PHP SDK, если:

- нужно быстро проверить работу метода или собрать простую интеграцию
- разрабатываете локальное приложение для внутренних задач
- нужна минимальная настройка подключения

## Python SDK

[B24PySDK](./b24pysdk/index.md) — официальный Python SDK для REST API Битрикс24. Он дает Python-интерфейс к методам Битрикс24, проверяет типы и параметры запросов перед отправкой, возвращает данные в привычных для Python структурах и единообразно обрабатывает ошибки.

В SDK есть интеграции для Django, FastAPI и Flask: они помогают валидировать данные, которые Битрикс24 передает при открытии приложения, вызове обработчиков событий и работе с бизнес-процессами.

Используйте B24PySDK, если:

- разрабатываете приложение, интеграцию или автоматизацию на Python
- нужно работать с методами Битрикс24 без ручной сборки HTTP-запросов
- нужны автодополнение в IDE, проверка параметров запросов и предсказуемая структура ответов
- бэкенд-приложению нужно надежно обрабатывать авторизацию, события и ошибки

## Go SDK

[B24GoSDK](./b24gosdk/index.md) — официальный Go SDK для REST API Битрикс24. Он берет на себя авторизацию, повторы при отказах, обход списков и разбор ответов, а метод вызывается по имени. Оберток на отдельные методы нет намеренно: метод, который Битрикс24 выпустил сегодня, доступен в SDK сегодня же.

Используйте B24GoSDK, если:

- разрабатываете интеграцию, приложение или фоновый сервис на Go
- нужны [пакетные запросы](../settings/how-to-call-rest-api/batch.md) и выгрузка больших списков
- нужно предсказуемое поведение при обрывах связи и превышении лимитов
- нужен код без внешних зависимостей

## С чего начать

1. Выберите SDK по таблице [Как выбрать SDK](#all-sdk) и откройте его страницу — там описаны установка и первый вызов
2. Настройте авторизацию: [вебхук](../local-integrations/local-webhooks.md) для интеграции в одном Битрикс24 или [приложение с OAuth](../settings/oauth/index.md) для установки в разные Битрикс24
3. Найдите нужный метод в разделе [Справочник REST API](../api-reference/index.md) и вызовите его средствами выбранного SDK

## Дополнительные инструменты

[MCP](../ai-tools/mcp.md) — вспомогательный сервис для AI-ассистентов в среде разработки. MCP предоставляет AI-ассистентам структурированные данные и спецификации методов REST API, помогает генерировать корректный код и ускорять создание приложений.

[B24 AI Starter](https://github.com/bitrix-tools/b24-ai-starter) — стартовый шаблон приложения для Битрикс24 с инструкциями для AI-агентов. В шаблоне есть готовый фронтенд на Nuxt 3 с подключенным UI Kit и три варианта бэкенда на выбор: PHP, Python или Node.js — с SDK, авторизацией через [протокол OAuth 2.0](../settings/oauth/index.md) и окружением в Docker. Шаблон избавляет от сборки структуры приложения с нуля: AI-агент дописывает бизнес-логику по готовым инструкциям из репозитория.

[UI Kit](../api-reference/widgets/ui-kit/index.md) — набор Vue-компонентов для создания интерфейсов в фирменном стиле Битрикс24. Обеспечивает единство визуального языка и ускоряет фронтенд-разработку.
