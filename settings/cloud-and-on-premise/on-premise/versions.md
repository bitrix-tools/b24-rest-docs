# Версионность модулей в коробочном Битрикс24

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

При разработке приложений учитывайте, что REST-методы и события, доступные в облачном Битрикс24, могут быть недоступны на отдельных коробочных установках.

Это происходит по двум причинам:

- обновления для коробочной версии выходят позже, чем для облака, потому что требуют отдельной проверки совместимости
- установку обновлений запускает администратор конкретного коробочного Битрикс24, поэтому установка может работать не на последней версии модулей

Перед установкой приложения проверьте доступность нужных инструментов REST API в конкретном Битрикс24:

1. Получите список доступных методов методом [methods](../../../api-reference/common/system/methods.md). Для точечной проверки одного метода используйте [method.get](../../../api-reference/common/system/method-get.md): он покажет, существует ли метод в этом Битрикс24 и доступен ли он с текущими правами приложения
2. Получите список доступных событий методом [events](../../../api-reference/events/events.md). Метод работает в контексте авторизации приложения и возвращает события, которые можно использовать в Битрикс24
3. Сравните результат с методами и событиями, которые нужны вашему приложению. Если нужного метода или события нет, проверьте версию модуля, к которому относится этот REST-инструмент

Список версий всех модулей коробочного Битрикс24 находится в административном разделе: *Настройки > Настройки продукта > Модули*.

## Что делать, если метод или событие недоступны

Если у вас нет административного доступа к коробочному Битрикс24, передайте администратору:

- название недоступного REST-метода или события
- название модуля, к которому относится метод или событие
- минимальную версию модуля, если она указана в документации к методу, событию или разделу

Администратор должен обновить нужный модуль или всю коробочную установку до актуальной версии. Обновления устанавливаются через встроенную систему SiteUpdate в административной части Битрикс24: *Marketplace > Обновление платформы*. В разделе *Установка обновлений* администратор может установить рекомендуемые обновления, а на вкладке *Список обновлений* выбрать, что именно обновить. Подробнее об обновлении коробки читайте в статье [Как обновить коробочную версию Битрикс24](https://helpdesk.bitrix24.ru/open/24668808/).

После обновления повторно проверьте доступность REST-метода через [methods](../../../api-reference/common/system/methods.md) или [method.get](../../../api-reference/common/system/method-get.md), а доступность события — через [events](../../../api-reference/events/events.md).

Если после обновления метод или событие все еще недоступны, проверьте, установлен ли соответствующий модуль и хватает ли приложению нужных [прав доступа](../../../api-reference/scopes/permissions.md).
