# Установка шаблонов сайтов

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Шаблон сайта — это конфигурационное решение: одностраничный или многостраничный сайт, сохраненный в один архив. Решение работает без REST API — страницы сайта из архива создает сам Битрикс24.

Разработчик собирает сайт на своем Битрикс24, выгружает его в архив, загружает архив в карточку приложения и публикует решение в Битрикс24 Маркетплейс. Дальше установку на Битрикс24 клиента выполняет сама платформа.

Сборка самого сайта — страницы, блоки и контент — описана в пользовательской документации [Как создать и настроить сайт в Битрикс24](https://helpdesk.bitrix24.ru/open/25309314/).

## Когда подходит шаблон сайта

Шаблон сайта подходит, когда решение состоит из готовых страниц и не требует своего кода: например, сайт-визитка для автосервиса или многостраничный сайт клиники.

Если решению нужен собственный код и обращения к REST API, выбирайте тиражное приложение. Если решение — это настройки CRM с воронками, стадиями и полями, выбирайте отраслевую CRM. Если автоматизация собирается из готовых роботов — умные сценарии. Все варианты и порядок их установки собраны в статье [{#T}](./index.md).

## Что нужно перед началом

- **Права.** Чтобы выгрузить сайт, нужно право на просмотр этого сайта. Если администратор запретил экспорт сайтов, кнопка выгрузки недоступна.
- **Кабинет разработчика.** Тип размещения зависит от региона: в Битрикс24 Маркетплейс для России доступна только подписка. Там, где есть бесплатный вариант, достаточно согласиться с офертой партнерского каталога. Условия по регионам описаны в статье [{#T}](../../market/preparing-to-publish/how-to-add-app.md).
- **Результат экспорта.** Сайт выгружается в отдельный архив. Именно его загружают в карточку приложения.
- **Ограничения архива.** Требования к весу архива, размеру изображений и имени файла собраны в статье [{#T}](../../market/preparing-to-publish/requirements-sites.md).

## Как подготовить шаблон сайта

1. Соберите сайт на своем Битрикс24 и наполните его демо-контентом. Страницы собираются из блоков верстки — готовых секций с текстом, картинками и формами. Рекомендации по структуре и оформлению собраны в статье [{#T}](../../market/preparing-to-publish/requirements-sites.md).

2. Выгрузите сайт в архив: на странице *Экспорт настроек* Битрикс24 Маркетплейс в группе *Сайты* выберите действие *Экспорт сайта*. Похожим образом выгружают [отраслевые CRM](./vertical-crm-installation.md) и [умные сценарии](./smart-scripts-installation.md), но действие у каждого решения свое. В архив попадают страницы сайта и блоки верстки, из которых он собран.

3. Загрузите архив в карточку приложения в кабинете разработчика — порядок описан в статье [{#T}](../../market/preparing-to-publish/how-to-add-app.md).

4. Опубликуйте решение в [Битрикс24 Маркетплейс](../../market/index.md). Требования к публикации собраны в статье [{#T}](../../market/preparing-to-publish/publication-requirements.md).

{% note warning "" %}

Сайт, созданный в Битрикс24 с помощью CoPilot, выгрузить в архив нельзя. Ограничение привязано к тому, как сайт появился: если вы собрали его сами, а CoPilot потом дорабатывал тексты, изображения или отдельные блоки, экспорт работает

{% endnote %}

## Как проходит установка

Установку выполняет тот Битрикс24, куда ставится решение, от разработчика на этом шаге ничего не требуется. Битрикс24:

1. скачивает архив из кабинета разработчика
2. распаковывает архив
3. устанавливает приложения из сохраненного списка и добавляет их блоки верстки в репозиторий этого Битрикс24
4. создает страницы сайта из архива

Как устанавливаются решения других типов, описано в статье [{#T}](./index.md).

## Приложения Маркетплейса в шаблоне сайта

Собирая сайт перед экспортом, разработчик может установить и использовать приложения из Битрикс24 Маркетплейс, которые добавляют нестандартные блоки верстки. Так разработчик шаблона занимается структурой и содержанием сайта, а готовые дизайнерские блоки берет из приложений.

Список задействованных приложений сохраняется в архиве при экспорте. В него попадают приложения, чьи блоки стоят на страницах сайта, и приложения, которые создали сами страницы.

{% note warning "" %}

Если среди этих приложений есть решения, доступные клиенту только по подписке Битрикс24 Маркетплейс, свой шаблон сайта тоже придется публиковать в каталоге на условиях подписки

{% endnote %}
