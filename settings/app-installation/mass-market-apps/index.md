# Обзор установки тиражных приложений

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Тиражное приложение перед работой нужно установить на конкретный Битрикс24. Для этого есть четыре варианта установки. Они отличаются тем, что пользователь делает при первом запуске приложения.

## Порядок работы над тиражным приложением

Что такое установка и зачем она нужна, описано в обзоре [{#T}](../index.md). Ниже собрано то, что специфично для тиражных приложений.

Обычно разработчик создает приложение в кабинете разработчика, пишет код и тестирует его: устанавливает приложение из кабинета на Битрикс24, где у него есть административный доступ. Только когда приложение проверено, разработчик отправляет его на модерацию. Опубликованное решение пользователи устанавливают из Битрикс24 Маркетплейс. Подробнее о подготовке к публикации — в разделе [{#T}](../../../market/preparing-to-publish/how-to-add-app.md).

Решите заранее, какой будет процедура установки и нужна ли она вообще.

## Варианты установочного процесса

Варианты установки:

- **[Добавление без установочного сценария](#no-install-scenario)** — приложение начинает работать сразу после установки. Подходит, когда приложению не нужны одноразовые настройки при установке
- **[Добавление с мастером установки](./installation-master.md)** — при установке Битрикс24 открывает ваш интерфейс, где можно выполнить одноразовые операции: зарегистрировать виджеты, подписаться на события и другое. Подходит приложениям с интерфейсом, которым нужна первичная настройка
- **[Добавление с вызовом установочного callback](./installation-callback.md)** — после установки Битрикс24 отправляет токены OAuth на ваш обработчик. Подходит приложениям без интерфейса, вся логика которых работает в обработчиках событий
- **[Добавление с мастером настройки для REST-only приложения](./rest-only-installation-master.md)** — встроенная форма Битрикс24 для приложений без своего интерфейса. Подходит, когда нужны простые настройки и данных от callback-обработчика недостаточно

Чаще всего тиражным приложениям нужен мастер установки: в нем регистрируют места встройки виджетов и подписываются на события.

## Добавление без установочного сценария {#no-install-scenario}

Чтобы приложение работало сразу, без процедуры установки, заполните поле *Ссылка на приложение* в карточке версии. Укажите в нем основной URL приложения: по этому адресу интерфейс приложения встраивается в левое меню Битрикс24.

Для статического приложения — архива с файлами HTML и JS — достаточно поместить в архив файл index.html.

И с URL, и со статическим архивом приложение доступно пользователям сразу после установки.

Если у приложения нет пользовательского интерфейса, отключите опцию *Добавлять свою страницу и пункт в главном меню*. Процедура установки такому приложению не нужна, но токены REST API нужны. Их приложение получит через [callback-обработчик](./installation-callback.md): Битрикс24 вызовет его сразу после установки.
