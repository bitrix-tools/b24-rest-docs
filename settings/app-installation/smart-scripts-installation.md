# Установка умных сценариев

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Умные сценарии — это конфигурационное решение: набор роботов CRM, которые запускают по выбранным лидам, сделкам, компаниям и контактам за пределами воронок. Решение работает без REST API — сценарии из архива применяет сам Битрикс24.

Разработчик собирает сценарии на своем Битрикс24, выгружает их в архив, загружает архив в карточку приложения и публикует решение в Битрикс24 Маркетплейс. Дальше установку на Битрикс24 клиента выполняет сама платформа.

## Когда подходят умные сценарии

Умные сценарии подходят, когда автоматизация собирается из готовых роботов и не требует своего кода: например, рассылка по отобранным контактам или последовательность действий по выбранным компаниям.

Если решению нужен собственный код и обращения к REST API, выбирайте тиражное приложение. Если решение — это настройки CRM целиком, с воронками, стадиями и полями, выбирайте отраслевую CRM. Если готовый сайт — шаблоны сайтов. Все варианты и порядок их установки собраны в статье [{#T}](./index.md).

## Что нужно перед началом

- **Права.** Выгрузить и загрузить умные сценарии может только администратор Битрикс24.
- **Кабинет разработчика.** Для бесплатного размещения достаточно согласиться с офертой партнерского каталога. Условия описаны в статье [{#T}](../../market/preparing-to-publish/how-to-add-app.md).
- **Результат экспорта.** Сценарии выгружаются в отдельный архив. Именно его загружают в карточку приложения.

## Как подготовить решение

1. Соберите сценарии на своем Битрикс24. Списки объектов, для которых настраивают сценарии, собраны в разделе *Автоматизация > Умные сценарии*, а в самом списке меню *Умные сценарии* содержит пункты *Список сценариев*, *Создать сценарий* и *Установить из Маркета*. Порядок настройки и требования к описанию собраны в статье [{#T}](../../market/preparing-to-publish/requirements-smart-scripts.md).

2. Выгрузите сценарии в архив. Экспорт называется *Экспорт Умных сценариев* и работает отдельно от экспорта настроек CRM, которым выгружают [отраслевые CRM](./vertical-crm-installation.md).

3. Загрузите архив в карточку приложения в кабинете разработчика — порядок описан в статье [{#T}](../../market/preparing-to-publish/how-to-add-app.md).

4. Опубликуйте решение в [Битрикс24 Маркетплейс](../../market/index.md). Требования к публикации собраны в статье [{#T}](../../market/preparing-to-publish/publication-requirements.md).

## Как проходит установка

Установку выполняет тот Битрикс24, куда ставится решение, от разработчика на этом шаге ничего не требуется. Битрикс24:

1. скачивает архив из кабинета разработчика
2. распаковывает архив
3. добавляет сценарии из файлов архива к объектам CRM — лидам, сделкам, компаниям и контактам

Как устанавливаются решения других типов, описано в статье [{#T}](./index.md).

## Приложения Маркетплейса в умных сценариях

Настраивая сценарии перед экспортом, разработчик может установить и использовать приложения из Битрикс24 Маркетплейс. Например, задействовать в сценарии нестандартного робота из готового решения. Так разработчик умных сценариев занимается бизнес-логикой, а отдельных роботов берет готовыми — как устроены роботы приложений, описано в обзоре [{#T}](../../api-reference/bizproc/bizproc-robot/index.md).

Список использованных приложений сохраняется в архиве при экспорте. При импорте приложения из этого списка устанавливаются автоматически на тот же Битрикс24, куда ставятся умные сценарии.

{% note warning "" %}

Если среди этих приложений есть решения, доступные клиенту только по подписке Битрикс24 Маркетплейс, свои умные сценарии тоже придется публиковать в каталоге на условиях подписки

{% endnote %}
