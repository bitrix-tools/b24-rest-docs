# Варианты установки приложений в Битрикс24

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

## Как устроена установка

Установка приложения — это его регистрация на конкретном Битрикс24, а не загрузка или скачивание кода. После регистрации сервер авторизации Битрикс24 начинает выдавать приложению токены OAuth 2.0, с которыми оно работает через REST API этого Битрикс24.

Процесс проходит в три этапа:

1. **Добавление приложения** — локальное приложение разработчик создает в разделе «Разработчикам» на своем Битрикс24, тиражное добавляет в [кабинете разработчика](../../market/preparing-to-publish/how-to-add-app.md) и публикует в Битрикс24 Маркетплейс
2. **Установка на Битрикс24** — сервер регистрирует приложение и выдает ему токены OAuth 2.0. Установку выполняет пользователь с правами администратора. Локальное приложение устанавливает разработчик на своем Битрикс24, тиражное — администратор из Битрикс24 Маркетплейс или разработчик из кабинета разработчика на любой Битрикс24 с административным доступом
3. **Завершение установки** — приложение без интерфейса устанавливается автоматически, приложение с интерфейсом и мастером настройки завершает установку методом `installFinish`. Подробности в статье [Завершение установки приложений](./installation-finish.md)

## Варианты установки

Сценарий установки зависит от типа решения. Различают два вида решений:

- тиражное приложение — работает через REST API, публикуется в Битрикс24 Маркетплейс и устанавливается на разные Битрикс24
- конфигурационное решение — готовый набор настроек Битрикс24, который работает без REST API

Конфигурационное решение Битрикс24 скачивает из кабинета разработчика и применяет его настройки автоматически.
