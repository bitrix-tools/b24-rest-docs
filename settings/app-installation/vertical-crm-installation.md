# Установка отраслевых CRM

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

Отраслевая CRM — это конфигурационное решение: набор настроек CRM, сохраненный в один архив. В архив попадают воронки сделок, стадии лидов, пользовательские поля объектов CRM, настройки роботов и бизнес-процессов. Решение работает без REST API — настройки из архива применяет сам Битрикс24.

Разработчик настраивает CRM на своем Битрикс24, выгружает настройки в файл, загружает архив в карточку приложения и публикует решение в Битрикс24 Маркетплейс. Дальше установку на Битрикс24 клиента выполняет сама платформа.

Страница описывает подготовку и публикацию решения. Как настроить саму CRM — завести воронки, поля и роботов — описано в пользовательской документации Битрикс24.

## Когда подходит отраслевая CRM

Отраслевая CRM подходит, когда решение состоит из одних настроек и не требует своего кода: например, готовая схема работы для автосервиса, клиники или агентства недвижимости.

Если решению нужен собственный код и обращения к REST API, выбирайте тиражное приложение. Если нужны роботы за пределами воронок — умные сценарии, если готовый сайт — шаблоны сайтов. Все варианты и порядок их установки собраны в статье [{#T}](./index.md).

## Что нужно перед началом

- **Права.** Выгрузить и загрузить настройки CRM может только администратор Битрикс24.
- **Кабинет разработчика.** Для бесплатного размещения достаточно согласиться с офертой партнерского каталога. Для решений по подписке Битрикс24 Маркетплейс контрагента проверяют и направляют соглашение на подпись через ЭДО — это занимает один-два рабочих дня. Условия описаны в статье [{#T}](../../market/preparing-to-publish/how-to-add-app.md).
- **Результат экспорта.** Настройки выгружаются в zip-архив. Именно его загружают в карточку приложения.

## Как подготовить отраслевую CRM

1. Настройте CRM на своем Битрикс24: воронки и стадии, пользовательские поля объектов, роботов и бизнес-процессы.

2. Выгрузите настройки в zip-архив. В канбане CRM найдите блок *Отраслевые CRM для вашего бизнеса* и выберите пункт *Экспорт своей CRM в файл*. Кнопка *Настроить* в этом же блоке открывает панель отраслевых решений.

3. Загрузите архив в карточку приложения в кабинете разработчика — порядок описан в статье [{#T}](../../market/preparing-to-publish/how-to-add-app.md).

4. Опубликуйте решение в [Битрикс24 Маркетплейс](../../market/index.md). Требования к публикации собраны в статье [{#T}](../../market/preparing-to-publish/publication-requirements.md).

## Как проходит установка

Установку выполняет тот Битрикс24, куда ставится решение, от разработчика на этом шаге ничего не требуется. Битрикс24:

1. скачивает архив из кабинета разработчика
2. распаковывает архив
3. применяет настройки из файлов архива

Как устанавливаются решения других типов, описано в статье [{#T}](./index.md).

## Приложения Маркетплейса в отраслевой CRM

Настраивая CRM перед экспортом, разработчик может установить и использовать приложения из Битрикс24 Маркетплейс. Например, задействовать в автоматизации нестандартных роботов из готового решения или подключить приложение, которое форматирует телефоны клиентов. Так разработчик отраслевой CRM занимается бизнес-логикой, а отдельные роботы и интеграции берет готовыми.

Список использованных приложений сохраняется в файле отраслевой CRM при экспорте. При импорте приложения из этого списка устанавливаются автоматически на тот же Битрикс24, куда ставится отраслевая CRM.

{% note warning "" %}

Если среди этих приложений есть решения, доступные клиенту только по подписке Битрикс24 Маркетплейс, свою отраслевую CRM тоже придется публиковать в каталоге на условиях подписки

{% endnote %}
