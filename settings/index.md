# Настройка и использование REST API

{% note tip "" %}

Выберите инструмент для разработки с AI-агентом:

- используйте [Битрикс24 Вайбкод](../ai-tools/vibecode.md), чтобы создать приложение для Битрикс24 по описанию задачи без знания языков программирования. Агент напишет код и разместит приложение на сервере без ручной настройки хостинга
- используйте [MCP-сервер](../ai-tools/mcp.md), чтобы разрабатывать интеграцию через REST API в своем проекте. Агент будет обращаться к официальной REST-документации

{% endnote %}

Интеграция с Битрикс24 на REST API проходит один и тот же путь независимо от задачи: вы авторизуетесь, вызываете методы, получаете события об изменениях и удерживаете нагрузку в пределах лимитов. Материалы ниже отвечают на практические вопросы каждого этапа — как безопасно обратиться к REST, какой тип приложения выбрать и настроить, чем отличается коробочная версия и как оптимизировать нагрузку.

Описания конкретных методов и их параметров сюда не входят: их смотрите в [Справочнике методов](../api-reference/index.md). Если вы еще не выполнили ни одного запроса, начните с раздела [Первые шаги](../first-steps/index.md).

## С чего начать {#getting-started}

1. Выберите способ авторизации: вебхук для проверки метода и простой интеграции, OAuth 2.0 для приложения — [Авторизация в REST](how-to-call-rest-api/authorization.md)
2. Соберите первый запрос и разберите ответ — [Как вызывать методы REST API](how-to-call-rest-api/index.md)
3. Оформите интеграцию как приложение, если нужны интерфейс, управление доступом или работа от имени разных пользователей — [Варианты установки приложений](app-installation/index.md)
4. Подпишитесь на нужные [события](../api-reference/events/index.md) и подготовьте обработчик к пиковой нагрузке — [Рекомендации по производительности](performance/index.md)
5. Проверьте требования безопасности и, для коробочной версии, сетевые доступы перед выходом на клиента — [Облако и коробка Битрикс24](cloud-and-on-premise/index.md)
