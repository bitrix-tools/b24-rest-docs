## Что значит «нужен разбор вручную»

На странице есть блок примеров, но что-то в нём не определяется автоматически по самой странице. Три причины:

- у блока нет вкладки `cURL` вовсе, поэтому имя метода взять неоткуда;
- тело запроса записано так, что не разбирается как JSON;
- написание параметров **верхнего уровня** не определяется: в таблице «Параметры метода» такого параметра нет, а решать за страницу нельзя.

Такие блоки заполняются вручную по той же странице. Подставлять вместо них пустые параметры или угадывать регистр нельзя — вкладка молча разошлась бы с соседними.

## Откуда берётся написание параметров

Имена параметров **верхнего уровня** — из таблицы «Параметры метода» этой же страницы (если таблицы нет — из вкладки JS). Коды полей внутри (`TITLE`, `STAGE_ID`, `UF_CRM_…`) не трогаются: это коды полей портала. Состав и значения параметров — ровно как в `cURL` этого же блока.
